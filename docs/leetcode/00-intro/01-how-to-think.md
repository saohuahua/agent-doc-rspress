# 算法问题的分析方法

算法设计从明确问题开始。输入相同，并不意味着适用方法相同：返回数值还是下标、要求一个答案还是全部答案、是否允许修改输入，都会影响状态设计与实现方式。数据结构的选择应建立在这些需求之上。

本篇以两数之和为例，介绍从问题定义到朴素方法、从计算瓶颈到优化方案的分析过程，不要求算法先修知识。

## 问题定义与约束

对于数组 `[2, 7, 11, 15]` 和目标值 9，“寻找两个和为 9 的数”仍不足以完整定义任务。返回数值 `[2, 7]` 与返回下标 `[0, 1]` 是不同要求；允许重复使用一个位置与要求位置不同，也对应不同的合法解集合。输出一组答案与输出全部答案还会改变终止条件。

这几个问题会改变方案。若返回原下标，排序之后就必须保留位置关系。若不能重复使用一个元素，就要保证两次选择来自不同位置。若需要全部答案，就不能遇到第一个结果直接结束。

问题定义需要覆盖输入、输出、合法范围和输入修改权限。算法所依赖的前提必须来自题目约束，不能由样例推定。例如样例只包含正数，并不证明所有合法输入均为正数；若允许负数，区间扩大后总和未必增加。

## 朴素方法的建立

直接方法是固定第一个位置，再检查其后每个位置。示例中先固定数值 2，与下一项 7 相加得到 9，即找到合法配对。若该位置的所有配对均失败，再处理下一个位置。

该方法具有明确步骤，可以作为正确性基线。朴素方法的作用不仅是提供初始实现，还在于暴露具体计算过程，使重复工作能够被识别；在小规模输入上，它也可用于验证优化方案。

上述过程对应两层循环：外层枚举位置 `i`，内层枚举 `j > i`，检查两项之和。限制 `j > i` 同时排除了同一位置复用与数对重复检查。长度为 n 时，检查次数为 n(n−1)/2，时间复杂度为 O(n²)。

## 计算瓶颈与信息需求

固定当前值 x 后，另一个数的值已经由等式确定为 `target - x`。内层循环的功能实际上是寻找这个确定值，而不是执行不可预测的组合计算。重复扫描可转换为对已访问记录的查询。

单独保存数值只能判断是否存在，无法满足返回下标的要求。因此记录需要包含“数值 → 下标”的对应关系。`Map` 提供按键查找关联值的操作，适合承载这项信息。结构选择由查询需求与输出要求共同决定。

结果复用并非适用于所有问题。例如包含 n 个不同元素的集合有 2ⁿ 个子集，显式输出全部子集至少需要访问这些结果。分析优化空间时，需要区分重复工作与输出规模决定的必要工作。

## 状态约定与操作顺序

假设当前访问 7，需要另一项是 2。Map 里只保存之前访问过的位置，查询命中 2 就说明两个位置不同。

查询必须先于当前项的记录。例如目标为 6、当前值为 3 时，若先写入当前项，再查询所需值 3，就可能返回当前位置两次。先查历史、后记当前项，可以直接保证匹配来自不同位置。

完整方案由此确定：从左到右遍历，查询 `target - 当前值` 是否存在于历史表；存在时返回历史下标与当前下标，否则记录当前值及其下标，再处理下一项。

## 正确性解释与过程验证

完整解法说明应包含状态定义、查询对象、更新顺序、终止条件与正确性依据。“使用 Map 遍历一次”只描述了工具与外部结构，没有说明这些要素。

所谓不变量，就是每轮开始时一直成立的事实。这里是“Map 只包含当前下标之前见过的元素”。初始时 Map 为空，确实没有之前的元素；记录当前项后，下一轮仍满足事实。因此查询不会选中当前位置本身。

正确性还需要说明覆盖性。设合法配对的位置为 i 和 j，且 i < j；处理 j 时，位置 i 的值已进入历史表，因此可以被查询命中。正确性论证解释任意合法输入上的结论，具体状态推演则用于核对实现是否遵循该论证，两者承担不同的验证职责。

## 分析阶段与检查对象

| 分析阶段 | 检查对象 | 阶段结果 |
| --- | --- | --- |
| 问题定义 | 最小输入 明确输出 合法约束 | 可判断候选答案是否合法 |
| 优化分析 | 重复扫描 重复计算 无效候选 | 确定可复用或可排除的信息 |
| 实现设计 | 状态含义 单步更新 循环边界 | 可执行且符合正确性依据的步骤 |

分层提示对应上述分析阶段，依次提供观察方向、所需信息与步骤组织。使用提示后的检查重点是能否在新的实例上重新建立状态与推导过程。

## 解法复述与检查

检查问题：两数之和的朴素方案是什么？重复计算发生在哪里？替代扫描需要保存哪些信息？先查询后记录的依据是什么？若要求全部数值组合，终止条件与记录内容需要怎样调整？

:::details 参考回答

直接枚举不同位置的所有数对。固定一个数后，总是在寻找它的补数，重复扫描可以改成查询已见记录。记录数值到下标的映射，从左向右先查询补数，存在就返回，之后才记录当前项，因此不复用当前位置。若输出所有组合，需要继续遍历，还要根据数值组合或下标组合的定义处理重复，不能原样照搬立即返回的代码。

:::

上述分析顺序适用于建立解题过程，具体的优化结论仍需要由每道题的约束、状态关系与正确性论证分别支持。
