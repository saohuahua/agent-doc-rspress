# 算法基础复习与迁移

## 练习一 输出要求改变

对同一数组，分别判断是否存在重复值，以及返回所有重复值及其出现次数。两项任务所需保存的信息有何差异？

:::details 提示与解析

存在性判断只需记录已出现的值，遇到重复即可结束。输出次数则需要完整扫描，并保存各值的计数。Set 提供的成员信息足以支持前者，但不足以独立支持后者。

:::

## 练习二 循环数量与实际工作

外层遍历 n 项，内层指针只向右移动且从不归零，两层循环一定是平方复杂度吗？

:::details 提示与解析

复杂度取决于内层指针在全部迭代中的累计移动次数。若最多移动 n 次，且每步其余工作为常数，总时间仍为 O(n)。若每次外层迭代都重置内层并重新扫描至末尾，总时间则可能达到 O(n²)。循环层数不能替代操作计数。

:::

## 练习三 相同值与同一个对象

两个节点值都是 3，能否据此判断两条链表相交？

:::details 提示与解析

不能。相交指共享同一个节点对象及其后续连接。分别创建的两个节点即使值相同，也可能属于彼此独立的链。引用关系图中，两条路径到达同一节点才表示相交，仅节点标签相同不构成相交。

:::
