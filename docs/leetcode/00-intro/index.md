# 算法基础与问题分析

本章介绍算法学习所需的基本分析方法与运行模型。具备 TypeScript 语法经验后，仍需要明确算法中的输入语义、状态表示、操作成本和正确性条件，这些内容决定程序是否能够在给定约束下得到完整答案。

解题分析同时包含过程与依据：过程说明如何执行，依据说明为何覆盖全部合法候选、为何排除某些候选，以及输入规模增长时工作量如何变化。样例演算用于展示过程，不能替代一般性的正确性与复杂度论证。

本章内容依次为：

1. [算法问题的分析方法](/leetcode/00-intro/01-how-to-think)：从问题定义建立朴素方法，再推导优化方案
2. [复杂度与数据结构](/leetcode/00-intro/02-complexity-and-structures)：从操作数量理解结构选择
3. [TypeScript 运行时与递归](/leetcode/00-intro/03-ts-runtime-and-recursion)：引用语义、数值范围与调用栈

后续章节通过先修链接引用本章概念。学习检查以能否说明概念含义、推演具体实例及判断适用条件为准。章节练习见 [基础复习与迁移](/leetcode/00-intro/review)。
