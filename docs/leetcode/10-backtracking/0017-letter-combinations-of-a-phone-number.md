# 0017 电话号码的字母组合

相关基础：[本章基础](/leetcode/10-backtracking/)。题目来源：[力扣 17](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)。

## 题目

:::info 题面

**难度**：中等

输入由数字2到9组成的字符串，返回电话按键对应字母的所有组合。每个数字必须选择恰好一个字母，组合字母顺序与数字位置一致。例如23先从abc里选一个，再从def里选一个，得到九个长度二的字符串。

原题用电话键盘图表示字母关系，文字对应如下：

| 数字 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 字母 | abc | def | ghi | jkl | mno | pqrs | tuv | wxyz |

:::

### 官方示例

> **示例 1**
>
> 输入：digits = "23"
> 输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]

> **示例 2**
>
> 输入：digits = "2"
> 输出：["a","b","c"]

### 约束

- 1 <= digits.length <= 4
- digits[i] 是范围 ['2', '9'] 的一个数字。

## 前期思路

### 朴素方法与复杂度

处理23时，先固定a，然后分别接d、e、f；再固定b，接d、e、f；最后固定c。对234，再在每个已得到的二字母前缀后接g、h、i。这个手工过程就是逐位置做选择，写几层循环能解决固定长度，但输入长度变化时固定层数不合适。

### 状态设计与优化依据

每个位置使用自己的按键映射，因此需要记录当前数字下标index和已选字母path。与全排列不同，一个字母出现过不代表不能再用，例如22允许aa。不能引入全局used来禁止相同字符，因为不同数字位置彼此独立，只限制每个位置选一个。

这里没有大量可以合并成一个答案的重复子任务，因为题目必须输出每一个不同前缀搭配后缀的字符串。可以复用同一段“处理下一位置”的代码逻辑，但不同前缀生成的结果都需要保留，不应为了避免递归重复而丢掉组合。

### 算法推导

先用映射表表示2到9各自的字母列表。visit(index)负责为当前位置选字母。index等于digits.length时所有位置已填满，将path.join('')保存为结果字符串并返回。

否则读取当前数字对应字母，逐个把一个字母压入path，调用visit(index+1)，返回后弹出字母，再试下一个。每次深入只推进一个数字位置，所以终止深度固定，不会出现无限使用同一位置的问题。

任何输出组合都对应每个位置唯一的一次字母选择，循环穷尽当前按键全部字母，逐层组合就覆盖所有答案。因为每个按键映射内没有重复字母，不同选择路径得到不同字符串。输入中重复数字不破坏这一点，因为它们占据不同位置。

### 变式分析与错误反例

- 若输入允许0或1，必须先确定它们代表空格、字面数字还是非法输入；不能自行默认为跳过，否则改变组合长度语义。若只求组合数量，直接把各按键字母数量相乘即可，不必生成全部字符串。错误禁止重复字母会在22时漏掉aa、bb、cc，说明是否允许复用必须看位置任务而不是套used模板。

## 执行过程示例 输入 23

| 第一位选择 | 第二位逐次选择 | 得到结果 |
| --- | --- | --- |
| a | d e f | ad ae af |
| b | d e f | bd be bf |
| c | d e f | cd ce cf |

每行之间先撤销第一位的旧字母，再选择新字母；行内每次撤销第二位。path 保存当前分支的可变选择序列；保存结果时 join 生成新的字符串，后续修改 path 不会改变已保存的答案。

## 解法复述与检查

- 为什么不需要used？
- 什么条件表示一个完整答案？
- 为什么空输入先返回？

:::details 算法概述

每层对应一个数字位置，查表拿到该位置能选的字母，逐个添加到当前前缀，然后处理下一位置。填完全部位置时生成字符串，回来撤销刚才字母。每个位置独立选择，所以相同字母可以在不同位置重复出现。空输入按题意直接返回空数组。

:::

## 复杂度与边界

- 长度为n，每个位置最多四种字母，总结果最多4^n个，每个生成字符串需要**O(n)**，时间和输出空间**O(n·4^n)**。
- 辅助path和递归栈**O(n)**，不修改输入。
- 数字7与9有四个字母，不能把映射全部写成三个。
- 输入只含2到9是题目契约，字符映射不处理0与1。
- 本地实现对约束之外的空字符串返回空数组。

## 分层提示

:::details 提示一 观察方向

手工列23时先固定哪个位置 每个位置有哪些选择

:::

:::details 提示二 需要的信息

记录正在处理的数字下标和已选前缀 不需要禁止重复字母

:::

:::details 提示三 组织步骤

逐位置查表枚举字母 进入下一位置 满长保存 返回弹出当前字母

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function letterCombinations(digits: string): string[] {
  if (digits.length === 0) return []
  const letters: Record<string, string> = {
    '2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
    '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz',
  }
  const result: string[] = []
  const path: string[] = []
  const visit = (index: number): void => {
    if (index === digits.length) {
      result.push(path.join(''))
      return
    }
    // 当前层只为当前数字选择一个字母
    for (const char of letters[digits[index]]) {
      path.push(char)
      visit(index + 1)
      path.pop()
    }
  }
  visit(0)
  return result
}
```
