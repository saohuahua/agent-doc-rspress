# 0131 分割回文串

相关基础：[本章基础](/leetcode/10-backtracking/)。题目来源：[力扣 131](https://leetcode.cn/problems/palindrome-partitioning/)。

## 题目

:::info 题面

**难度**：中等

给非空小写字母字符串，将它切成若干连续片段，要求每段都是回文，返回全部切分方案。每个字符必须被覆盖恰好一次。aab可切成a、a、b，也可切成aa、b；不能切出只包含aa而漏掉b的方案，也不能重排字符。

:::

### 官方示例

> **示例 1**
>
> 输入：s = "aab"
> 输出：[["a","a","b"],["aa","b"]]

> **示例 2**
>
> 输入：s = "a"
> 输出：[["a"]]

### 约束

- 1 <= s.length <= 16
- s 仅由小写英文字母组成

## 前期思路

### 朴素方法与复杂度

字符串有n-1个相邻字符间隙，每个间隙可以切或不切，因此最多2的n减一次方种切法。可以先生成每种切法，再检查每个片段是否回文，但当第一段已经不是回文时，后面怎样切都不可能修好它，继续生成剩余切法浪费工作。

### 状态设计与优化依据

从左到右构建切分，start表示尚未处理的第一个字符位置，path保存已经确认回文的片段。每次枚举当前这一段的终点end，只有s[start..end]为回文才继续处理end+1。这样非法片段不会进入路径，搜索始终保持已完成部分合法。

同一区间的回文判定也可能被不同前缀切法反复询问。先用二维表保存每个左右区间是否回文，依赖是两端相等且内部回文。长度一和二只需检查两端相等；更长读取内部。按区间长度递增预处理，具体状态思想可见 [多维动态规划基础](/leetcode/16-2d-dp/)。

### 算法推导

预处理完成后，visit(start)遍历end从start到n-1。若回文表为假，直接跳过这个终点，而不是结束循环，因为更长片段可能回文，例如ab不是回文但aba是。若为真，截取片段加入path，递归处理后缀，再pop恢复。

start等于n时，说明前面所有字符已由合法片段覆盖，复制path作为完整答案。不是每层入口都保存，因为未处理完的前缀方案不是整串答案，这一点与子集每个前缀都可作为答案不同。

任意合法切分都有一个确定的第一段终点，之后又是合法后缀切分，循环和递归会逐段选到它。不同终点序列代表不同切分位置，所以不会重复。start每次至少增加一，递归一定结束，最大深度n对应每个字符单独一段。

### 变式分析与错误反例

- 若只求最少切割次数，不需要列出所有方案，可以用回文表加前缀最优状态求解。若只判断是否存在切分，在单字符也算回文的规则下永远存在，问题会变得平凡，应先检查题意是否遗漏了段长等限制。错误遇到ab非回文就停止，会在aba时错过整段回文。

## 执行过程示例 输入 aab

| 当前start | 尝试片段 | 判断与后续 |
| --- | --- | --- |
| 0 | a | 回文 深入start1 |
| 1 | a | 回文 深入start2 |
| 2 | b | 回文 到末尾 保存a a b |
| 1 | ab | 非回文 跳过 |
| 0 | aa | 回文 深入start2再取b 保存aa b |
| 0 | aab | 非回文 跳过 |

对同一个start2的后缀b，两个不同前缀都要得到自己的完整输出，不能简单用“访问过start2”剪掉第二次，否则会漏掉aa、b。可以复用回文真值，但不能丢掉不同前缀带来的不同答案。

## 解法复述与检查

- 为什么非回文时用continue而不是break？
- 什么时候才允许保存path？

:::details 算法概述

首先计算各区间回文性，然后从尚未处理的位置枚举下一段终点。片段是回文才加入路径继续切后缀，处理完整串才复制保存。返回后撤销片段，同一层继续尝试更长片段。不同切点对应不同方案，非法片段提前排除。

:::

## 复杂度与边界

- 预处理时间和空间**O(n²)**。
- 搜索与复制输出保守为**O(n·2^n)**时间，输出总字符和片段存储上界**O(n·2^n)**。
- 排除输出，回文表**O(n²)**，路径字符总长**O(n)**，递归栈**O(n)**。
- 不修改输入。
- 单字符只有一段方案，全相同字符串使每个切点都可选，是指数输出的典型最坏情况。

## 分层提示

:::details 提示一 观察方向

先决定第一段在哪结束 它必须满足什么才能继续

:::

:::details 提示二 需要的信息

保存下一个未处理位置 已选片段以及区间回文真值

:::

:::details 提示三 组织步骤

枚举终点 回文才深入下一位置 全串耗尽保存 返回撤销当前片段

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function partition(s: string): string[][] {
  const n = s.length
  const palindrome = Array.from({ length: n }, () => new Array<boolean>(n).fill(false))
  for (let length = 1; length <= n; length++) {
    for (let left = 0; left + length <= n; left++) {
      const right = left + length - 1
      palindrome[left][right] = s[left] === s[right] &&
        (length <= 2 || palindrome[left + 1][right - 1])
    }
  }
  const result: string[][] = []
  const path: string[] = []
  const visit = (start: number): void => {
    if (start === n) {
      result.push([...path])
      return
    }
    for (let end = start; end < n; end++) {
      // 短片段失败不代表更长片段也失败
      if (!palindrome[start][end]) continue
      path.push(s.slice(start, end + 1))
      visit(end + 1)
      path.pop()
    }
  }
  visit(0)
  return result
}
```
