# 0051 N 皇后

相关基础：[本章基础](/leetcode/10-backtracking/)。题目来源：[力扣 51](https://leetcode.cn/problems/n-queens/)。

## 题目

:::info 题面

**难度**：困难

在n乘n棋盘上放n个皇后，任意两个不能同行、同列或同对角线，返回所有棋盘方案。每行用一个由点和Q组成的字符串表示。不是只求方案数量，也不是找到一个就停止。n至少为1，某些规模例如2和3没有合法方案，返回空数组。

:::

### 官方示例

> **示例 1**
>
> 输入：n = 4
> 输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]

> **示例 2**
>
> 输入：n = 1
> 输出：[["Q"]]

### 约束

- 1 <= n <= 9

## 前期思路

### 朴素方法与复杂度

最直接从n²个格子里挑n个，再检查冲突，搜索空间极大。先利用同行约束：n个皇后不能同行，而棋盘恰有n行，所以每行必须恰好一个。这样可以逐行决定皇后的列，不再枚举一行放零个或多个的无效配置。

### 从冲突中提取信息

处理当前行时，此前行已经各放一个皇后，所以不会发生同行冲突；只需要知道哪些列和两种对角线已经被占用。列号直接作为集合键。向右下延伸的同一对角线上，行列同时加一，因此row-col不变；向左下延伸时行加一列减一，因此row+col不变。

这两个表达式分别是在同一对角线上移动时保持不变的量，因此可用于识别对角线。负的row-col也可以作为Set里的数字键，不需要为了数组下标再额外平移。另存positions[row]表示该行皇后列，用于成功后构造棋盘。

### 算法推导

visit(row)枚举当前行每一列。如果列、差对角线或和对角线已占用，就跳过。这是安全剪枝，因为此前皇后不会在当前分支后续移动，当前冲突已经无法靠填后面的行修复。

选择合法列后，把三项占用加入集合并记录位置，继续下一行。返回后删除三项占用，让同层别的列能使用属于它们的资源。positions当前行会被下一候选覆盖，不必清空；构造棋盘只在所有行已经赋值后进行。

row==n表示所有行完成，此时逐行按列位置创建点串和Q，加入结果。每层固定一行，枚举所有可能列，所以任意合法棋盘对应一条唯一列序列，必定被访问；集合只排除确实攻击此前皇后的列，所以不漏合法方案，也不会产生相同棋盘两次。

### 变式分析与错误反例

- 若只求数量，可在row==n时计数而不构造棋盘，减少输出成本，但仍需搜索所有方案。若棋盘有禁放格子，在候选判断中增加格子许可即可，三类攻击规则仍成立。错误只检查列会把任意列排列都当答案，如[0,1,2,3]四个皇后全在同一对角线上。

## 执行过程示例 四皇后的一个有效分支

下标从0开始，选择列序列[1,3,0,2]。这里只展示该成功分支，其他失败候选仍由循环检查并回退。

| 行列 | 差键 | 和键 | 为什么可放 |
| --- | --- | --- | --- |
| 0行1列 | -1 | 1 | 三个集合初始为空 |
| 1行3列 | -2 | 4 | 列3与两个键都未使用 |
| 2行0列 | 2 | 2 | 列0与两个键都未使用 |
| 3行2列 | 1 | 5 | 列2与两个键都未使用 |

这得到 .Q..、...Q、Q...、..Q.。比如第二行若尝试列0，和键为1，撞上第一行皇后的和键1，因此立刻跳过，即使两者列不同也不能放。

## 解法复述与检查

- 为什么可以每行只决定一列？
- 两个对角线编号从哪里来？
- 返回后要清理哪些集合？

:::details 算法概述

n个互不同列同行的皇后必定每行一个，所以逐行枚举列。保存已占用的列、行减列对角线和行加列对角线，三者都未占用才放。深入下一行后返回就撤销占用，所有行完成再根据列位置生成棋盘。每个合法棋盘对应唯一列选择序列。

:::

## 复杂度与边界

- 列不重复使搜索节点受排列树约束，每节点扫描n列，给出**O(n·n!+R·n²)**的保守时间上界，R为输出方案数。
- 辅助集合、位置数组和递归栈**O(n)**，输出空间**O(R·n²)**。
- 不修改输入。
- n=1输出单Q，n=2与3输出空。
- Set操作采用常见平均常数时间模型，棋盘构造的n²字符成本明确计入输出。

## 分层提示

:::details 提示一 观察方向

n个皇后不许同行 n行棋盘意味着每行必须几个

:::

:::details 提示二 需要的信息

列可直接记录 对角线沿线移动时行减列或行加列保持不变

:::

:::details 提示三 组织步骤

逐行尝试不冲突列 标记三类占用 深入后撤销 全行完成才构造棋盘

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function solveNQueens(n: number): string[][] {
  const result: string[][] = []
  const positions = new Array<number>(n)
  const columns = new Set<number>()
  const differences = new Set<number>()
  const sums = new Set<number>()
  const visit = (row: number): void => {
    if (row === n) {
      result.push(positions.map(col => '.'.repeat(col) + 'Q' + '.'.repeat(n - col - 1)))
      return
    }
    for (let col = 0; col < n; col++) {
      const difference = row - col
      const sum = row + col
      if (columns.has(col) || differences.has(difference) || sums.has(sum)) continue
      // 三种占用分别排除同列与两个方向的对角线
      columns.add(col)
      differences.add(difference)
      sums.add(sum)
      positions[row] = col
      visit(row + 1)
      // 撤销当前皇后使同层其他候选互不影响
      columns.delete(col)
      differences.delete(difference)
      sums.delete(sum)
    }
  }
  visit(0)
  return result
}
```
