# 回溯复习 选择单位与状态恢复

## 练习一 顺序是否重要

输入 [1,2] 分别求排列和子集 为什么前者允许从2回头选1 后者不需要

:::details 提示与解析

排列12与21不同 必须枚举两条路径 子集同一组只有一个答案 约定原下标递增便不会重复 每题的选择起点取决于结果身份

:::

## 练习二 是否允许复用

候选 [2,3] 凑7 若2和3无限使用 与每个只允许一次 分别怎样传下一层起点

:::details 提示与解析

无限使用可以得到223 递归仍从当前下标开始 每个一次必须从下一下标开始 此输入无解 两者都不需要回头选择更小下标

:::

## 练习三 剪枝是否安全

切回文时发现ab不回文 能否停止所有更长片段 总和题超目标又能否停止

:::details 提示与解析

ab能扩成aba 所以只能跳过当前终点 正数候选超额无法被后续正数修复 可以剪 若允许负数则后者也不再安全

:::
