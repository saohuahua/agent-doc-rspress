# 0078 子集

相关基础：[本章基础](/leetcode/10-backtracking/)。题目来源：[力扣 78](https://leetcode.cn/problems/subsets/)。

## 题目

:::info 题面

**难度**：中等

给互不相同的整数数组，返回所有子集，包括空集和全集。题目数组非空。子集不关心排列顺序，[1,2] 与 [2,1] 代表同一个子集，只能输出一次。结果顺序不限。每个原位置只能选一次，区别于允许无限取同一个数的组合总和。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [1,2,3]
> 输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

> **示例 2**
>
> 输入：nums = [0]
> 输出：[[],[0]]

### 约束

- 1 <= nums.length <= 10
- -10 <= nums[i] <= 10
- nums 中的所有元素 互不相同

## 前期思路

### 朴素方法与复杂度

以 [1,2] 为例，先考虑1选还是不选，再考虑2选还是不选：都不选得到空集，只选2得到[2]，只选1得到[1]，都选得到[1,2]。每个元素有两种决定，共2的n次方种子集。完整输出具有指数规模，仅写出全部结果就需要指数级时间。

### 怎样避免同一子集重复出现

如果像全排列一样每层从所有未用数字中挑一个，并在每层记录当前路径，就会同时得到[1,2]和[2,1]。需要一条规范：每个子集内部按原下标递增选择。任何子集都能唯一按这个顺序表示，因此规范不会丢答案，只去掉同一组元素的不同选择次序。

保存path表示当前选中元素，start表示下一次最小允许下标。每次只能从start到末尾选一个位置i，下一层从i+1继续。这样已选位置和它之前的候选不能再次被选，也不需要额外used数组。

### 算法推导

进入每次递归时，先复制path作为一个答案。为什么不是等到末尾才保存？因为当前路径本身就是一个合法子集，未来选择是可选的，不需要把数组所有元素填满。最初path为空，所以自然包含空集。

然后枚举i从start到n-1，压入nums[i]，递归visit(i+1)，返回后pop恢复。循环结束表示当前前缀的所有扩展都已尝试，自动返回。start==n时没有扩展，但入口保存已经记录该子集。

每条路径下标严格递增，因此同一子集不可能通过不同顺序生成。反过来任一子集按下标排好，其第一个、第二个直到最后一个元素都会被逐层枚举到，所以没有遗漏。这是“限制选择范围”解决重复的具体依据，不是等输出后再用Set补救。

### 变式分析与错误反例

- 若允许重复值，[1,1] 按不同下标选择会输出两次[1]。可排序后在同层跳过相同值，但不能在整个路径里禁止重复，因为[1,1]本身是合法子集。若只求固定大小k的组合，只在path长度k时保存并停止，起点递增的去重思想仍适用。

## 执行过程示例

| 递归入口 | path | 保存结果 | 后续动作 |
| --- | --- | --- | --- |
| start0 | [] | [] | 先尝试下标0 |
| start1 | [1] | [1] | 再尝试下标1 |
| start2 | [1,2] | [1,2] | 无候选 返回并撤销 |
| 回到根再选下标1 | [2] | [2] | 下一start2 无候选 |

最终四个子集。没有从[2]回头选1的分支，因为这会重复之前的[1,2]。这个“不回头”来自子集无序的题意，而不是一种可以直接迁移到全排列的规则。

## 解法复述与检查

- 为什么每个入口都保存？
- 为什么下一层从i+1开始而不是零？

:::details 算法概述

使子集中的原下标始终递增，以此保证每个集合只有一种生成顺序。当前路径随时都是合法子集，所以递归入口先复制保存。再枚举起点之后的元素，选择后只允许继续选更靠后的位置，返回时撤销该选择。

:::

## 复杂度与边界

- 共有2的n次方个子集，复制总元素数量为n乘2的n减一次方，时间和输出空间上界**O(n·2^n)**。
- 辅助path与递归栈**O(n)**，不修改输入。
- 本地扩展允许空数组并产生[[]]，因为空集也是唯一子集。
- 数字互异使下标集合与数值集合一一对应。

## 分层提示

:::details 提示一 观察方向

同一组数字改变选择顺序 是否应该算新答案

:::

:::details 提示二 需要的信息

保存下一次允许选择的最小下标 让同一组只按一种顺序生成

:::

:::details 提示三 组织步骤

入口保存当前路径 遍历后续下标 选择后从下一下标继续 返回撤销

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function subsets(nums: number[]): number[][] {
  const result: number[][] = []
  const path: number[] = []
  const visit = (start: number): void => {
    // 当前路径本身就是一个合法子集
    result.push([...path])
    for (let i = start; i < nums.length; i++) {
      path.push(nums[i])
      // 下标递增消除同一集合的不同选择顺序
      visit(i + 1)
      path.pop()
    }
  }
  visit(0)
  return result
}
```
