# 0141 环形链表

相关基础：[本章基础](/leetcode/07-linked-list/)。[官方题目](https://leetcode.cn/problems/linked-list-cycle/)。

## 题目

:::info 题面

**难度**：简单

从头沿 next 一直走，是否可能再次遇见已经访问过的同一个节点？若会就有环，返回 true。题面中的 pos 只是描述测试器怎样连边，不是函数参数，也不能通过它直接判断。两个节点数值相同不代表环，环由对象之间的连接关系决定。

:::

### 官方示例

> **示例 1**
>
> 输入：head = [3,2,0,-4], pos = 1
> 输出：true

> **示例 2**
>
> 输入：head = [1,2], pos = 0
> 输出：true

> **示例 3**
>
> 输入：head = [1], pos = -1
> 输出：false

### 约束

- 链表中节点的数目范围是 [0, 10^4]
- -10^5 <= Node.val <= 10^5
- pos 为 -1 或者链表中的一个 有效索引 。

### 进阶要求

尝试只用 O(1) 额外空间判断是否有环。

## 前期思路

### 朴素方法与复杂度

最直接的办法是保存访问过的节点引用：每到一个节点检查 Set，已经存在就有环；走到 null 就无环。时间 O(n)，辅助空间 O(n)。这已经把“环”的定义变成可执行过程。若不保存整个访问历史，单个向前指针无法知道某节点是否重访，需要另一个能体现重复的参照物。

### 优化依据

存在环时，两个指针进入环后的位置差可以按环长取模。每轮前进步数不同，会持续改变相对位置；无环时，较快指针先到达 null。因此可以通过两个不同速度的指针检测环，而不保存全部访问历史。这种方法叫快慢指针，但追赶能够必然成功，还需要说明速度差。

### 算法推导

slow 每轮走一步，fast 每轮走两步。每轮开始先检查 fast 及 fast.next 非空，保证两步都能安全走。移动后再比较引用，不能在一开始比较，因为二者同在头并不意味着有环。

如果无环，fast 不断向末尾前进，有限步内遇到空，返回 false。如果有环，slow 最终也会进入环。设环长为 L，二者在环内每轮相对距离变化一格，模 L 的距离最多经过 L 次变化就会变成零，因此必然相遇。这里只能说明存在环，相遇位置不必是环入口。

比较引用保证只有真正走到同一对象才命中，val 从未参与判断。算法没有修改 next，因此不会为检测本身制造环或破坏环。

### 变式分析与错误反例

- 错误反例：只有一个节点且 next=null，若在循环移动前检查 slow===fast，会立即误报有环。另一个错误是比较 val，两个独立值为 1 的节点就足以骗过它。
- 如果需要环入口，不能返回这次相遇节点，例子 a→b→c→b 的相遇节点是 c，但入口是 b。应继续使用距离关系定位，见本章 0142。若节点后继由一个确定函数生成而非 next 保存，同样可以把函数状态看作节点，但必须保证状态空间有限且后继规则确定。

## 执行过程示例

链表 a→b→c→b，b 与 c 构成环。

| 轮次 | slow 移动后 | fast 移动后 | 判断 |
| --- | --- | --- | --- |
| 1 | b | c | 不同 继续 |
| 2 | c | c | 同一对象 有环 |

无环 a→b→c 的第一轮到 b 和 c，下一轮因 c.next 为空结束。单节点自环第一次移动后仍都是该节点，所以正确判 true。

## 解法复述与检查

复述检查：

- 共同起点为什么不能作为有环证据？
- 快指针的两步怎样保证安全？
- 环内相对距离每轮变化多少，为何一定能相遇？

:::details 算法概述

可先用访问集合判断重访。如果要省空间，可以让两个指针每次分别走一步和两步。快指针走到空说明无环；存在环时，两者进入环后每轮相对靠近一格，迟早相遇。必须移动后再比较对象引用，共同起点本身不是证据。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { ListNode } from '../shared.js'

export function hasCycle(head: ListNode | null): boolean {
  let slow = head
  let fast = head
  while (fast !== null && fast.next !== null) {
    slow = slow!.next
    fast = fast.next.next
    // 移动之后比较避免把共同起点误判为环
    if (slow === fast) return true
  }
  return false
}
```

## 复杂度与边界

- 有 n 个可达节点时，进入环前最多 **O(n)** 步，追赶最多一圈 **O(n)**，总时间 **O(n)**。
- 辅助空间 **O(1)**，没有递归栈，也不修改输入。
- 空链、单节点无环、自环、很长前缀接短环都遵循同一逻辑。
