# 0024 两两交换链表中的节点

相关基础：[本章基础](/leetcode/07-linked-list/)。[官方题目](https://leetcode.cn/problems/swap-nodes-in-pairs/)。

## 题目

:::info 题面

**难度**：中等

把相邻两节点成对交换，1→2→3→4 变成 2→1→4→3。题目要求交换节点，不能只交换内部值。奇数长度最后剩下一个不动，空链和单节点也不变。注意“成对”固定按原来的位置划分，第一组处理完应从原第三个节点开始下一组。

:::

### 官方示例

> **示例 1**
>
> 输入：head = [1,2,3,4]
> 输出：[2,1,4,3]

> **示例 2**
>
> 输入：head = []
> 输出：[]

> **示例 3**
>
> 输入：head = [1]
> 输出：[1]

### 约束

- 链表中节点的数目在范围 [0, 100] 内
- 0 <= Node.val <= 100

## 前期思路

### 朴素方法与复杂度

手工画四个位置：组前节点 before、第一节点 first、第二节点 second、后续入口 after。原来是 before→first→second→after，目标是 before→second→first→after。可以先把所有节点装进数组再交换引用，但图上已经告诉只需局部四个位置，没有必要存全链。

### 优化依据

本题并没有重复的大量数值计算，优化重点是避免额外存储与避免丢失连接。若只顾把 second.next 改成 first，原 first.next 仍指向 second，就暂时出现两节点环；若后续引用也没保护，剩余链会丢失。赋值顺序需要同时满足目标连接关系和未处理部分仍可访问这两个条件。

### 算法推导

增加 dummy，使第一组也存在 before。每轮确认 before 后面至少两个节点，保存 first 与 second。首先 first.next = second.next，把原第一节点接向组后；接着 second.next = first，完成组内反向；最后 before.next = second，让处理完的前缀接到新组头。

完成后原 first 是这一组的新尾，把 before 移到 first。它的 next 正好是下一组入口，不应移到 second，否则会重新处理已完成的节点。循环开始时，before 之前都是已经交换好的完整组，而后面保持原顺序，这一约定每轮都成立。

每轮消耗两个节点，因此最终只可能剩零个或一个。剩一节点没有配对对象，本来就应该不动。所有赋值只连接现有节点，每组不增不减，且组与组之间顺序不变。

### 变式分析与错误反例

- 错误反例：1→2→3 中若只交换 val，会让原节点 1 的对象依然在首位，与节点交换要求不符。若组后继续令 before=second，下一轮会错误地把已处理的 first 和后续节点配对。
- 若要求每 k 个反转，局部重连思路仍然可用，但必须先确认组内是否够 k 个，并保存组后入口；不足 k 时按题意保持，详见 0025。若只要求数值排列且对象身份无关，交换值是另一种允许的操作，但不能默认两个问题完全等价。

## 执行过程示例

输入 1→2→3→4→5。

| 阶段 | before | 本组 | 处理后链表 |
| --- | --- | --- | --- |
| 初始 | dummy | 1 和 2 | 尚未处理 |
| 第一组完成 | 1 | 2→1 | 2→1→3→4→5 |
| 第二组完成 | 3 | 4→3 | 2→1→4→3→5 |
| 检查下一组 | 3 | 只有 5 | 不满足两个节点而停止 |

在每次画图时，给节点写对象标识而不仅是值，才能确认确实交换了节点。

## 解法复述与检查

复述检查：

- 请画出组前、第一、第二和组后四个位置，再说出三条目标连接。为什么下一轮前驱是原第一节点？
- 奇数尾节点怎样处理？

:::details 算法概述

将问题拆成局部重连。用哑节点保存组前位置，每次取后面两个节点，先让第一接到组后，再让第二接第一，最后组前接第二。原第一成了新尾，也是下一组的前驱。每次处理两个，最后不足两个保持不变。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { ListNode } from '../shared.js'

export function swapPairs(head: ListNode | null): ListNode | null {
  const dummy = new ListNode(0, head)
  let before = dummy
  while (before.next !== null && before.next.next !== null) {
    const first = before.next
    const second = first.next!
    // 先连接组尾再将第二个节点接到组前
    first.next = second.next
    second.next = first
    before.next = second
    before = first
  }
  return dummy.next
}
```

## 复杂度与边界

- 时间 **O(n)**，每对常数次改边；辅助空间 **O(1)**，无递归栈。
- 原地修改 next，不修改 val，不新建结果节点。
- dummy 只占常数空间且不返回。
- 所有边重连后链仍无环。
