# 0142 环形链表 II

相关基础：[本章基础](/leetcode/07-linked-list/)。[官方题目](https://leetcode.cn/problems/linked-list-cycle-ii/)。

## 题目

:::info 题面

**难度**：中等

这次不只判断有环，还要返回从头第一次进入环的节点引用。若沿 next 会到 null，返回 null。入口是拓扑位置，不是最小值，也不必是检测环时两个指针第一次相遇的位置。先读 0141 理解为什么一快一慢会相遇，再看怎样把这个相遇信息转化为入口。

示例中的 `pos` 描述尾节点连回的下标，`-1` 表示不连回；它用于构造测试链表，不是函数入参。返回的是入口节点对象，示例用下标说明该对象的位置。

:::

### 官方示例

> **示例 1**
>
> 输入：head = [3,2,0,-4], pos = 1
> 输出：返回索引为 1 的链表节点

> **示例 2**
>
> 输入：head = [1,2], pos = 0
> 输出：返回索引为 0 的链表节点

> **示例 3**
>
> 输入：head = [1], pos = -1
> 输出：返回 null

### 约束

- 链表中节点的数目范围在范围 [0, 10^4] 内
- -10^5 <= Node.val <= 10^5
- pos 的值为 -1 或者链表中的一个有效索引

### 进阶要求

尝试只用 O(1) 额外空间定位环入口。

## 前期思路

### 朴素方法与复杂度

用 Set 顺着链走，遇到第一个已经记录的对象就返回，简单且正确。因为前缀没有重复，第一次重访必然发生在环入口。时间 O(n)，额外空间 O(n)。如果使用快慢指针检测，已经省掉集合，但仅得到环上某个位置，必须再回答“它与入口相差多少”。

### 优化依据

不需要记住沿途每一处位置，距离关系就足够。设头到入口的距离为 a，环长度为 L，首次相遇时慢指针走了 t 步，快指针走了 2t 步。相遇意味着快指针比慢指针多走整数圈，所以 t=kL。慢指针从头走到相遇点，在环上的位移是 t-a，因此相遇点再走 a 步，就来到环位移 t，也就是入口。

### 算法推导

先按 0141 的规则检测相遇。相遇后把一个新指针 entry 放回头，另一个留在相遇点，然后二者每次各走一步。经过 a 步，entry 第一次到入口，另一个也恰好回到入口，因此返回这里。

为什么它们不会提前在错误位置相遇？entry 在走完 a 步之前仍在环外，而另一个始终在环内，环外节点不可能与环内对象相同。若 a=0，头本身就是入口，第一次相遇位置也会使这段同步过程立即或按关系成立，代码直接比较即可。

推导使用的是模环长的距离，不要求相遇前慢指针只走半圈或快指针只多走一圈。k 可以是任意正整数，这是长前缀短环情形下仍然正确的原因。无环时第一阶段就返回 null，不进入定位过程。

### 变式分析与错误反例

- 错误反例：a→b→c→d→b 中直接返回第一次相遇点会返回 d，正确入口为 b。若第二阶段仍让一个指针走两步，刚才关于同步 a 步的证明不再成立，不能保留第一阶段速度。
- 若要求环长，从相遇节点出发沿 next 走到再次回到自己，计步即可；如果要求断开环，需先定位入口，再找环上其前驱并改 next，这会修改输入，应与只读检测明确区分。

## 执行过程示例

a→b→c→d→b，前缀长度 1，环长 3。

| 检测轮次 | slow | fast | 说明 |
| --- | --- | --- | --- |
| 1 | b | c | 尚未相遇 |
| 2 | c | b | 快指针已经绕回 |
| 3 | d | d | slow 走了 3 步 是环长倍数 |
| 定位起点 | a | d | 一个回到链表头 |
| 同走一步 | b | b | 返回入口 b |

相遇点 d 并非环入口，因此还需要第二阶段定位入口。

## 解法复述与检查

复述检查：

- 第一次相遇为什么不一定是入口？
- 慢指针总路程为何是环长整数倍？
- 一个回头以后为何能恰好同时到入口？

:::details 算法概述

先用一快一慢找相遇，没有相遇就是无环。设慢指针相遇时走 t 步，因为快指针多走整数圈，所以 t 是环长倍数。头到入口若为 a，相遇点再走 a 步也到入口。于是一个指针回头，另一个留在相遇点，同速前进，首次重合就是入口。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { ListNode } from '../shared.js'

export function detectCycle(head: ListNode | null): ListNode | null {
  let slow = head
  let fast = head
  while (fast !== null && fast.next !== null) {
    slow = slow!.next
    fast = fast.next.next
    if (slow === fast) {
      let entry = head
      // 一个从头出发一个从相遇处出发同步前进
      while (entry !== slow) {
        entry = entry!.next
        slow = slow!.next
      }
      return entry
    }
  }
  return null
}
```

## 复杂度与边界

- 时间 **O(n)**，检测和定位均至多与可达节点数同阶；辅助空间 **O(1)**，不修改节点，无递归。
- 输出为原入口引用。
- 支持头部即入口、自环、无环与空链。
- 非空断言对应已证实的环结构和安全的移动条件，不意味着可以删除第一阶段空检查。
