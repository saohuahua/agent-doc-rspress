# 0021 合并两个有序链表

相关基础：[本章基础](/leetcode/07-linked-list/)。[官方题目](https://leetcode.cn/problems/merge-two-sorted-lists/)。

## 题目

:::info 题面

**难度**：简单

输入两条非递减链表，输出合并后仍非递减的链表头。允许重复值，也允许某条为空。本实现重用原节点，不新建一整份答案。题目常规输入的两条链独立且无环；如果它们共享尾部，原地合并可能把同一个节点接入两次，那属于另一个需要约定的输入场景。

:::

### 官方示例

> **示例 1**
>
> 输入：l1 = [1,2,4], l2 = [1,3,4]
> 输出：[1,1,2,3,4,4]

> **示例 2**
>
> 输入：l1 = [], l2 = []
> 输出：[]

> **示例 3**
>
> 输入：l1 = [], l2 = [0]
> 输出：[0]

### 约束

- 两个链表的节点数目范围是 [0, 50]
- -100 <= Node.val <= 100
- l1 和 l2 均按 非递减顺序 排列

## 前期思路

### 朴素方法与复杂度

手工可以把所有数收集到数组，排序再建链，成本 O((m+n)log(m+n))，还要额外存储。但已知每条链内部有序，重新排序等于丢弃了已知信息。两条链的头节点分别是各自剩余部分的最小值，比较这两个候选即可确定下一项。

### 优化依据

为什么只看头就够？一条有序链里，当前头不大于后面任何值。因此两条剩余链全体节点的最小值，一定在两个当前头之一。无须反复扫描整条剩余链，也无须保存所有数。只需保存两个未处理入口和输出尾，就能持续构造结果。

### 算法推导

结果最初为空，直接操作头会遇到第一次选谁的分支。创建一个哑节点 dummy，它不属于答案，tail 从这里开始；每次把较小头接到 tail.next，再让被选择链的入口前进一步，最后更新 tail。

循环开始时，dummy.next 到 tail 是已经确定的有序前缀，两个输入变量指向尚未输出部分。选择较小头保证新值不会超过任何未处理值，也不会小于先前输出尾，因此有序性保持。每次只消耗一条链的一个节点，所以不会漏掉或重复消耗节点。

任意一条耗尽后，另一条本来有序且不小于当前尾，可以整体接上，无需再逐节点比较。返回 dummy.next 而非 dummy，避免把占位的值混入答案。相等时优先 list1 只是确定稳定顺序，换成另一边也满足数值要求。

### 变式分析与错误反例

- 错误反例：1→4 和 2→3，若选了 1 后同时推进两条链，2 被跳过，答案缺节点。若每轮忘记 tail = tail.next，后一次赋值会覆盖前一次连接。
- 若输入未排序，两个头不保证全局最小，应先排序或换方案。若要求不修改任何输入边，可以沿同样的选择规则新建节点，时间不变但输出空间 O(m+n)。若要合并很多条，可以复用这个两路合并作为分治基本操作。

## 执行过程示例

输入 1→3 与 2→3。

| 两个当前头 | 选择 | 已确定输出 | 下一步原因 |
| --- | --- | --- | --- |
| 1 和 2 | 1 | 1 | 第一条推进到 3 |
| 3 和 2 | 2 | 1→2 | 第二条推进到 3 |
| 3 和 3 | 第一条 3 | 1→2→3 | 第一条耗尽 |
| null 和 3 | 整体接后者 | 1→2→3→3 | 剩余部分已排序 |

## 解法复述与检查

复述检查：

- 为什么所有剩余节点的最小值只需比较两个头？
- 每轮究竟推进哪条链？
- 一边耗尽后为何另一边可以整体接入？

:::details 算法概述

两条链本来有序，所以每条剩余部分最小值就是头，下一项只需在两个头里选。使用一个哑节点统一空结果的连接，把较小节点接到结果尾，然后只推进它所属链。某条耗尽就整体接另一条，最后返回哑节点后继。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { ListNode } from '../shared.js'

export function mergeTwoLists(list1: ListNode | null, list2: ListNode | null): ListNode | null {
  const dummy = new ListNode()
  let tail = dummy
  while (list1 !== null && list2 !== null) {
    // 每条链剩余部分的最小值都在头部
    if (list1.val <= list2.val) {
      tail.next = list1
      list1 = list1.next
    } else {
      tail.next = list2
      list2 = list2.next
    }
    tail = tail.next
  }
  // 未耗尽部分自身有序可以整体接入
  tail.next = list1 ?? list2
  return dummy.next
}
```

## 复杂度与边界

- 时间 **O(m+n)**，辅助空间 **O(1)**，哑节点为固定开销，不含递归栈。
- 输出复用原节点，所以输入 next 会被修改。
- 空加空返回 null，单边空直接接非空侧。
- 输出节点数仍为 m+n，不能把结果包含这些现有节点误记成新分配的辅助空间。
