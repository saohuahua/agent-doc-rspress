# 0019 删除链表的倒数第 N 个结点

相关基础：[本章基础](/leetcode/07-linked-list/)。[官方题目](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)。

## 题目

:::info 题面

**难度**：中等

删除链表倒数第 n 个节点，并返回可能发生变化的头。n 从 1 开始计数，倒数第一就是尾。题目保证链表非空且 1≤n≤链表长度，不需要猜测无效 n 应如何处理。单链表删除一个节点的关键通常不是找到它自己，而是找到它前面的节点，让前驱跳过它。

:::

### 官方示例

> **示例 1**
>
> 输入：head = [1,2,3,4,5], n = 2
> 输出：[1,2,3,5]

> **示例 2**
>
> 输入：head = [1], n = 1
> 输出：[]

> **示例 3**
>
> 输入：head = [1,2], n = 1
> 输出：[1]

### 约束

- 链表中结点的数目为 sz
- 1 <= sz <= 30
- 0 <= Node.val <= 100
- 1 <= n <= sz

### 进阶要求

尝试只扫描链表一趟。

## 前期思路

### 朴素方法与复杂度

可以先遍历统计长度 L，再从头找到正数第 L-n+1 个节点的前驱，修改连接，时间 O(L)，但要走两遍。该方法通过总长度将倒数位置转换为正数位置，正确性直接来自位置编号关系。若希望一次同步扫描，不必先知道 L，而是维持两个指针之间的固定间距，让末尾出现时自动定位。

### 优化依据

倒数是相对于结尾定义的位置，因此当一个指针到尾时，另一个若恰好落后 n 条边，就位于待删节点的前驱。需要保存的不是整条历史，而是这个距离关系。为使删除头也有前驱，增加 dummy→head。dummy 是结构上的辅助位置，不计入原链长度。

### 算法推导

让 fast 和 slow 都从 dummy 出发，fast 先走 n 步。这时二者之间相差 n 条边。随后只要 fast.next 不为空，就让两个指针各走一步，间距保持不变。

fast 最终停在真实尾节点，slow 则位于尾之前 n 条边处。其后继恰好是倒数第 n 个，所以执行 slow.next = slow.next.next。注意这个版本的条件是 fast.next，不是 fast；另一种先走 n+1 步再让 fast 走到 null 的写法也能正确，但不能把两种边界混搭。

若 n=L，fast 初始就到尾，slow 仍是 dummy，跳过 dummy.next 正好删掉头。每次同步推进使 fast 更接近末尾，有限链必然终止。除待删前驱的一条边外，其余顺序不变。

### 变式分析与错误反例

- 错误反例：长度 2 且 n=2 时，若 slow 从 head 开始却仍采用相同快指针间距，会定位到错误位置。若返回原 head，删头后调用者仍从被删除的旧头开始。
- 如果要求返回倒数第 n 个而不是删除，终点关系可让慢指针直接停在目标，不再需要前驱；但要重新推导起点与停止条件。若允许一次遍历且输入来自不能重读的流，可以保留长度 n 的队列，但链表上的双指针已经避免了该空间。

## 执行过程示例

1→2→3→4→5 删除倒数第 2 个。

| 阶段 | fast | slow | 距离 |
| --- | --- | --- | --- |
| 同在哑节点 | dummy | dummy | 0 |
| 先走两步 | 2 | dummy | 2 条边 |
| 同走一次 | 3 | 1 | 2 条边 |
| 再走一次 | 4 | 2 | 2 条边 |
| 最后一次 | 5 | 3 | 2 条边 |
| 跳过后继 | 5 | 3 | 把 3.next 从 4 改为 5 |

## 解法复述与检查

复述检查：

- 删除为什么需要前驱而不仅是目标节点？
- 快指针先走几步、最终停在哪里？
- 删除头时慢指针应停在哪里？

:::details 算法概述

删除需要待删节点的前驱。首先添加哑节点处理删头情况，再让快指针领先 n 步。二者同速走到快指针位于尾时，慢指针就是目标前驱，改它的 next 跳过一个节点。返回哑节点后继，因为原头可能已经被删掉。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { ListNode } from '../shared.js'

export function removeNthFromEnd(head: ListNode | null, n: number): ListNode | null {
  const dummy = new ListNode(0, head)
  let fast: ListNode | null = dummy
  let slow = dummy
  // 保持快指针领先指定节点数
  for (let step = 0; step < n; step++) fast = fast!.next
  while (fast!.next !== null) {
    fast = fast!.next
    slow = slow.next!
  }
  // 慢指针停在待删节点的前驱
  slow.next = slow.next!.next
  return dummy.next
}
```

## 复杂度与边界

- 时间 **O(L)**，辅助空间 **O(1)**，没有递归。
- 会修改输入连接，输出重用节点。
- 删唯一节点得到 null，删头或删尾不需要特殊分支。
- 实现依赖 n 合法，不把非空断言当成输入验证。
