# 0160 相交链表

相关基础：[本章基础](/leetcode/07-linked-list/)。[官方题目](https://leetcode.cn/problems/intersection-of-two-linked-lists/)。

## 题目

:::info 题面

**难度**：简单

两条单向链表可能在某个节点汇合，汇合以后共享同一批节点。返回第一个共享节点的对象引用，没有共享节点则返回 null。相交不是两个节点的 val 相同：分别创建的两个值为 8 的节点仍是两个对象。题目保证链表无环，且函数不能改变原结构。判断依据是两条引用序列是否进入同一批节点对象。

示例中的 `skipA` 与 `skipB` 是两条链到共享节点之前各自经过的节点数，`intersectVal` 是共享节点的数值；它们用于描述测试链表，不是函数入参。即使列表展示出相同的数值尾段，也要以图中实际共用的节点引用判断相交。

:::

### 官方示例

> **示例 1**
>
> 输入：intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5], skipA = 2, skipB = 3
> 输出：Intersected at '8'

> **示例 2**
>
> 输入：intersectVal = 2, listA = [1,9,1,2,4], listB = [3,2,4], skipA = 3, skipB = 1
> 输出：Intersected at '2'

> **示例 3**
>
> 输入：intersectVal = 0, listA = [2,6,4], listB = [1,5], skipA = 3, skipB = 2
> 输出：No intersection

### 约束

- listA 中节点数目为 m
- listB 中节点数目为 n
- 1 <= m, n <= 3 * 10^4
- 1 <= Node.val <= 10^5
- 0 <= skipA <= m
- 0 <= skipB <= n
- 如果 listA 和 listB 没有交点，intersectVal 为 0
- 如果 listA 和 listB 有交点，intersectVal == listA[skipA] == listB[skipB]

### 进阶要求

尝试在 O(m + n) 时间内只用 O(1) 额外空间。

## 前期思路

### 朴素方法与复杂度

最直接的方法是对 A 中每个节点，遍历 B 检查有没有同一个对象，时间 O(mn)。更容易想到的优化是把 A 中的节点对象放进 Set，再沿 B 找第一个命中，时间 O(m+n)，额外空间 O(m)。集合方法按对象身份判断相交，但保存了整条链的访问历史；进一步优化可利用两条链的路径长度关系。

### 优化依据

困难不在共享尾部，而在两个不共享前缀长度不同。若让两个指针直接一起走，较短的前缀先到汇合点，另一个还没到，二者会一直错开。其实只需补齐这段距离。可以先量出两条长度，让长的一条先走差值；也可以让两个指针各自把 A 和 B 都走一次，用交换起点自然抵消长度差。

### 算法推导

a 从 A 出发，b 从 B 出发。正常时每次走一个 next，走到 null 后，下一步切换到另一条头节点。只有引用相同时停止，包括两个指针都为 null。

设独立前缀分别长 x 和 y，共享尾部长 c。走 A 再 B 的指针到第二次汇合点前走过 x+c+y，另一条路线是 y+c+x，因此能同时到达共享入口。如果首次就相遇，返回的也是共享入口，因为两条无环单链表一旦共享就不会再分叉。没有共享尾部时，两者走完长度相同的组合路线后同时为 null。

这里的交换不是修改链表，只是把局部变量重新指向另一个现有对象。null 也是路线中的切换状态，不能为了少写一步跳过某个头节点。当前实现把两边都按同一规则处理，空头也能自然终止。

### 变式分析与错误反例

- 错误反例：A 为独立节点 1→8，B 为另一批节点 2→8，比较 val 会误判相交；必须比较引用。
- 如果要求两个含环链表的交点，需要先判断环入口，分别讨论无环、同入口和不同入口但同环的情形，原来的组合长度推导不成立。若只要求布尔结果，返回值改为是否非空即可，移动规则不变。

## 执行过程示例

A 为 a→c，B 为 b→d→c，c 是同一个对象。表列出每轮开始时的位置。

| 轮次 | a | b | 原因 |
| --- | --- | --- | --- |
| 0 | a | b | 各自起点 |
| 1 | c | d | 各走一步 |
| 2 | null | c | A 先结束 |
| 3 | b | null | a 换到 B |
| 4 | d | a | b 换到 A |
| 5 | c | c | 补齐前缀差后命中同一对象 |

## 解法复述与检查

复述检查：

- 值相等与共享对象有何区别？
- 交换起点如何抵消前缀长度差？
- 不相交时两个指针最终怎样停止？

:::details 算法概述

首先区分值相同和对象相同。两条无环链表如果相交就共享尾部，真正障碍是前缀长度差。使两个指针走完自己的链后换到对方头，这样分别走 A 加 B 和 B 加 A，距离差被抵消。在同一个对象处停下就是入口，无交点时最终一起到 null。整个过程只移动指针，不改 next。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { ListNode } from '../shared.js'

export function getIntersectionNode(headA: ListNode | null, headB: ListNode | null): ListNode | null {
  let a = headA
  let b = headB
  // 交换起点使两条路线的总长度相同
  while (a !== b) {
    a = a === null ? headB : a.next
    b = b === null ? headA : b.next
  }
  return a
}
```

## 复杂度与边界

- 时间 **O(m+n)**，每个指针最多走两条链的长度并经过切换状态。
- 辅助空间 **O(1)**，无递归栈，输出是现有节点引用而非新链表。
- 单边为空、同一个头、长度不同、值重复但不共享均可处理。
- 无环是终止前提，有环输入不能直接使用此论证。
