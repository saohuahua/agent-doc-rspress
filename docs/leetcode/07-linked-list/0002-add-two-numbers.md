# 0002 两数相加

相关基础：[本章基础](/leetcode/07-linked-list/)。[官方题目](https://leetcode.cn/problems/add-two-numbers/)。

## 题目

:::info 题面

**难度**：中等

每个节点存一个十进制数位，最低位在头部。例如 2→4→3 表示 342，而不是 243。给出两个非负整数的这种表示，返回相加后的新链表，仍然低位在前。输入节点值为 0 到 9，链表非空，不存在多余前导零，但整数 0 用单节点 0 表示。

:::

### 官方示例

> **示例 1**
>
> 输入：l1 = [2,4,3], l2 = [5,6,4]
> 输出：[7,0,8]

> **示例 2**
>
> 输入：l1 = [0], l2 = [0]
> 输出：[0]

> **示例 3**
>
> 输入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
> 输出：[8,9,9,9,0,0,0,1]

### 约束

- 每个链表中的节点数在范围 [1, 100] 内
- 0 <= Node.val <= 9
- 题目数据保证列表表示的数字不含前导零

## 前期思路

### 朴素方法与复杂度

最直观可能是把链表转成 number，相加后再拆位。但位数可能很长，JavaScript number 不能精确保存任意长度整数，数值转换会丢精度。可以考虑 bigint，但这绕开了本题希望理解的逐位过程。纸上竖式加法正好从个位开始，输入头部已经给了正确顺序。

### 优化依据

一次加法只需要两边当前数位与上一位产生的进位，而不需要已经处理的低位原始内容。两条链长度不同时，较短一边缺失的高位等同于 0。于是保留两个当前节点和一个 carry，就能让任意长的输入按位完成。本实现选择新建输出节点，以保持两条输入链不变。

### 算法推导

每轮计算 sum = 当前两位 + carry。sum 的个位是 sum % 10，新进位是向下取整的 sum / 10。由于两个数位最多各 9，进位最多 1，所以每轮 sum 最多 19，不涉及大整数精度问题。

把新数位接到输出尾，推进存在的输入指针，再继续。终止条件不能仅看两条链是否结束：9 加 1 时第一轮输出 0 且产生进位 1，输入虽然都空了，还需再输出高位 1。因此循环条件包含 carry。

正确性可以按数位理解：每轮把当前位总量分为留在本位的余数和传给更高位的整十数，正是十进制表示的定义。此前低位已经确定，不会被更高位改变。所有输入位和进位都用完时，所有位的和完整输出。dummy 统一第一次创建节点的连接。

### 变式分析与错误反例

- 错误反例：9 加 1 如果循环只判断输入指针，得到单节点 0 而不是 0→1。将链表数字拼成 number 则会在超过安全整数范围时得到错误数位。
- 若改成高位在前，不能原样从头逐位加，因为低位进位还未知。可用两个栈把数位倒序取出，或在允许修改输入时先反转再加。若进制变成 B，只需让数位范围与取模除数同步变成 B，推导仍来自按位进位。

## 执行过程示例

输入 2→4→3 与 5→6→4，也就是 342+465。

| 当前两位 | 旧进位 | 总和 | 输出位 | 新进位 |
| --- | --- | --- | --- | --- |
| 2 和 5 | 0 | 7 | 7 | 0 |
| 4 和 6 | 0 | 10 | 0 | 1 |
| 3 和 4 | 1 | 8 | 8 | 0 |

结果 7→0→8 表示 807。再手推 9→9 加 1：先输出 0，再输出 0，输入结束后仍输出进位 1。

## 解法复述与检查

复述检查：

- 为什么头部正好对应竖式加法的起点？
- 某条链提前结束怎样补位？
- 两条链都结束后为什么仍可能继续一轮？

:::details 算法概述

输入低位在前，正好顺着链做竖式加法。每次取两位，不存在的一边按零，加上旧进位，余数作为新节点，商作为新进位。只要还有输入位或进位就继续，避免漏掉最高位。全程只进行小整数加法，不把整个长整数转成 number。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { ListNode } from '../shared.js'

export function addTwoNumbers(l1: ListNode | null, l2: ListNode | null): ListNode | null {
  const dummy = new ListNode()
  let tail = dummy
  let carry = 0
  // 最后一个进位也是待处理的一位
  while (l1 !== null || l2 !== null || carry !== 0) {
    const sum = (l1?.val ?? 0) + (l2?.val ?? 0) + carry
    tail.next = new ListNode(sum % 10)
    tail = tail.next
    carry = Math.floor(sum / 10)
    l1 = l1?.next ?? null
    l2 = l2?.next ?? null
  }
  return dummy.next
}
```

## 复杂度与边界

- 设最长输入长度为 n，时间 **O(n)**，额外工作空间 **O(1)**，新结果占 **O(n)** 输出空间，无递归。
- 输入完全不修改。
- 官方保证非空；本地若两边都传 null，会返回 null，这不是用来替代整数零的题面表示。
