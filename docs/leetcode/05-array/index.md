# 普通数组基础

## 数组结构与问题分类

数组提供按下标访问的能力，但题目可能要求最大连续和、区间合并、位置重排、乘积组合或寻找缺失值。共同学习点是识别“什么信息值得保留”和“写入是否会破坏未来读取”，不能用一个遍历模板覆盖全部。

先读[入门基础](/leetcode/00-intro/)。TS 中数字数组传递的是引用，修改元素影响调用者，重新赋值局部参数只更换局部引用。是否允许修改输入，需要在写方案前确认，本章每题会明确实际行为。

## 区分位置 数值 与已完成区域

位置 i 描述元素放在哪里，nums[i] 描述它是什么。缺失正数题可以人为规定数字 v 应放在位置 v - 1，于是数组被借作存在记录；轮转数组则按位置映射改变布局，数值本身不决定目标位置。前者有值域条件，后者有位置规则，两者不能混为“都交换一下”。

原地覆盖最危险的是写入尚未读取的位置。安全方案可能借助临时值交换，可能选择从后往前，也可能拆成可逆的反转。画出交换前后的数组并标记后续仍需读取的旧值，可以检查写入是否造成覆盖。

## 从所有候选到充分状态

最大子数组和若直接保留所有起点，需要平方级枚举。但当右端确定时，所有旧候选都增加同一个数，大小次序不变，因此只需保留前一右端的最大和。这里的“充分”指丢掉其他信息仍能做正确的下一步决定。

状态必须用一句话定义。例如“必须以当前位置结尾的最大和”与“目前见过的最大和”不同，前者用来继续延伸，后者用来回答结果。遇到负数时两者可能明显不同，不能因为都叫最大就共用一个变量。

## 前后缀 复用共同一段的计算

对每个位置求排除自身的乘积，所需元素恰好分为左段和右段。左乘积可正向累积，右乘积可反向累积，空段用一而不是零，因为一是乘法不改变结果的单位值。

前缀是否包含当前位置，要在定义里明确。包含时读取与更新顺序不同；不包含时通常先使用历史值，再把当前数纳入。最大值、乘积、和都可能采用前后缀，但只有具体合并规则成立时才能这样拆解。

## 排序建立可处理的顺序

合并区间按左端排序后，未来区间不会突然回到更左处，已经与后段分开的旧段可以确定下来。排序建立了可安全完成一次扫描的处理顺序。

默认 sort 把值按字符串比较，数字必须提供比较器。二维数组中仅复制外层仍共享内层区间，如果合并时会改终点，应连内层一并复制，或者明确允许输入变化。本章合并区间实现选择复制，以便保持调用者数据。

## 从约束推导候选范围

要求常数空间看似限制，但缺失正数中长度 n 同时限定答案最多 n + 1，真正需要记录的只有 n 个候选。忽略超出范围的数字不是随意丢数据，而是已证明它们无法改变更小缺失值。

学习时先列清非空要求、是否有负数、是否允许重复、是否禁止除法、是否允许原地修改。约束不只是写测试时检查的边角，它经常直接决定能不能使用某种方案。
