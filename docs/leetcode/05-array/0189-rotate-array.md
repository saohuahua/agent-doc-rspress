# 0189 轮转数组

阅读前提：[本章基础](/leetcode/05-array/)。[官方题目](https://leetcode.cn/problems/rotate-array/)。

## 题目

:::info 题面

**难度**：中等

把数组整体向右移动 k 次，超出右端的元素绕到左端，直接修改原数组。例如 [1,2,3,4,5,6,7] 右移三次得到 [5,6,7,1,2,3,4]。这里不是排序，也不是把某几个值交换，所有元素的相对环形顺序保持不变。

:::

### 官方示例

> **示例 1**
>
> 输入: nums = [1,2,3,4,5,6,7], k = 3
> 输出: [5,6,7,1,2,3,4]

> **示例 2**
>
> 输入：nums = [-1,-100,3,99], k = 2
> 输出：[3,99,-1,-100]

### 约束

- 1 <= nums.length <= 10^5
- -2^31 <= nums[i] <= 2^31 - 1
- 0 <= k <= 10^5

### 进阶要求

比较至少三种不同做法 并尝试只用 O(1) 额外空间原地轮转。

## 前期思路

### 朴素方法与复杂度

一次右移可以保存最后一项，让其他项依次右移一格，再把保存的值写到开头。重复 k 次是 O(nk)，k 很大时做了大量重复搬运。

观察移动 n 次会回到原状，因此先用 k 对 n 取余，只考虑剩余 steps 次。另一个直接方案是创建新数组，把旧下标 i 的值放到 (i + steps) % n，再复制回去，时间 O(n)，但需要 O(n) 空间。常数额外空间要求进一步排除新数组方案，因此需要保证原地重排不会覆盖尚未转移的数据。

### 从分段观察推导操作

右移三次的目标可写成两段：原前段 A 为 [1,2,3,4]，原后段 B 为 [5,6,7]，目标是 B 后接 A。每段内部顺序不能改变。直接把 B 写到前面会覆盖 A，所以先想一种原地、可逆、不会丢失值的操作：交换两端元素完成反转。

整体反转 AB，会得到反转的 B 接反转的 A，也就是 [7,6,5,4,3,2,1]。段的位置已经交换好了，只是各段内部倒序。再把前 steps 个元素反转恢复 B，把剩下元素反转恢复 A，就得到目标。

三次反转分别完成段位置交换和段内顺序恢复。用两段符号表示可以直接验证变换结果，无需逐项追踪整个数组。

### 算法推导与正确性

先规范化 steps。反转整个数组，然后反转闭区间 [0,steps - 1]，再反转 [steps,n - 1]。反转函数用左右指针交换，直到相遇。每次交换让两端进入最终反转位置，不触碰中间未处理值，因此不会丢失元素。

整体反转把 A、B 顺序颠倒，同时反转各自内部；两次局部反转各自恢复一次，所以最后严格得到 BA。这一论证同时解释了段边界为何是 steps，而不是 n - steps：整体反转后前面已经是原后段 B，它的长度就是 steps。

### 变式分析与错误反例

- 直接从左到右写 nums[(i + k) % n] = nums[i] 会覆盖未来要读的值，例如 [1,2,3] 右移一位，写入位置 1 后原来的 2 已丢失。必须用额外数组、循环置换或反转来管理覆盖。
- 若要求向左移 d 位，可以转换成向右移 (n - d % n) % n 位。若要求返回新数组而不修改原输入，额外数组映射方案反而更直观，不必为了常数空间强行破坏接口要求。

## 执行过程示例

| 阶段 | 数组 | 目的 |
| --- | --- | --- |
| 初始 | 1 2 3 4 5 6 7 | A 长四 B 长三 |
| 全部反转 | 7 6 5 4 3 2 1 | B 到前 A 到后 但内部均倒序 |
| 反转前三项 | 5 6 7 4 3 2 1 | 恢复 B 的原顺序 |
| 反转后四项 | 5 6 7 1 2 3 4 | 恢复 A 的原顺序 |

k 为零时第一段是空区间，反转函数自然不执行；整段会反转两次，最终保持不变，虽然也可提前返回减少操作。

## 解法复述与检查

- 为什么先取余？
- 目标的两段是什么？
- 整体反转后还错在哪里？

:::details 解法概述

先将移动次数归一化为 steps = k % n，将原数组分为前段 A 和最后 steps 项组成的后段 B，目标为 BA。整体反转使 B 移至前方、A 移至后方，同时反转两段内部顺序。再分别反转前 steps 项和剩余项，恢复段内顺序，从而得到目标排列。

:::

## TypeScript 实现

```ts
export function rotate(nums: number[], k: number): void {
  if (nums.length === 0) return
  const steps = k % nums.length
  const reverse = (left: number, right: number): void => {
    while (left < right) {
      const temporary = nums[left]
      nums[left++] = nums[right]
      nums[right--] = temporary
    }
  }
  // 整体反转交换两段位置再分别恢复段内顺序
  reverse(0, nums.length - 1)
  reverse(0, steps - 1)
  reverse(steps, nums.length - 1)
}
```

## 复杂度与边界

- 三次反转总交换次数 **O(n)**，时间 **O(n)**，辅助空间 **O(1)**，函数内辅助函数没有递归，不占增长的调用栈。
- 修改输入，返回 void。
- 单元素、k 为零、k 大于 n 都由取余和空区间自然处理。
- 题目 k 非负，不采用负数余数来表示左移。
