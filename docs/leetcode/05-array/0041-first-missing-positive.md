# 0041 缺失的第一个正数

阅读前提：[本章基础](/leetcode/05-array/)。[官方题目](https://leetcode.cn/problems/first-missing-positive/)。

## 题目

:::info 题面

**难度**：困难

从没有排序的整数数组中找缺失的最小正整数。正整数从一开始，零和负数都不作为答案候选。[3,4,-1,1] 缺少 2，因此返回 2。要求 O(n) 时间和 O(1) 额外空间，允许修改输入。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [1,2,0]
> 输出：3

> **示例 2**
>
> 输入：nums = [3,4,-1,1]
> 输出：2

> **示例 3**
>
> 输入：nums = [7,8,9,11,12]
> 输出：1

### 约束

- 1 <= nums.length <= 10^5
- -2^31 <= nums[i] <= 2^31 - 1

## 前期思路

### 朴素方法与复杂度

依次查询 1、2、3 是否出现，返回第一个未出现的正整数。每次扫描整数组，最坏 O(n²)。建一个 Set 可以把存在查询变快，时间 O(n)，但额外空间 O(n)，没有满足限制。

压缩存在记录所需空间，首先需要确定候选值的范围。长度为 n 的数组，最理想也只能覆盖 1 到 n，此时答案为 n + 1；如果这 n 个数没有全出现，最早缺失就在 1 到 n 中。因此答案一定落在 1 到 n + 1，远大于 n 的数无需保留存在信息。

### 把数组位置借来记录存在

数组恰好有 n 个槽位，可以让位置 0 负责数字 1，位置 1 负责数字 2，一般位置 value - 1 负责数字 value。若一个范围内的正数存在，就把它放回对应位置。最后从左到右查看，第一个没有放对的位置 i 就说明 i + 1 不存在。

但直接覆盖目标会丢失那里原有的值，所以要交换。被换回当前位置的值也可能需要归位，因此当前位置要用 while 持续处理，直到遇到无关值、已经归位，或者目标已有相同数字。

重复值是重要边界：[1,1] 中第二个 1 想去位置 0，但那里已经是 1，继续交换不会改变数组，会死循环。因此必须判断目标值与当前值不同，才执行交换。

### 算法推导与正确性

遍历每个位置，只要当前值在 1 到 n 之间且目标位置不是同值，就交换过去。每次成功交换至少让一个正数进入最终正确位置。正确位置以后不会被错误数字破坏，因为只有它对应的数字会被送来，而相同数字会触发停止条件。

因此成功交换总次数不超过 n，外层加内层不是平方。处理完之后，任何出现过的范围内正数均已出现在对应位置：处理该值时，要么成功交换到目标下标，要么确认目标位置已有同值。最后顺序检查，第一个错位对应最小缺失正数；全对就返回 n + 1。

### 变式分析与错误反例

- 只用 if 交换一次会漏处理换回值。例如本例位置 1 第一次换回 1 后若不继续，它就没被放到位置 0，最后可能错误认为 1 缺失。无限交换相同值则在 [1,1] 上导致无限循环。
- 若不允许修改输入，不能使用此实现；可以接受 O(n) 额外空间使用 Set，或者讨论其他时间空间折中。若问题改找缺失的所有一到 n 的数字，归位完成后收集所有错位对应数字，输出可能 O(n)，但归位思想依旧成立。

## 执行过程示例

输入 [3,4,-1,1]。

| 处理位置 | 动作与原因 | 数组 |
| --- | --- | --- |
| 0 | 3 属于位置 2 交换 | -1 4 3 1 |
| 0 | -1 不在有效范围 停止 | -1 4 3 1 |
| 1 | 4 属于位置 3 交换 | -1 1 3 4 |
| 1 | 换回的 1 属于位置 0 继续交换 | 1 -1 3 4 |
| 1 | -1 无关 停止 | 1 -1 3 4 |
| 2 与 3 | 已在正确位置 无需动作 | 1 -1 3 4 |
| 检查 | 位置 1 不是 2 | 返回 2 |

## 解法复述与检查

- 为什么只关心一到 n？
- 为什么交换后还要继续处理当前位置？
- 为什么重复值必须停止？

:::details 解法概述

长度为 n 的数组，其最小缺失正数至多为 n + 1，因此只需记录 1 到 n 是否出现。将有效正数 v 交换到下标 v - 1，继续处理换回的数；若目标位置已有相同值，则停止交换。完成后从左到右检查，第一个值不等于下标加一的位置对应最小缺失正数；全部匹配则返回 n + 1。

:::

## TypeScript 实现

```ts
export function firstMissingPositive(nums: number[]): number {
  const n = nums.length
  for (let i = 0; i < n; i++) {
    // 只把范围内且尚未归位的正数送回对应位置
    while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] !== nums[i]) {
      const target = nums[i] - 1
      const temporary = nums[target]
      nums[target] = nums[i]
      nums[i] = temporary
    }
  }
  for (let i = 0; i < n; i++) {
    if (nums[i] !== i + 1) return i + 1
  }
  return n + 1
}
```

## 复杂度与边界

- 每次有效交换固定一个此前未固定的位置，总时间 **O(n)**，辅助空间 **O(1)**，无递归。
- 输入会被重排，不保持原顺序。
- 全非正数返回 1，完整覆盖 1 到 n 返回 n + 1，重复值不会导致死循环。
- 先检查范围再索引，避免负值或大值访问错误位置。
- 题目整数在安全范围内。
