# 普通数组复习与迁移

## 练习一 最大和改成输出区间

[4,-1,2,-9,3] 除最大和外还要返回左右下标，添加哪些状态？

:::details 提示与解析

重新从当前数开始时更新当前段起点，历史最大变好时保存当前起点与右端。最佳是下标 0 到 2，和为 5。当前起点与最佳起点分开，否则后续重新开始会毁掉已记录答案。

:::

## 练习二 轮转但不能修改原数组

是否还应优先三次反转？

:::details 提示与解析

不必。创建等长结果，旧位置 i 写到 (i + k % n) % n，直接返回结果，时间 O(n)，输出空间 O(n)。接口已经要求新结果，清晰的映射更合适。若仍反转，需要先复制，已不再有整体常数空间优势。

:::

## 练习三 缺失正数但不允许改输入

原地把值送回对应下标的方法还能照搬吗？

:::details 提示与解析

不能，因为归位会改变顺序。使用 Set 记录存在并从一递增查找可做到 O(n) 时间、O(n) 空间；若还强制常数空间，需要重新讨论允许的时间代价，不能同时宣称保留输入和使用原实现。

:::

## 解法复述检查

每个变量保存哪段信息，丢弃其他信息的理由是什么，哪个写入可能覆盖尚未使用的旧值，以及哪些复杂度来自排序、复制和输出。状态变化应能够通过一次具体更新进行验证。
