# 0053 最大子数组和

阅读前提：[本章基础](/leetcode/05-array/)。[官方题目](https://leetcode.cn/problems/maximum-subarray/)。

## 题目

:::info 题面

**难度**：中等

在非空数组中选一段非空连续子数组，使其和最大，返回这个和。[-2,1,-3,4,-1,2,1,-5,4] 的答案是 6，对应 [4,-1,2,1]。不能跳过中间负数任意挑正数，也不能用空数组的零代替全负数的答案。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
> 输出：6

> **示例 2**
>
> 输入：nums = [1]
> 输出：1

> **示例 3**
>
> 输入：nums = [5,4,-1,7,8]
> 输出：23

### 约束

- 1 <= nums.length <= 10^5
- -10^4 <= nums[i] <= 10^4

### 进阶要求

在线性解法之外 再分析分治法如何解决同一问题。

## 前期思路

### 朴素方法与复杂度

固定一个起点，逐个加入右侧元素，每次比较累计和与历史最大。然后换起点重复。这样枚举全部 O(n²) 个区间，累加可增量进行，额外空间 O(1)。

减少候选起点需要依据整个区间的累计和，不能仅凭当前元素为负就切断区间。一个区间中间的负数可能连接更大的正数段，比如 [4,-1,2] 的最佳和是 5，不能因为 -1 就强行切断。

### 从按起点枚举改为按终点分类

考虑所有以当前数 x 结尾的连续区间。它们只有两种来源：只取 x，或者把 x 接到一个以前一位置结尾的非空区间后。由于给每个旧区间都加同一个 x，其中旧和最大的接上后仍然最大。因此无需保留所有旧起点，只需要旧终点的最大和。

把这个值叫 ending，明确含义是“必须以当前下标结尾的最佳和”，不是整个历史的最佳和。新 ending 等于 x 与旧 ending + x 中较大的一个。旧 ending 为负，接上它只会拖累当前数，重新从 x 开始更好；旧 ending 为正，保留它才有益。

这一步将完整候选集合压缩为一个足以决定后续转移的状态。理由来自所有候选增加同一项后大小关系不变，而不是因为题目里有“最大”就必然能这样做。

### 算法推导与正确性

以第一个位置结尾的非空区间只有第一项本身，因此 ending 与 best 均初始化为第一项。每到一个新位置，先算以它结尾的最好结果，再用它更新全局 best。任何非空连续区间都有唯一终点，分别求出每个终点下的最佳值，再取最大，就覆盖了全部候选。

初始化保证第一个终点正确；如果前一个终点的最佳和正确，接或不接的两种来源穷尽了新终点的所有区间，因此新值也正确。循环最后返回 best，不能返回 ending，因为全局答案不一定结束在最后一项。

### 变式分析与错误反例

- 错误做法把遇到的所有正数加起来，在 [2,-100,3] 得到 5，但两端不连续，正确答案是 3。把 best 初始化为零则会错误允许空区间。
- 若要返回区间位置，选择单独开始时更新临时起点，刷新 best 时保存临时起点和当前终点。若题目改成最大乘积，负数乘负数可能翻转大小关系，只存最大旧结果就不足，还需要最小旧结果。这里的加法保序性不能无条件迁移到乘法。
- 以当前位置作为结尾定义状态，可以对照[力扣官方题解](https://leetcode.cn/problems/maximum-subarray/solutions/228009/zui-da-zi-xu-he-by-leetcode-solution/)中的动态规划解释。本篇从朴素区间枚举先确定这个状态为什么足以连接前后计算。

## 执行过程示例

输入 [-2,1,-3,4,-1,2]。

| 当前数 | 接上旧段的和 | 单独开始的和 | ending 与原因 | best |
| --- | --- | --- | --- | --- |
| -2 | 初始 | -2 | -2 必须非空 | -2 |
| 1 | -1 | 1 | 1 舍弃负前缀 | 1 |
| -3 | -2 | -3 | -2 保留前面的正收益 | 1 |
| 4 | 2 | 4 | 4 重新开始 | 4 |
| -1 | 3 | -1 | 3 继续原段 | 4 |
| 2 | 5 | 2 | 5 继续原段 | 5 |

读到 -3 时 ending 虽然变负，best 仍是 1，两个状态的职责不能互相替代。

## 解法复述与检查

- 以某位置结尾的区间从哪里来？
- 为什么只保留一个旧和？
- 为什么初始化不能是零？

:::details 解法概述

按右端对候选区间分类。以当前数结尾的区间，要么只包含当前数，要么在以前一位置结尾的区间后追加当前数。所有旧区间加上同一个数后大小关系不变，因此只需保存前一终点的最大和。比较两种来源得到当前终点最大和，再维护所有终点中的历史最大值。

:::

## TypeScript 实现

```ts
export function maxSubArray(nums: number[]): number {
  // 当前值表示必须以当前位置结尾的最大连续和
  let ending = nums[0]
  let best = nums[0]
  for (let i = 1; i < nums.length; i++) {
    ending = Math.max(nums[i], ending + nums[i])
    best = Math.max(best, ending)
  }
  return best
}
```

## 复杂度与边界

- 每项只进行常数次加法比较，时间 **O(n)**，辅助空间 **O(1)**，无递归，不修改输入。
- 输入保证非空，直接读取第一项成立。
- 全负数返回其中最大单项，例如 [-3,-1] 返回 -1，而不是零。
- 题目整数及累计和在 number 安全整数范围内。
