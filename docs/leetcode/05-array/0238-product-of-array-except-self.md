# 0238 除了自身以外数组的乘积

阅读前提：[本章基础](/leetcode/05-array/)。[官方题目](https://leetcode.cn/problems/product-of-array-except-self/)。

## 题目

:::info 题面

**难度**：中等

返回一个等长数组，每项是原数组中除当前位置以外所有数的乘积。要求线性时间且不能使用除法。[1,2,3,4] 对应 [24,12,8,6]。数字允许零和负数，不能假设总乘积除以当前数总是可用。

:::

### 官方示例

> **示例 1**
>
> 输入: nums = [1,2,3,4]
> 输出: [24,12,8,6]

> **示例 2**
>
> 输入: nums = [-1,1,0,-3,3]
> 输出: [0,0,9,0,0]

### 约束

- 2 <= nums.length <= 10^5
- -30 <= nums[i] <= 30
- 输入 保证 数组 answer[i] 在 32 位 整数范围内

### 进阶要求

除返回的结果数组外 尝试只用 O(1) 额外空间。

## 前期思路

### 朴素方法与复杂度

计算第一项时跳过第一项，乘其他数；计算第二项时跳过第二项，又把大部分相同数字乘一遍。n 个答案各做 O(n) 次乘法，总 O(n²)。这个过程正确，但重复乘了大量共同前段与后段。

总乘积除以自身虽然看起来只需线性时间，却直接违反不用除法的要求，而且零会让除法无定义。因此应将所需元素分成当前位置左侧和右侧两部分，分别计算贡献。

### 把需要的元素分成两段

当前位置 i 不参与，那么其余元素恰好分为 i 左边全部元素和 i 右边全部元素，两段没有重叠也没有遗漏。答案就是左乘积乘右乘积。

相邻位置的左乘积只差一个新增元素，因此可从左到右滚动计算。设 prefix 是当前位置之前的乘积，先写入 result[i]，再乘上 nums[i]，使记录的乘积不包含当前位置。第零项左侧为空，空乘积定义为 1，因为乘一不会改变另一段的真实乘积。

右边同理，从右到左维护 suffix。先用 suffix 乘到已有 result[i] 上，再把当前数纳入 suffix。第二遍结束后，每个位置便同时含有左右两段贡献。

### 辅助空间压缩与正确性

最直观的版本可以各建一张左乘积表和右乘积表，但题目本来就需要返回结果数组。第一遍把左乘积直接放在结果位置，第二遍原地乘右贡献，就省去额外表。prefix 和 suffix 每次只需要当前滚动值，不必保存历史。

正确性可以按两遍分开理解：第一遍在位置 i 写入时，prefix 恰等于下标小于 i 的所有数乘积；第二遍处理 i 时，suffix 恰等于下标大于 i 的所有数乘积。两者相乘覆盖全部但排除 i，因此每项正确。

### 变式分析与错误反例

- 若把空乘积初始化为零，所有结果都会被乘成零。若先 prefix *= nums[i] 再写 result[i]，就把自身纳入，得到的不是题目要求。
- 如果操作改成除自身的和，同样可以分左右贡献，但也可以总和减自身，因为减法在零处不存在除法问题。若操作不满足可以合并两段结果的规则，就不能机械套用前后缀。这里乘法的结合律允许先分别求两段乘积，再合并得到全体乘积。

## 执行过程示例

nums 为 [1,2,3,4]。

| 第一遍位置 | 写入的左乘积 | 更新 prefix |
| --- | --- | --- |
| 0 | 1 | 1 |
| 1 | 1 | 2 |
| 2 | 2 | 6 |
| 3 | 6 | 24 |

第一遍结果为 [1,1,2,6]。

| 第二遍位置 | 当前右乘积 | 本项最终结果 | 更新 suffix |
| --- | --- | --- | --- |
| 3 | 1 | 6 | 4 |
| 2 | 4 | 8 | 12 |
| 1 | 12 | 12 | 24 |
| 0 | 24 | 24 | 24 |

## 解法复述与检查

- 排除当前位置后如何分段？
- 为什么先写结果再更新前缀？
- 边界空段为什么是 1？

:::details 解法概述

除当前位置外的元素恰好分为左侧和右侧两段，答案为两段乘积之积。第一遍正向把不包含自身的左乘积写入结果，第二遍反向将不包含自身的右乘积乘入对应位置。滚动乘积从 1 开始，每轮先使用已有乘积，再纳入当前元素。

:::

## TypeScript 实现

```ts
export function productExceptSelf(nums: number[]): number[] {
  const result = new Array<number>(nums.length)
  let prefix = 1
  for (let i = 0; i < nums.length; i++) {
    // 当前结果先保存左侧所有数的乘积
    result[i] = prefix
    prefix *= nums[i]
  }
  let suffix = 1
  for (let i = nums.length - 1; i >= 0; i--) {
    // 乘上右侧乘积后再把当前数纳入后缀
    result[i] *= suffix
    suffix *= nums[i]
  }
  return result
}
```

## 复杂度与边界

- 两次扫描时间 **O(n)**，除输出数组外辅助空间 **O(1)**，输出空间 **O(n)**，无递归，不修改输入。
- 题目保证相关前缀后缀及结果在限定整数范围，number 足够。
- 一个零时只有零位置可能有非零答案；两个零时全部为零，代码无需特殊分支。
- 负数符号自然由乘法处理。
