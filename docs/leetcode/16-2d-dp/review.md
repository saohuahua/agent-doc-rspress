# 多维状态复习

## 练习一 相同路线规则不同问题

在只能向右或向下移动的条件下，网格 [[1,9],[2,1]] 的路线数量与最小路径和分别是什么？

:::details 提示与解析

共有两条路线，最小路径和为 4。数量合并使用相加，代价合并则先取较小值，再加当前格的权重。即使移动方向相同，合并运算也取决于所求结果。

:::

## 练习二 空前缀边界

空串与 abc 的最长公共子序列长度和编辑距离为何不同？

:::details 提示与解析

空串没有可匹配字符，因此最长公共子序列长度为 0。空串变为 abc 需要三次插入，因此编辑距离为 3。初始化由子问题含义决定，不能统一填零。

:::

## 练习三 连续性改变

abc 与 ac 的最长公共子序列长度为 2。若要求公共子串，答案是否仍为 2？

:::details 提示与解析

不是。最长连续公共片段的长度为 1。不匹配时，以当前位置结尾的连续状态必须中断，不能继承允许跳过字符时的前缀最优值。

:::
