# 0064 最小路径和

相关基础：[本章基础](/leetcode/16-2d-dp/)。题目来源：[力扣 64](https://leetcode.cn/problems/minimum-path-sum/)。

## 题目

:::info 题面

**难度**：中等

非空矩形网格每格有非负数字，从左上走到右下，只能向右或向下，求沿途包含起终点的最小数字总和。返回代价，不是路线条数。与不同路径相比移动规则一样，但“比较候选的方式”已经改变，不能仍把上方和左方数量相加。

:::

### 官方示例

> **示例 1**
>
> 输入：grid = [[1,3,1],[1,5,1],[4,2,1]]
> 输出：7

> **示例 2**
>
> 输入：grid = [[1,2,3],[4,5,6]]
> 输出：12

### 约束

- m == grid.length
- n == grid[i].length
- 1 <= m, n <= 200
- 0 <= grid[i][j] <= 200

## 前期思路

### 朴素方法与复杂度

尝试所有向右或向下的路线，为每条路线累计代价，最后取最小。这样直观正确，却反复计算到同一格的许多路线。每步选择右侧和下侧权重较小的格子也不能保证最优，因为当前权重较小不代表后续总路径和较小，需要比较完整路径的累计代价。

### 状态定义与依赖

定义 cost[row][col] 为从起点到该格的最小路径和，并且包含该格数字。如果有两条路线到同一格，其中一条累计代价更大，那么接上相同后续路径后，其总代价仍更大；当前位置之后的合法动作不依赖来路，所以较大代价的历史路线不再有优势，只保留最小累计代价足够。

上述论证给出了合并同一格历史路线的依据。若额外规定某个格子的进入方向影响之后能否移动，那么仅保存坐标和代价可能不足，还要保留方向信息。

### 算法推导

到当前格只能从上方或左方来，因此选择 cost上 与 cost左 中较小者，再加当前格代价。相加当前格一次，是因为两个前驱状态都尚未包含它。两条来源是互斥候选，不能相加，否则会将两条不同路线的代价合并。

起点状态等于grid[0][0]。第一行只能从左来，所以累计左侧代价；第一列只能从上来，所以累计上方代价。实现也可以把不存在的来源看成Infinity，统一比较，但起点仍单独初始化，不能让两个无来源值都为Infinity。

按行递增、列递增计算，所有依赖先完成。每条到达当前格的路线有唯一最后一步，固定来源后使用它的最小代价不会限制当前移动，因此两个来源最小值加当前值正好是当前最优。逐格成立后目标状态就是全题答案。

### 变式分析与错误反例

- 若允许负数但仍只能右下移动，这个有向无环依赖仍成立，不会因为负数就自动失效。若允许上下左右且可能有负环，重复绕行可不断降低代价，需要另行定义路径限制与算法。若想返回具体路线，应记录每格选择哪个前驱，遇到相同代价还需约定任选或全部输出。

## 执行过程示例

网格 [[1,3,1],[1,5,1],[4,2,1]]，按同一位置写最小累计和。

| 行 | 各列最优值 | 来源解释 |
| --- | --- | --- |
| 0 | 1 4 5 | 起点1 随后只能向右累计 |
| 1 | 2 7 6 | 第一列向下 5选上4左2得7 末格选上5得6 |
| 2 | 6 8 7 | 第一列继续向下 中格取上7左6加2 末格取上6加1 |

答案7。贪心先看邻居会从起点选择向下的1，因为它小于右边3；但随后最佳代价也会是9，而先向右能得到7。这个例子直接显示眼前局部数字不是完整路径代价。

## 解法复述与检查

- 状态是否包含当前格？
- 为什么边界不能全部设1？
- 为什么较贵的到达历史可以丢弃？

:::details 算法概述

保存到每个格子且包含它的最小累计代价。两条路线到了同一格以后选择相同，所以只保留便宜的。当前格从上方或左方来，取两者代价较小值再加本格。起点用自身数字，边界沿唯一方向累计，最后读终点。

:::

## 复杂度与边界

- 时间 **O(mn)**，辅助空间 **O(mn)**，无递归栈，保留输入不修改，输出一个数。
- 单格返回自身，单行单列就是数字和，零值正常参与比较。
- 题目数值与网格规模下累计和精确。
- 若仅需最终代价，可利用当前格仅依赖上一行与本行左侧的性质进行滚动压缩。
- 本实现保留完整二维表，使每个坐标与状态一一对应。

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function minPathSum(grid: number[][]): number {
  const rows = grid.length
  const columns = grid[0].length
  const cost = Array.from({ length: rows }, () => new Array<number>(columns).fill(Infinity))
  cost[0][0] = grid[0][0]
  for (let row = 0; row < rows; row++) {
    for (let col = 0; col < columns; col++) {
      if (row === 0 && col === 0) continue
      // 不存在的来源保持不可达而不是假定免费进入
      const fromTop = row > 0 ? cost[row - 1][col] : Infinity
      const fromLeft = col > 0 ? cost[row][col - 1] : Infinity
      cost[row][col] = Math.min(fromTop, fromLeft) + grid[row][col]
    }
  }
  return cost[rows - 1][columns - 1]
}
```
