# 0005 最长回文子串

相关基础：[本章基础](/leetcode/16-2d-dp/)。题目来源：[力扣 5](https://leetcode.cn/problems/longest-palindromic-substring/)。

## 题目

:::info 题面

**难度**：中等

给非空字符串，返回其中最长的回文连续子串。回文从两端读相同，例如 aba 和 abba。必须连续，不能跳过字符。可能有多个同长度答案，返回任意一个即可。本题字符为英文字母和数字，代码按UTF-16码元索引在该范围内没有字符拆分问题。

:::

### 官方示例

> **示例 1**
>
> 输入：s = "babad"
> 输出："bab"

> **示例 2**
>
> 输入：s = "cbbd"
> 输出："bb"

### 约束

- 1 <= s.length <= 1000
- s 仅由数字和英文字母组成

## 前期思路

### 朴素方法与复杂度

枚举每个起点和终点，对区间从两端向内比较，发现不等就失败，全部对应字符相等就是回文。区间有O(n²)个，每次比较最多O(n)，总时间O(n³)。例子 ababa 中，验证整个串时会再次比较 aba，而这个内部片段在之前可能已经检查过。

### 优化依据

一段字符串是否回文，取决于两端是否相等，以及去掉两端以后内部是否回文。内部区间的答案可以被较大区间使用，因此定义 palindrome[left][right] 表示闭区间 left 到 right 是否回文。这里状态是布尔判定，另用两个变量保存见过的最长答案起点和长度。

不能只记每个位置结尾的最长回文长度来直接判断任意内段，因为外层需要的是特定左右端点的内部真值。需要两个边界共同描述子问题，才知道这次读取的究竟是哪一段。

### 算法推导

如果两端字符不同，无论内部怎样都不回文。如果相同，长度一和二直接成立：单字符本身对称，两个相同字符中间为空。长度至少三时，进一步读取 palindrome[left+1][right-1]。

依赖指向更短区间，所以按区间长度从一到n计算。固定长度后枚举起点，终点由 left+length-1 得到。这样内部短两位的区间必定已计算完成，不需要依赖复杂的倒序坐标技巧。命中回文且长度严格超过历史最好时更新答案。

所有长度一正确，长度二由两端比较正确。更长区间的两端条件与内部回文条件既必要又充分，因此逐长度推进得到全部区间真值。枚举了每一条连续子串并记录最大长度，自然不会漏掉最长结果。

### 变式分析与错误反例

- 若只求回文子串数量，每个真状态计一次即可，注意按位置不同的相同文本是不同子串。如果改为最长回文子序列，两端不等时还能丢弃某端继续比较，原来直接判false的规则失效。中心扩展也能在O(n²)时间与O(1)辅助空间解决本题，但本章主解保留区间依赖，理解后再比较空间权衡。

## 执行过程示例

输入 abba。

| 长度 | 被检查的区间 | 结果 |
| --- | --- | --- |
| 1 | a b b a | 全部为真 先记录首个a |
| 2 | ab bb ba | 只有bb为真 最好长度2 |
| 3 | abb bba | 两端都不同 为假 |
| 4 | abba | 两端a相等且内部bb已为真 最好长度4 |

奇数情况 aba 会读取中间单字符b的真值。偶数情况依靠长度二作为基础。因此只考虑单字符中心却不考虑双字符，会漏掉abba，这也是检查其他解法时的重要边界。

## 解法复述与检查

- 为什么两个边界都要进入状态？
- 为什么按长度顺序计算？
- 结果为什么还要保存起点？

:::details 算法概述

保存每个闭区间是否回文。两端不同直接失败，相同时长度不超过二直接成立，更长则查询去掉两端后的内部区间。按长度递增保证内部已经计算，发现更长回文就记录它的起点和长度，最后截取返回。

:::

## 复杂度与边界

- 状态数**O(n²)**，每个常数次比较，时间**O(n²)**，辅助空间**O(n²)**，没有递归栈，不修改输入。
- 最后截取答案需要**O(答案长度)**输出存储，已不改变时间上界。
- 单字符直接成功，相同长度只保留先找到的答案；题目允许任意最优答案，测试不能固定babad必须返回bab而排斥aba。

## 分层提示

:::details 提示一 观察方向

去掉回文两端相同字符后 剩下部分有什么性质

:::

:::details 提示二 需要的信息

保存每个左右端点区间的回文真值 不能只记一个全局最长值

:::

:::details 提示三 组织步骤

短区间先算 两端相等再看内部 更新最长起点与长度 最后截取

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function longestPalindrome(s: string): string {
  const n = s.length
  const palindrome = Array.from({ length: n }, () => new Array<boolean>(n).fill(false))
  let bestStart = 0
  let bestLength = 0
  // 内部区间更短所以按长度递增求解
  for (let length = 1; length <= n; length++) {
    for (let left = 0; left + length <= n; left++) {
      const right = left + length - 1
      palindrome[left][right] = s[left] === s[right] &&
        (length <= 2 || palindrome[left + 1][right - 1])
      if (palindrome[left][right] && length > bestLength) {
        bestStart = left
        bestLength = length
      }
    }
  }
  return s.slice(bestStart, bestStart + bestLength)
}
```
