# 0072 编辑距离

相关基础：[本章基础](/leetcode/16-2d-dp/)。题目来源：[力扣 72](https://leetcode.cn/problems/edit-distance/)。

## 题目

:::info 题面

**难度**：中等

给两个可以为空的小写字符串，允许对第一个串插入一个字符、删除一个字符或替换一个字符，每次操作代价一，求变成第二个串的最少次数。字符相同不需要操作，交换相邻字符不是一种单步操作。结果是最少次数，不要求返回操作脚本。

:::

### 官方示例

> **示例 1**
>
> 输入：word1 = "horse", word2 = "ros"
> 输出：3

> **示例 2**
>
> 输入：word1 = "intention", word2 = "execution"
> 输出：5

### 约束

- 0 <= word1.length, word2.length <= 500
- word1 和 word2 由小写英文字母组成

## 前期思路

### 朴素方法与复杂度

直观上可以尝试各种删改插直到相同，但分支很多，随意插入甚至会使字符串越来越长。更容易控制的方向是按两个前缀来对齐：当前原串前缀变为目标前缀需要多少操作。不同编辑路径会反复到达同一对前缀问题，因此保存其最优值有意义。

### 状态定义与转换方向

定义 cost[i][j] 为把word1前i个字符变成word2前j个字符的最少次数。i和j都是长度，所以当前末尾字符是i-1和j-1。零行表示从空串生成目标前缀，只能插入j次；零列表示把原前缀变空，只能删除i次。原前缀与目标前缀的方向决定删除和插入的依赖坐标。

前缀状态的核心价值是固定已经要处理的内容。后续追加字符不会要求知道先前用了哪条最优操作路径，只需要知道代价。所有操作代价非负且局部作用于对齐过程，最优子问题可以连接到最后一步。

### 算法推导

末尾相同时，可以直接保留这两个字符，把问题交给前i-1与前j-1，代价不增加。在单位编辑距离中存在这样的最优对齐：相同末尾匹配不会比专门删除插入或替换它们更贵，所以无需强制为相同字符增加一步。

末尾不同时，考虑最后的对齐动作。删除原串末尾，剩下原前i-1仍要变成目标前j，候选cost[i-1][j]+1。插入目标末尾，则原前i只需先变成目标前j-1，再补最后字符，候选cost[i][j-1]+1。替换原末尾为目标末尾，两个前缀同时缩短，候选cost[i-1][j-1]+1。三者取最小。

这三个候选不是同时执行的步骤，而是所有可能最后动作的类别。每种都能构造合法编辑过程，任何最优对齐最后也属于保留、删除、插入或替换之一，所以比较它们完整覆盖最优方案。按行列递增计算，三个依赖都在已完成位置。

### 变式分析与错误反例

- 若替换成本改为二、插入删除仍为一，候选各加的代价要分别调整，不能统一在min后加一。若允许相邻交换一次，ab到ba可为1，而原题至少2，需要新增状态转移；不能把这个规则默默算入。错误末尾相同也加一会把相同字符串误判需要编辑，零代价保留是必要动作。

## 执行过程示例

把ab变为ac，列为空、a、ac。

| 原前缀 | 空 | a | ac |
| --- | --- | --- | --- |
| 空 | 0 | 1 | 2 |
| a | 1 | 0 | 1 |
| ab | 2 | 1 | 1 |

最后一格b与c不同，删除候选为cost[1][2]+1=2，插入候选为cost[2][1]+1=2，替换候选为cost[1][1]+1=1，选替换。a到ac那格选择插入c，ab到a那格选择删除b，因此同一张小表也展示了三类动作的方向。

![编辑距离三个前缀依赖与操作含义](./assets/0072-prefix-dependencies.svg)

图中的箭头均从已知状态指向当前状态，表示读取关系。上方状态减少原前缀长度，左方状态减少目标前缀长度，左上状态同时减少两者。三个候选分别构造完整的编辑方案，当前格只保留最小代价，不把三种操作串联执行。

## 解法复述与检查

检查三个候选的语义：删除动作对应哪一个更短原前缀，插入动作对应哪一个更短目标前缀，替换动作为什么同时缩短两个前缀。

:::details 算法概述

保存原串每个前缀变成目标每个前缀的最少次数。空到非空只能插入，非空到空只能删除。末尾相同直接继承两个更短前缀的代价；不同时比较删除原末尾、补目标末尾、替换末尾三种候选，各加一次。按依赖顺序填表，最后返回完整两串的代价。

:::

## 复杂度与边界

- 时间**O(mn)**，辅助空间**O(mn)**，无递归栈，不修改输入。
- 任一字符串为空时由边界直接给答案，两者都空为0。
- 长度下标避免访问负字符位置。
- 结果不超过max(m,n)，number足够。
- 完整表方便回溯编辑脚本，若只需数量可考虑滚动行但要保存旧左上值。

## 分层提示

:::details 提示一 观察方向

先固定两个前缀 考虑它们最后字符相同还是不同

:::

:::details 提示二 需要的信息

两个前缀长度决定剩余任务 不需要保存所有编辑历史

:::

:::details 提示三 组织步骤

初始化空串行列 相同继承左上 不同比较上左左上分别对应的编辑动作

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function minDistance(word1: string, word2: string): number {
  const m = word1.length
  const n = word2.length
  const cost = Array.from({ length: m + 1 }, () => new Array<number>(n + 1).fill(0))
  // 空串边界分别对应连续删除与连续插入
  for (let i = 0; i <= m; i++) cost[i][0] = i
  for (let j = 0; j <= n; j++) cost[0][j] = j
  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (word1[i - 1] === word2[j - 1]) cost[i][j] = cost[i - 1][j - 1]
      else {
        // 三个候选分别删除原末尾插入目标末尾或替换末尾
        cost[i][j] = 1 + Math.min(cost[i - 1][j], cost[i][j - 1], cost[i - 1][j - 1])
      }
    }
  }
  return cost[m][n]
}
```
