# 1143 最长公共子序列

相关基础：[本章基础](/leetcode/16-2d-dp/)。题目来源：[力扣 1143](https://leetcode.cn/problems/longest-common-subsequence/)。

## 题目

:::info 题面

**难度**：中等

给两个非空小写英文字母字符串，求它们最长公共子序列的长度。子序列可以跳过字符，但必须保持相对顺序；同一公共序列必须在两个字符串里都能按顺序选出。abcde与ace的答案为3，而不是要求两串有一个连续的ace片段。

:::

### 官方示例

> **示例 1**
>
> 输入：text1 = "abcde", text2 = "ace"
> 输出：3

> **示例 2**
>
> 输入：text1 = "abc", text2 = "abc"
> 输出：3

> **示例 3**
>
> 输入：text1 = "abc", text2 = "def"
> 输出：0

### 约束

- 1 <= text1.length, text2.length <= 1000
- text1 和 text2 仅由小写英文字符组成。

## 前期思路

### 朴素方法与复杂度

可以枚举第一个串的所有子序列，然后逐个检查是否也是第二个串的子序列，挑最长。枚举已有指数数量。另一种递归想法是比较两串末尾，尝试保留或跳过一些字符；不同的跳过顺序会反复遇到同一对前缀，这提供了可以保存的子问题。

### 双前缀状态的必要性

只知道第一个串处理了多少字符不够，还需要知道第二个串允许匹配到哪里。定义 length[i][j] 为第一个串前i个字符与第二个串前j个字符的最长公共子序列长度。长度下标使零行零列表示某一边为空，答案自然为0。

该状态不要求包含两边最后字符。这里是在两个前缀内任选合法公共序列，所以可以跳过末尾。如果把“必须结尾”与“前缀最佳”混用，转移就会出现看起来相似但实际错误的加一。

### 算法推导

两边末尾字符相等，记为c时，可以在更短的两个前缀公共序列后同时接上c，得到 length[i-1][j-1]+1。该匹配不会损失最优性。对任意最优公共序列：如果它不以c结尾，那么它在两个原串中的最后一个匹配都位于末尾之前，还能追加两串末尾的c，得到更长序列，与最优矛盾。因此最优公共序列必以c结尾。

既然c是该公共序列的最后一项，就可以把它在两串中的最后一次匹配都移到各自末尾，前面的匹配顺序完全不受影响。删去这对末尾c后，剩余部分是两个更短前缀的公共子序列，长度至多为length[i-1][j-1]。这给出上界，而在更短前缀的最优序列后追加c又能达到该上界，所以公式确实成立。不能把序列中间的某个同字符任意移到末尾，因为那样可能越过后续匹配。

两边末尾字符不相等时，它们不能彼此匹配。任何公共序列至少要跳过其中一边的末尾，所以取 length[i-1][j] 和 length[i][j-1] 的较大值。不能两者相加，因为它们是两种完整候选，可能包含大量相同匹配；相加会重复计算。

按i从1到m、j从1到n计算，左上、上、左三个依赖都已完成。第一行第一列的零处理空前缀。最终读取两个完整串对应的状态，不是取任意一行的累计和。

### 变式分析与错误反例

- 若要求最长公共子串，末尾不等时连续性断掉，结尾长度要归零，不能继承左或上。若要求返回具体公共子序列，可以从表右下沿转移来源回走，相等匹配收集字符；并列时任选或按额外规则选择。错误只比较字符集合会把ab与ba算成2，但保持顺序的答案只有1。

## 执行过程示例

第一个串abc，第二个串ac，表中每行是一个前缀，列依次为空、a、ac。

| 第一串前缀 | 空 | a | ac |
| --- | --- | --- | --- |
| 空 | 0 | 0 | 0 |
| a | 0 | 1 | 1 |
| ab | 0 | 1 | 1 |
| abc | 0 | 1 | 2 |

ab与ac的末尾b和c不等，所以继承去掉其中一个末尾后的较大值1。abc与ac末尾同为c，接上前缀ab与a的最佳1，得到2。跳过b保留ac，体现子序列不要求连续。

## 解法复述与检查

- 状态下标是字符位置还是前缀长度？
- 末尾不等时为何取最大？

:::details 算法概述

保存两串各取一个前缀时的最长公共子序列长度。任一前缀为空就是零。末尾相等时用更短两前缀答案加一，末尾不同则至少跳过一边，取两种跳过结果的较大值。按前缀长度递增填表，最后读完整两串状态。

:::

## 复杂度与边界

- 时间**O(mn)**，辅助空间**O(mn)**，无递归栈，不修改输入，输出一个长度。
- 全不相同为0，两串相同为串长，重复字符依靠位置顺序处理，不用去重。
- 可滚动压缩但需保留旧左上值，基础主解先保留完整表。
- 字符采用题目小写英文字母前提。

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function longestCommonSubsequence(text1: string, text2: string): number {
  const m = text1.length
  const n = text2.length
  // 零行零列表示其中一边为空前缀
  const length = Array.from({ length: m + 1 }, () => new Array<number>(n + 1).fill(0))
  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (text1[i - 1] === text2[j - 1]) length[i][j] = length[i - 1][j - 1] + 1
      // 末尾不同只能选择跳过一边而不能把两种方案相加
      else length[i][j] = Math.max(length[i - 1][j], length[i][j - 1])
    }
  }
  return length[m][n]
}
```
