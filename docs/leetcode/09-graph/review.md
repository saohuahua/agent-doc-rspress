# 图论复习与迁移

## 一 相邻规则变化

若岛屿允许斜对角连通 应该怎样调整

:::details 提示与解析

先改变边的定义 把四个方向扩为八个方向 访问标记和每次搜索增加一个分量的逻辑不变 例如对角两个陆地原来是两岛 现在是一岛

:::

## 二 时间代价变化

若感染某些格子需要两分钟 普通分层队列还保证最早时间吗

:::details 提示与解析

不保证 原方案依赖每条传播边恰好一分钟 代价不等时层数不等于时间 应按当前最小累计到达时间扩展 例如使用最短路优先队列

:::

## 三 前缀和单词

插入apple后 查询app和以app为前缀是否相同

:::details 提示与解析

不同 app路径存在 所以前缀查询为真 但app节点没有单词结束标记 完整查询为假 若后续插入app只需在原路径末尾加标记 不必再造整条路径

:::
