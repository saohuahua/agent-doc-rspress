# 堆复习与迁移

## 一 保留最小的k个

将保留最大的 k 个元素改为保留最小的 k 个元素，应使用哪种堆？

:::details 提示与解析

需要淘汰当前候选中最大的元素，因此使用最大堆。新值入堆后，若元素数量超过 k，就移除最大者。堆方向由淘汰规则决定。

:::

## 二 相同优先级

频次相同时，额外要求优先选择数值较小的元素，比较规则应如何变化？

:::details 提示与解析

需要定义完整比较顺序：频次为第一优先级，数值为第二优先级。若堆顶负责淘汰，它应保存完整规则下最差的候选；仅比较频次无法保证新的并列处理规则。

:::

## 三 滚动中位数

数据流还需要删除最早加入的元素，当前双堆实现能否直接使用？

:::details 提示与解析

不能直接使用。本实现只能高效删除堆顶，过期元素可能位于堆内部。需要支持索引删除，或使用延迟删除并维护有效大小，否则数量平衡和中位数读取都会受到过期元素影响。

:::

## 理解检查

说明堆顶代表最终查询所需的边界，还是需要淘汰的候选；给出比较方向的依据，并解释每次修改后如何恢复查询所需性质。
