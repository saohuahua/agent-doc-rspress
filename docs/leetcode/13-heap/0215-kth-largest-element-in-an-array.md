# 0215 数组中的第K个最大元素

排名查询只需要确定目标位置所属的数值，不要求得到完整有序数组。本题还给定了有限整数值域，因此可以进一步考察频次是否足以表达排名。

相关基础：[本章基础](/leetcode/13-heap/)。[力扣原题](https://leetcode.cn/problems/kth-largest-element-in-an-array/)。

## 题目

:::info 题面

**难度**：中等

输入非空整数数组和合法k，返回降序排序后第k个位置的数。重复值各占一个排名，不是第k个不同值。官方要求O(n)时间，且明确元素在负10000到正10000之间。这个固定整数值域是下面主解的必要前提，不是额外猜测。

:::

### 官方示例

> **示例 1**
>
> 输入: [3,2,1,5,6,4], k = 2
> 输出: 5

> **示例 2**
>
> 输入: [3,2,3,1,2,4,5,5,6], k = 4
> 输出: 4

### 约束

- 1 <= k <= nums.length <= 10^5
- -10^4 <= nums[i] <= 10^4

## 前期思路

### 朴素方法与复杂度

复制数组按数值降序排序，再读取下标k减一，正确且容易实现，时间O(n log n)。堆可以进一步只保留最大的k项：新数入最小堆，超过k便淘汰候选中的最小值，最后堆顶就是第k大。这里堆顶代表入选候选中的最小值，而非全局最小值。

### 优化依据

候选堆避免了完整排序，但时间O(n log(k+1))，仍不满足对全部合法k的线性要求。若只需要一个排名，其实不需要保存每个重复元素的位置。知道每个数值出现几次，就知道它们分别占据降序排列中的多少个位置。题目值域只有固定的20001个整数，可以直接用下标表达大小顺序。

### 算法推导

创建长度20001的计数数组counts，把值x映射到下标x加10000。偏移量只用于把负值平移成合法非负下标，不改变大小关系。扫描输入，每出现一个值就把对应计数加一，重复值不能去重。

随后从最大下标向零扫描，相当于按数值从大到小看各个频次组。维护rank表示还要越过多少个位置才能遇到目标，初始为k。某个数值出现c次，就占据接下来c个连续排名。如果rank大于c，目标在更小值中，令rank减c继续；若rank不大于c，目标就在当前这一组，返回对应数值。代码先减再判断是否非正，是同一逻辑。

正确性依据如下：比当前值大的所有组已经依次跳过，rank恰好是目标在剩余降序序列里的位置。当前组内元素相同，所以无论目标落在该组第几个，返回值都一样。扫描覆盖所有可能数值，合法k保证必定在某组结束。

这题虽然被官方归档到堆分类，但分类不是解法限制。堆仍适合任意比较型数值或在线小k候选维护；固定值域计数则利用了本题更强的条件，满足这里的线性要求。有限值域计数的空间结论依赖给定范围，不能直接推广到任意整数选择问题。

### 变式分析与错误反例

- 若值域扩大到任意安全整数，不应创建覆盖整个范围的数组。可选容量k的最小堆得到O(n log(k+1))，或使用随机快速选择得到期望O(n)、最坏O(n²)，并明确各自保证。如果数据流中k会突然增大，只保留旧k项的堆也可能丢失必要历史。
- 错误反例：`[5,5,4]`求第2大，若先去重会返回4，正确是5。若用原始负数作为数组下标，JS会创建负名字属性而非预期的数组位置，计数扫描读不到它，因此必须做偏移映射。

## 执行过程示例

输入`[5,5,3,2]`，k为3。计数表只有5对应2次、3对应1次、2对应1次非零，其余桶跳过。

| 扫描数值 | 该值次数 | 进入时rank | 处理后含义 |
| --- | --- | --- | --- |
| 大于5的值 | 都为0 | 3 | 不占排名 仍需第3个 |
| 5 | 2 | 3 | 跳过前两个5 rank变1 |
| 4 | 0 | 1 | 不变 |
| 3 | 1 | 1 | rank减为0 目标在该组 |

返回3。若k为2，就会在5这一组结束，重复值各自占排名。

## 解法复述与检查

- 为何频次足以回答排名？
- 负数如何映射下标？
- rank每一步具体表示什么？
- 为何这个线性结论依赖固定值域？

:::details 算法概述

首先利用官方给定的有限整数范围建立计数表，记录每个值出现多少次。再按数值从大到小扫描，一个值出现几次就占据几个排名，用剩余排名k减掉整组次数。当目标落进当前频次组，就返回这个数。统计需要n步，扫描固定20001个值，因此在本题固定值域下是线性。

:::

## TypeScript 实现

```ts
export function findKthLargest(nums: number[], k: number): number {
  const minimum = -10000
  const maximum = 10000
  const counts = Array<number>(maximum - minimum + 1).fill(0)
  // 平移下标使负数也能进入计数表 重复值保留全部次数
  for (const num of nums) counts[num - minimum]++
  let rank = k
  for (let index = counts.length - 1; index >= 0; index--) {
    rank -= counts[index]
    if (rank <= 0) return index + minimum
  }
  throw new Error('输入不符合题目的取值或排名约束')
}
```

## 复杂度与边界

- 记U为可取整数数量，时间**O(n+U)**，辅助空间**O(U)**，不修改输入。
- 本题U固定为20001，不随n增长，因此按官方固定值域分析为**O(n)**时间、**O(1)**相对n的空间；实际仍分配20001项，不能说没有额外内存。
- 若值域也作为输入规模增长，必须保留**O(n+U)**与**O(U)**表述。
- k等于1取最大，等于n取最小。
