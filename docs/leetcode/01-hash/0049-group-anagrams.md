# 0049 字母异位词分组

阅读前提：[本章基础](/leetcode/01-hash/)。[官方题目](https://leetcode.cn/problems/group-anagrams/)。

## 题目

:::info 题面

**难度**：中等

输入是一组只含小写英文字母的字符串。把能通过重新排列字母互相得到的单词放在一组，返回各组，不要求固定组顺序或组内顺序。例如 eat 和 tea 属于一组，eat 和 tan 不属于一组。这里允许空字符串，也可能多次输入同一单词，重复输入仍要保留。

:::

### 官方示例

> **示例 1**
>
> 输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
> 输出: [["bat"],["nat","tan"],["ate","eat","tea"]]

> **示例 2**
>
> 输入: strs = [""]
> 输出: [[""]]

> **示例 3**
>
> 输入: strs = ["a"]
> 输出: [["a"]]

### 约束

- 1 <= strs.length <= 10^4
- 0 <= strs[i].length <= 100
- strs[i] 仅包含小写字母

## 前期思路

### 朴素方法与复杂度

拿到新单词后，可以逐组寻找一个代表单词，检查两者字母是否相同。如果属于某组就放进去，否则开一组。判断不能只看有哪些字母，abb 与 aab 都有 a 和 b，却无法重排成彼此，因为次数不同。

设有 n 个单词，最大长度为 m。若每次比较先统计字母，最坏每个单词要对照前面许多组，比较次数 O(n²)，每次又花 O(m)。该方法的主要重复工作是新单词反复与各组逐一比较。

### 从重复比较到共同标识

优化目标是为同组单词生成同一个标识，并通过标识直接定位组。这要求两点：同组不能算出不同标识，不同组不能意外算出相同标识。只保存字母集合会违反第二点，刚才的 abb 和 aab 就会撞在一起。

先尝试把字母排好序。eat 和 tea 都变成 aet；abb 仍是 abb，aab 仍是 aab。排序保留每个字母的次数，同时抹去了本来不重要的位置。因此两个字符串的排序结果相同，当且仅当它们的字母及次数相同。这个排序字符串称为规范化标识，也就是把多种等价写法转换成统一表示。

据此建立查询表：键是排序字符串，值是这一组原始单词数组。键负责比较身份，值保留用户要求的结果。分组结果应保存原单词；若保存排序键，会丢失原始拼写。

### 算法推导与正确性

逐个读取原单词，复制字符并排序得到键。查询键对应的组，不存在就新建，存在就追加。每个输入只加入一次。相同键代表同样的字母计数，因此不会把不同组混在一起；同组必有相同键，因此也不会拆散一组。读完所有单词就结束。

这里 sort 作用在 split 产生的新数组上，原字符串不变。前端常见的按类别分组，同样需要保证类别标识准确表达等价关系，Map 只负责按键查询。

### 变式分析与错误反例

- 固定小写字母表也可以用 26 个计数生成键，时间可降为 O(nm)。但拼接时必须有分隔，例如计数 1 和 11 与 11 和 1 不能都直接拼成 111。若只问有多少组，表里无需保存完整单词数组，使用键集合即可。若忽略大小写，应在生成键前统一大小写，但结果仍可保留原词。
- 错误方法按单词长度分组，会把 ab 和 cd 放到一起；长度相同只提供必要条件，不是充分条件。

## 执行过程示例

| 原单词 | 排序键 | 操作原因 | 处理后的分组 |
| --- | --- | --- | --- |
| eat | aet | 首次出现此键 | eat |
| tea | aet | 同键表示同种字母构成 | eat tea |
| tan | ant | 新键需要新组 | eat tea 与 tan |
| ate | aet | 回到已有组 | eat tea ate 与 tan |

空词的键是空字符串，它也是有效 Map 键。两个空词会归在一组，不应该被过滤掉。

## 解法复述与检查

- 为什么只记录字母集合不够？
- 排序为何能同时避免拆组和混组？
- 结果中为什么保留原单词？

:::details 解法概述

为每个单词生成排序后的字符序列，以此作为分组键。相同字母及次数产生相同键，不同字母组成产生不同键，因此可以直接定位分组，避免逐组比较。将原单词追加到键对应的数组，处理完所有输入后返回各组；排序键用于判等，原单词用于保留结果内容。

:::

## TypeScript 实现

```ts
export function groupAnagrams(strs: string[]): string[][] {
  // 用排序后的字母序列标识同一类单词
  const groups = new Map<string, string[]>()
  for (const word of strs) {
    const key = word.split('').sort().join('') // [!code highlight]
    const group = groups.get(key)
    if (group === undefined) groups.set(key, [word]) // [!code highlight]
    else group.push(word)
  }
  return [...groups.values()]
}
```

## 复杂度与边界

- 按比较排序 **O(m log m)** 和哈希表平均常数查询模型，总时间 **O(nm log m)**，更精确是各单词排序成本之和。
- 分组键最多占 **O(nm)** 字符，当前拆分排序的数组占 **O(m)**，分组结果存 **O(n)** 个原字符串引用；不修改输入，无递归代码。
- JS 排序内部辅助空间由引擎决定，一般也应计入临时排序开销，不能承诺整个算法常数空间。
- 小写英语使按默认字符顺序排序可以形成稳定一致的标识。
- 若输入是一般 Unicode，要先确定按码点还是字素比较，不能把 split 的码元直接当用户看到的字符。
