# 0128 最长连续序列

阅读前提：[本章基础](/leetcode/01-hash/)。[官方题目](https://leetcode.cn/problems/longest-consecutive-sequence/)。

## 题目

:::info 题面

**难度**：中等

输入没有排序，输出数值连续的一串数字的最大长度。连续指整数值逐一增加一，不要求这些数在原数组中相邻。例如 [100,4,200,1,3,2] 中 1、2、3、4 组成长度 4 的序列。重复出现的 2 不会把长度增加到 5。题目要求线性时间，输入可以为空。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [100,4,200,1,3,2]
> 输出：4

> **示例 2**
>
> 输入：nums = [0,3,7,2,5,8,4,6,0,1]
> 输出：9

> **示例 3**
>
> 输入：nums = [1,0,1,2]
> 输出：3

### 约束

- 0 <= nums.length <= 10^5
- -10^9 <= nums[i] <= 10^9

## 前期思路

### 朴素方法与复杂度

最容易想到先排序，再数相邻数值相差一的最长段。注意相等时应该略过，差大于一才重新开始。这个方案思路正确，但排序通常要 O(n log n)，没有达到题目希望的 O(n)。

另一种直接方法是从每个数出发找下一个整数：看到 1 就找 2、3、4，看到 2 又找 3、4。如果每次在原数组线性找数字，成本更高。即使先用集合让查询变快，连续序列 [1,2,3,4] 仍会被从四个起点反复扫描，最坏 O(n²)。

### 优化依据

真正重复的是同一条连续链的后半部分。1 已经向后走完整条链，2 再走就没有价值。如何知道一个数是不是该启动扫描？观察链的起点：1 的前一个整数 0 不在集合里，而 2、3、4 的前一个数都存在。

因此只允许没有前驱的数启动向后计数。有前驱不意味着它没有用，而是它会被更早的起点统一处理。Set 提供快速存在查询，跳过非起点则消除重复扫描；两者共同构成线性时间算法。

### 算法推导与正确性

本题只关心某个整数存在与否，不需要原位置，所以用 Set 去重保存所有数。遍历集合而非原数组，避免同一个起点因重复输入多次启动扫描。若 value - 1 存在，跳过；否则不断检查 current + 1，直到缺失。长度为终点减起点再加一。

完整性依据如下：每个有限连续整数段一定有最小值，它没有前驱，因此会被启动扫描。其余数都有前驱，不另起扫描。不同连续段不相交，所以每个唯一数字只在某次向后扫描中被经过一次。外层看似套了 while，总工作量仍是唯一数字数量的常数倍。

扫描顺序无需有序。即使先遇到 4，只要发现 3 存在就跳过；稍后遇到 1 才完整计数。程序不是依赖遍历顺序，而是依赖集合已经包含全部输入。

### 变式分析与错误反例

- [1,1,1,2,3,4] 如果遍历原数组，三个 1 都会触发完整向后扫描。把起点重复 n 次，再接长连续段，可能退化为平方时间；这说明去重不仅影响答案，还影响复杂度。
- 若要求返回具体最长段，只需在刷新最佳长度时保留起点，最终生成起点到终点的数字，输出空间随长度增长。若要求原数组中连续位置的递增段，则题意已改变，不能随意重排或放进集合。例如 [1,3,2] 的整数集合连续，但原位置不是长度三的递增段。

| 100 | 99 不存在 | 扫到 100 后停止 独立一段 | 1 |
| 4 | 3 存在 | 不是起点 跳过 | 1 |

## 解法复述与检查

- 为什么使用集合还不够？
- 为什么只有没有前驱才能开始？
- 为什么应该遍历集合而不是原数组？

:::details 解法概述

先用集合去重并提供存在查询。对每个唯一数字，若前一个整数存在，则该数字不是连续段起点，无需重新扫描；否则向后逐一查找连续整数。每个连续段只由最小值启动一次扫描，统计各段长度的最大值即可。

:::

## TypeScript 实现

```ts
export function longestConsecutive(nums: number[]): number {
  const values = new Set(nums)
  let best = 0
  for (const value of values) {
    // 有前驱的数字留给序列起点统一处理
    if (values.has(value - 1)) continue // [!code highlight]
    let current = value
    while (values.has(current + 1)) current++
    best = Math.max(best, current - value + 1)
  }
  return best
}
```

## 复杂度与边界

- 在常见哈希表平均常数查询假设下，建集合 **O(n)**，每个唯一数字最多参与一次前驱判断和一次段扫描，总时间 **O(n)**，额外空间 **O(n)**。
- 不修改数组，无递归，输出常数空间。
- 空数组返回 0，全部重复数字返回 1，负整数同样适用。
- 题目整数范围使加一减一在 JS 安全整数范围内。
