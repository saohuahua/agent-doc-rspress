# 0020 有效的括号

括号合法性同时要求类型匹配和嵌套顺序正确。左右数量相等只是必要条件，右括号还必须匹配最近尚未闭合的左括号。

相关基础：[本章基础](/leetcode/12-stack/)。[力扣原题](https://leetcode.cn/problems/valid-parentheses/)。

## 题目

:::info 题面

**难度**：简单

字符串只由三类左右括号组成。每个右括号必须由同类型的左括号匹配，而且闭合顺序要符合嵌套。返回布尔值，不要求修改字符串或给出匹配位置。`([)]` 数量匹配但顺序错误。

:::

### 官方示例

> **示例 1**
>
> 输入：s = "()"
> 输出：true

> **示例 2**
>
> 输入：s = "()[]{}"
> 输出：true

> **示例 3**
>
> 输入：s = "(]"
> 输出：false

> **示例 4**
>
> 输入：s = "([])"
> 输出：true

> **示例 5**
>
> 输入：s = "([)]"
> 输出：false

### 约束

- 1 <= s.length <= 10^4
- s 仅由括号 '()[]{}' 组成

## 前期思路

### 朴素方法与复杂度

可以反复删除相邻的正确括号对，直到不能删除。若最终为空就有效，否则无效。合法括号的最内层一定有相邻对，所以这个过程有依据。不过重复扫描和重建字符串最坏需要O(n²)时间，例如很多层嵌套每轮只能去掉中间一对。

### 优化依据

删除内层之后，真正需要记住的是外层尚未闭合的左括号。没有必要每次重新扫描前面整段。遇到一个右括号，它只能匹配最近还没闭合的左括号；如果越过最近者去找更早的，就会让括号交叉，违反嵌套。

### 算法推导

从左向右读。看到左括号，保存它，等待后续闭合。看到右括号，先检查是否还有等待的左括号；没有就失败。有则检查最近一个的类型，必须与当前右括号匹配，成功后移除该左括号。

最近加入的先取出，正好是栈的规则。循环开始时栈从底到顶保存前面尚未闭合的左括号，顶项就是当前最内层。合法闭合只删除顶项，其他外层仍保留；不匹配时不存在其他合法补救，因为后续字符无法改变已经发生的交叉或提前闭合。

读完还要检查栈为空。过程中从未发生错误只说明所有已出现的右括号合法，并不说明左括号都有对应右括号。每轮处理一个字符，必定结束；合法嵌套的每个右括号都会匹配顶项，因此也不会误拒合法字符串。

### 变式分析与错误反例

- 若要求返回每个括号的匹配下标，栈中改存左括号下标，通过原字符串判断类型，弹出时记录下标对即可。嵌套规则没变，输出增加了位置信息需求。
- 错误反例：仅比较三类左右数量时，`([)]`会错误通过；仅检查扫描途中是否成功匹配而不检查结束栈时，`((`也会错误通过。两处分别对应次序和完整性。

## 执行过程示例

用`([])`覆盖全部字符。

| 字符 | 栈变化 | 原因 |
| --- | --- | --- |
| ( | 空变成( | 外层尚未闭合 |
| [ | (变成([ | 新打开的内层优先闭合 |
| ] | ([变成( | 最近左括号类型匹配 |
| ) | (变成空 | 外层完成 |

读完栈空，返回true。

## 解法复述与检查

- 为什么只检查最近的左括号？
- 遇到右括号时栈空怎么办？
- 为什么最后还要判断空栈？

:::details 算法概述

从左向右保存尚未闭合的左括号。每个右括号必须匹配栈顶，因为栈顶是最内层。类型不符或没有左括号立即失败，匹配就弹出。读完必须没有遗留左括号，才返回有效。

:::

## TypeScript 实现

```ts
export function isValid(s: string): boolean {
  const stack: string[] = []
  const matches: Record<string, string> = { ')': '(', ']': '[', '}': '{' }
  for (const char of s) {
    if (char === '(' || char === '[' || char === '{') {
      stack.push(char)
    } else {
      // 最近尚未闭合的左括号必须先完成
      if (stack.pop() !== matches[char]) return false
    }
  }
  return stack.length === 0
}
```

## 复杂度与边界

- 时间**O(n)**，每个字符只处理一次；最坏全部为左括号，辅助空间**O(n)**。
- 不修改输入。
- 合法输入仅含六种括号，因此非左括号一定是三种右括号之一。
- 空串会返回true，这是自然扩展，官方主要输入非空。
