# 栈复习与迁移

## 一 匹配顺序

若字符串还包含普通字母 有效括号应怎样处理这些字符

:::details 提示与解析

先明确新题规则 若只检查括号可忽略普通字母 不能把所有非左括号都当成右括号 栈仍保存未闭合左括号 次序规则不变

:::

## 二 相等温度

把更暖改为不低于当天温度 比较条件怎样变化

:::details 提示与解析

原来相等不能解决等待 新条件下相等就能结算 因此弹出条件从当前严格大于栈顶改为大于等于 例如70与70的等待从0变为1

:::

## 三 历史最小值

只维护一个全局最小值 能实现最小栈的pop吗

:::details 提示与解析

不能完整支持 恰好弹出当前最小元素后不知道剩余最小值 每层保存此前最小信息才能恢复 例如压入3和1后弹出1 需要找回3

:::

## 口述检查

说明每项为何入栈 它等待哪个条件 为什么只看栈顶以及何时能永久出栈 再解释总复杂度而非只数循环层数
