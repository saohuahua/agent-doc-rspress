# 0084 柱状图中最大的矩形

想找最大矩形，可以先固定它的高度，再问这个高度最多能向左右延伸多远。难点在于不用为每根柱子重新从头寻找边界。

相关基础：[本章基础](/leetcode/12-stack/)。[力扣原题](https://leetcode.cn/problems/largest-rectangle-in-histogram/)。

## 题目

:::info 题面

**难度**：困难

输入非负柱高数组，每根柱子宽度都是1。返回完全包含在柱状图内部的最大轴对齐矩形面积。矩形可以跨多根连续柱子，高度不能超过覆盖范围内最矮的一根。

:::

### 官方示例

> **示例 1**
>
> 输入：heights = [2,1,5,6,2,3]
> 输出：10

> **示例 2**
>
> 输入： heights = [2,4]
> 输出： 4

### 约束

- 1 <= heights.length <=10^5
- 0 <= heights[i] <= 10^4

## 前期思路

### 朴素方法与复杂度

固定每根柱子作为矩形最低高度，向左右扩展，直到遇到更矮的柱子。面积等于该高度乘以可覆盖宽度。最大矩形一定能选一根最低柱作为代表，所以这种枚举不会漏解；但每根柱子重新扫边界最坏O(n²)。

### 优化依据

从左到右走时，右边界尚未出现的柱子还在等待。新柱子如果更矮，就同时终止一批更高柱子的延伸。可以暂存这些未确定右边界的下标，等第一个更矮值出现时一次结算，不再让每根柱子独立扫描右方。

### 算法推导

栈中保存下标，底部先放负一作为左边界哨兵，真实柱高从底到顶不降。当前高度若小于栈顶高度，就弹出那根柱子，以它的高度计算矩形。当前下标i是右边第一个更矮位置，不包含在矩形中；弹出后新的栈顶left作为左侧边界，覆盖下标left+1到i-1，因此宽度为i-left-1。

相等高度暂时不弹出。这样新的左边界可能是等高而非严格更矮，当前结算的范围不一定是这根柱子的最大延伸，但仍是合法矩形。更早的等高柱子稍后弹出时会覆盖这整段，因此全局最优不会漏掉。本实现弹出后得到的左边界可能等高；正确性由更早等高柱子覆盖更宽候选来保证，不能将其解释为两侧边界均严格更矮。

遍历末尾再追加一个虚拟高度零，促使所有正高度待办结算；真实数组不改动。零高度不弹也不影响最大面积。对于任意最大矩形，取它最低高度中最靠左的相关待办代表，右侧更矮或结尾到来时会计算到至少同样宽的合法范围，所以最大值能被记录。

### 变式分析与错误反例

- 若柱宽不再全为1，下标差不等于真实宽度，需要保存宽度前缀和，用两侧边界之间的宽度总和计算面积。高度决定能否延伸的逻辑仍然成立，但面积公式必须调整。
- 错误反例：`[2,2]`最大面积为4，只计算单柱或把等高柱当作不可跨越障碍会返回2。另一错误是宽度写成i-left，`[2,1]`结算首柱时会包含当前更矮柱，得到不合法面积。

## 执行过程示例

用`[2,1,2]`走完整段，栈下标初始为负一。

| 当前位置与高度 | 弹出及面积 | 栈变化 | 最大面积 |
| --- | --- | --- | --- |
| 0与2 | 无 | -1 0 | 0 |
| 1与1 | 弹0 宽1 面积2 | -1 1 | 2 |
| 2与2 | 无 | -1 1 2 | 2 |
| 3与虚拟0 | 弹2 宽1 面积2 再弹1 宽3 面积3 | -1 | 3 |

较矮中柱反而支撑更宽矩形，不能只找最高柱。

## 解法复述与检查

- 固定高度后到底缺哪两个边界？
- 宽度为什么减一？
- 相等柱子不弹时为什么仍不会漏掉最大面积？

:::details 算法概述

使还没遇到右侧更矮柱子的下标留在不降栈里。新柱子更矮时，弹出较高柱子，用当前下标作右边界、新栈顶作左侧边界，按二者之间的宽度计算面积。相等柱子由较早位置最终覆盖更宽范围，末尾用虚拟零清算剩余正高度。每根柱子只进出一次。

:::

## TypeScript 实现

```ts
export function largestRectangleArea(heights: number[]): number {
  const stack = [-1]
  let best = 0
  for (let i = 0; i <= heights.length; i++) {
    // 末尾虚拟零用于结算仍在等待右边界的正高度
    const current = i === heights.length ? 0 : heights[i]
    while (stack.length > 1 && heights[stack[stack.length - 1]] > current) {
      const height = heights[stack.pop()!]
      const left = stack[stack.length - 1]
      best = Math.max(best, height * (i - left - 1))
    }
    if (i < heights.length) stack.push(i)
  }
  return best
}
```

## 复杂度与边界

- 每个下标入栈一次、出栈至多一次，时间**O(n)**，辅助空间**O(n)**。
- 不修改输入。
- 全零结果为0，单柱结果等于高度；面积在本题约束下可由number精确表示。
- 哨兵只有位置含义，不读取heights的负一下标。
