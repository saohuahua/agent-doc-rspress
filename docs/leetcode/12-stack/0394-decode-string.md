# 0394 字符串解码

嵌套编码的解码需要暂停外层处理并进入内层。保存外层前缀与重复次数，才能在内层完成后恢复外层计算。

相关基础：[本章基础](/leetcode/12-stack/)。[力扣原题](https://leetcode.cn/problems/decode-string/)。

## 题目

:::info 题面

**难度**：中等

输入是合法编码字符串，数字k后跟方括号，表示括号内字符串重复k次，编码可以嵌套。数字仅表示重复次数，普通内容不含作为正文的数字。输出完整解码字符串，例如`3[a2[c]]`得到accaccacc。

:::

### 官方示例

> **示例 1**
>
> 输入：s = "3[a]2[bc]"
> 输出："aaabcbc"

> **示例 2**
>
> 输入：s = "3[a2[c]]"
> 输出："accaccacc"

> **示例 3**
>
> 输入：s = "2[abc]3[cd]ef"
> 输出："abcabccdcdcdef"

> **示例 4**
>
> 输入：s = "abc3[cd]xyz"
> 输出："abccdcdcdxyz"

### 约束

- 1 <= s.length <= 30
- s 由小写英文字母、数字和方括号 '[]' 组成
- s 保证是一个 有效 的输入。
- s 中所有整数的取值范围为 [1, 300]

## 前期思路

### 朴素方法与复杂度

可以每次寻找最内层括号，把它展开为普通字符串，再从头寻找下一组。对示例先把2[c]变成cc，再把3[acc]展开。这样很直观，但不断定位括号、拼接大字符串和重新扫描已经处理过的前缀，会产生额外重复。

### 优化依据

真正需要暂停的是外层尚未完成的部分。遇到左括号时，已经积累的外层前缀与这一层的重复次数以后还要用，把它们保存起来，随后专心处理内层即可。内层结束后只需恢复最近一次暂停的上下文，不需要重新搜索整个字符串。

### 算法推导

维护current表示当前层已解码的内容，count表示正在读取的多位重复次数。遇数字时用旧count乘十再加本位，这样12不会被当成两次独立重复。遇普通字母追加到current。

遇左括号，把当前前缀与count一起压入栈，再把current清空、count归零，开始一个新的内层。遇右括号，当前层已经完整解码；弹出最近的上下文，把current按它的次数重复，再接到保存的前缀之后。

为什么弹最近的上下文？合法嵌套要求最后打开的括号先关闭。每个栈帧都保存进入该层前恰好缺失的两项信息，恢复不会混入更外层的重复次数。扫描完成时所有括号已经闭合，current就是整体结果。这里不能把数字和前缀设成一个全局共享值而不保存历史，否则嵌套会覆盖外层状态。

### 变式分析与错误反例

- 若只问解码后长度，不需要构造实际字符串，把current换成长度，普通字母加一，闭合时做前缀长度加重复次数乘内层长度即可。此时仍须考虑结果是否超过number安全整数范围。
- 错误反例：`12[a]`若每遇数字直接覆盖次数，会得到两个a而不是十二个。`2[a3[b]]`若只保留一个重复变量，内层3会覆盖外层2，无法正确恢复。

## 执行过程示例

手推`2[a2[b]]`。

| 输入阶段 | 栈中暂停的前缀与次数 | current | 原因 |
| --- | --- | --- | --- |
| 2[ | 空前缀与2 | 空 | 进入外层 |
| a | 同前 | a | 当前层字母 |
| 2[ | 再压入a与2 | 空 | 暂停a进入内层 |
| b] | 恢复外层记录 | abb | 内层b重复两次接到a后 |
| ] | 空栈 | abbabb | 外层重复两次 |

## 解法复述与检查

- 遇到左括号要保存什么？
- 多位数字怎么读取？
- 为什么先解内层再乘外层次数？

:::details 算法概述

从左向右读取当前层内容和重复次数。遇左括号就保存当前前缀与次数并开始新层，遇右括号就取回最近上下文，把已解码内层重复后接回前缀。数字逐位累积，所有层恢复完成后得到完整字符串。

:::

## TypeScript 实现

```ts
export function decodeString(s: string): string {
  const stack: Array<{ prefix: string; count: number }> = []
  let current = ''
  let count = 0
  for (const char of s) {
    if (char >= '0' && char <= '9') {
      count = count * 10 + Number(char)
    } else if (char === '[') {
      // 保存外层现场后才开始构建内层内容
      stack.push({ prefix: current, count })
      current = ''
      count = 0
    } else if (char === ']') {
      const frame = stack.pop()!
      current = frame.prefix + current.repeat(frame.count)
    } else {
      current += char
    }
  }
  return current
}
```

## 复杂度与边界

- 扫描字符本身**O(n)**，但解码输出长度L可能远大于输入，不能简单说整体**O(n)**。
- 若按平坦不可变字符串每次复制计费，总时间是扫描加所有拼接与重复产生的字符数，一个保守上界为**O(nL)**；常见输入接近**O(n+L)**，具体与引擎字符串实现有关。
- 逻辑存活数据和输出空间**O(n+L)**，嵌套栈**O(n)**。
- 不修改输入，合法编码保证弹栈存在对应帧。
