# 0042 接雨水

阅读前提：[本章基础](/leetcode/02-two-pointers/)。[官方题目](https://leetcode.cn/problems/trapping-rain-water/)。

## 题目

:::info 题面

**难度**：困难

每根柱子宽度为一，高度非负。下雨后凹陷能存多少水，返回所有位置水量之和。这次中间柱子占据空间，必须扣掉柱高；与只选两条边的盛水容器不同。[2,0,2] 中间能放两格水，左右两根柱子本身不放水。

:::

### 官方示例

> **示例 1**
>
> 输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
> 输出：6

> **示例 2**
>
> 输入：height = [4,2,0,3,2,5]
> 输出：9

### 约束

- n == height.length
- 1 <= n <= 2 * 10^4
- 0 <= height[i] <= 10^5

## 前期思路

### 朴素方法与复杂度：逐列计算

逐列计算可以将二维形状问题分解为独立的水深问题。单列水面的上限受两侧挡板共同限制。如果左边最高挡板是 4，右边最高挡板是 2，水面最多到 2，因为更高就会从右边流走。假如这列柱子高 1，就能存 1 格；柱子高 3，则这里根本没有正的储水空间。

因此可以对每个位置分别向左找最高柱、向右找最高柱，再计算较矮挡板减去当前高度并截到零。每列扫描 O(n)，共有 n 列，时间 O(n²)，额外空间 O(1)。这个办法已经把形状问题变成了清楚的逐列求和。

### 优化依据

计算位置 i 的左边最高值时，位置 i - 1 已经扫过前面所有柱子。重新从头找最高值没有必要。只要记住前一个位置的最高值，再与当前柱高比较，就得到新的最高值。右边完全对称，只是扫描方向反过来。

本实现将左右最大值定义为包含当前位置的区间最大值，这让两个最大值都至少等于当前柱高，于是最后相减天然非负，不必再额外截零。这是一个定义选择，包含与不包含都能做，但公式边界必须配套。

### 算法推导与正确性

leftMax[i] 定义为从 0 到 i 的最高柱，初值就是第一根柱。后续由前缀最高和当前高度取最大。rightMax[i] 定义为从 i 到末尾的最高柱，必须从右向左算，因为它依赖 i + 1 的答案。

每列水面等于两个最大值的较小值。如果水面更高，较低一侧没有足够高的挡板，会漏走；达到这个高度时左右各存在不低于它的挡板，可以容纳这列水。减去柱体占据部分就得到水深。各列宽度为一，分别加起来不重叠也不遗漏。

本题在题单中归入双指针分类。本篇采用前后预处理作为主解，显式保存每列的左右高度依据。常数空间的双指针解法可进一步利用两侧最大值的大小关系，提前结算水量。

### 变式分析与错误反例

- 只看相邻两根柱子会漏算 [3,0,0,3]：每个零的相邻最低高度为零，但远处边界能共同挡住三格水。只取一侧最高值也不行，[3,0,1] 中间只能放一格，左边高并不能阻止右侧漏水。
- 如果每列宽度不同，应把水深乘本列宽度再加总，挡水高度公式仍成立。若要 O(1) 空间，可同时维护左右已见最高值，每次结算较低最高值那侧，因为另一侧已经提供足够挡板；空间压缩成立的前提是该侧水量已可确定，而非仅改变遍历形式。

## 解法复述与检查

- 一列水位为什么取两侧最高值的较小值？
- 为什么右侧表倒着算？
- 为什么相减不会负数？

:::details 解法概述

按列计算水量，每列水面由左右最高挡板中的较低者限制。为避免逐列重新扫描，从左到右保存包含自身的前缀最高值，从右到左保存包含自身的后缀最高值。每列取两者较小值减去柱高，再累加得到总水量。

:::

## TypeScript 实现

```ts
export function trap(height: number[]): number {
  const n = height.length
  if (n === 0) return 0
  // 左右记录都包含当前位置
  const leftMax = new Array<number>(n)
  const rightMax = new Array<number>(n)
  leftMax[0] = height[0]
  for (let i = 1; i < n; i++) leftMax[i] = Math.max(leftMax[i - 1], height[i])
  rightMax[n - 1] = height[n - 1]
  for (let i = n - 2; i >= 0; i--) rightMax[i] = Math.max(rightMax[i + 1], height[i])
  let water = 0
  for (let i = 0; i < n; i++) {
    // 水面受两侧较低的最高挡板限制
    water += Math.min(leftMax[i], rightMax[i]) - height[i] // [!code highlight]
  }
  return water
}
```

## 复杂度与边界

- 三次线性扫描，时间 **O(n)**，两个长度 n 的数组使辅助空间 **O(n)**，无递归，输入不变，输出一个数。
- 单调递增或递减数组储水为零；全零同样为零。
- 数字范围内总量可由 number 精确表示。
- 空数组的提前返回是本地防御，不改变正常输入行为。
