# 双指针复习与迁移

## 练习一 稳定移除指定数值

把 [2,3,2,4] 中的 2 移除，返回有效长度并保持其余顺序。

:::details 提示与解析

读指针扫描全部，写指针只在值不等于 2 时写入。最终前两项为 3、4，返回 2；尾部内容无需定义。与移动零相比，筛选条件改变且不必补零。时间 O(n)，空间 O(1)。

:::

## 练习二 数组无序时能否按和大小移动

输入 [3,2,4]，目标 6，直接从两端开始是否有可靠排除规则？

:::details 提示与解析

没有。两端和 7 偏大后移右端会跳过真正答案 2 与 4。可以先排序并保留原下标，或用查询表找补数。左右移动依赖排序后的单调关系，不能仅因为任务是两数配对就套用。

:::

## 练习三 容器也要返回位置

除最大面积之外，还要输出对应两根线的原下标。

:::details 提示与解析

移动规则不变，刷新历史最大面积时同时保存当前 left、right。因为没有排序，指针下标就是原下标。若并列有指定取舍，应在更新条件中处理，并列结果的取舍与边界移动规则应分别处理。

:::

## 解法复述检查

能否解释指针职责、覆盖安全、排除依据、停止条件，以及当前值与历史答案的区别。检查要求包括独立推演三次指针移动，并说明每次移动的排除依据。
