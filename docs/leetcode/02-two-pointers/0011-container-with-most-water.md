# 0011 盛最多水的容器

阅读前提：[本章基础](/leetcode/02-two-pointers/)。[官方题目](https://leetcode.cn/problems/container-with-most-water/)。

## 题目

:::info 题面

**难度**：中等

数组每项代表一根竖线的高度，下标是横坐标。选两根竖线和横轴组成容器，水面不能高于较矮的边。返回最大容量，不需要返回位置。例如高度 [1,8,6,2,5,4,8,3,7] 选下标 1 和 8，宽 7，高受 7 限制，面积为 49。

与接雨水相比，本题只选两根边，中间竖线不作为容器底部障碍扣除体积。宽度是右下标减左下标，不是包含的柱子数量，不能额外加一。

:::

### 官方示例

> **示例 1**
>
> 输入：[1,8,6,2,5,4,8,3,7]
> 输出：49

> **示例 2**
>
> 输入：height = [1,1]
> 输出：1

### 约束

- n == height.length
- 2 <= n <= 10^5
- 0 <= height[i] <= 10^4

## 前期思路

### 朴素方法与复杂度

直接枚举每一对边，计算宽度乘较小高度，取最大值。n 根线共有 O(n²) 对，计算每对 O(1)，所以时间 O(n²)，额外空间 O(1)。这是可行基线，难点在于怎样少检查一些配对，又能保证不会漏掉更好的答案。

先看极端选择：把两根边放在最左和最右，宽度最大。接下来总要缩小范围，需要证明移除哪一端后，不会遗漏尚未检查的更优解。

### 从限制因素推导移动规则

假设左边高度为 2，右边高度为 8。当前容量被左边 2 限制。如果保留左边，换一根更靠左的右边，宽度必定减小，新的有效高度仍不可能超过 2，因此面积不可能超过刚算出的面积。

所以当前左边与范围内任何右边搭配，都不可能比当前配对更好。当前配对的面积已经记录，可以安全丢掉左边。相反，移动右边而保留左边，并不能解除矮边限制，还把宽度缩短了。只有换掉短边，才有机会用更高水位弥补宽度损失。

这不是保证每次移动面积都会增大，而是保证被丢弃的一批候选没有必要再看。算法允许当前面积下降，只要历史最大值仍保存着。

### 算法推导与正确性

两端开始，先计算本次面积更新最大值，再移动较短边。高度相等时任选一边都安全，因为保留任意一条当前边向内配对，高度仍受该值限制，宽度更小。循环直到两指针相遇，不再存在两根不同的线。

每次移动都排除了“以刚移走的短边为一端、另一端在当前范围内”的全部候选；它们不超过已经记录的配对。剩余候选仍在缩小后的区间中。不断排除后，所有可能优于记录的候选都被检查或证明不优，因此最终最大值正确。

### 变式分析与错误反例

- 错误规则移动较高边，在 [1,2,4,3] 中会一直保留最左的 1，错过面积 4。错误规则“每次只保留面积增大的移动”也没有依据，短期下降不代表剩余区间没有更好配对。
- 如果还要返回两根线的位置，在更新历史最大时一起保存左右下标即可。若允许倾斜容器或横坐标不等距，必须重新写面积定义：横坐标不等距但按递增顺序给出时，宽度改为坐标差，缩小宽度的证明仍成立；若横坐标无序，要先按坐标排序再讨论。

## 执行过程示例

输入 [1,2,4,3]，完整过程如下。

| 左右下标 | 高度 | 面积 | 移动与原因 | 历史最大 |
| --- | --- | --- | --- | --- |
| 0 和 3 | 1 和 3 | 3 乘 1 得 3 | 左边矮 保留它只会更窄 | 3 |
| 1 和 3 | 2 和 3 | 2 乘 2 得 4 | 左边矮 继续换左边 | 4 |
| 2 和 3 | 4 和 3 | 1 乘 3 得 3 | 右边矮 换右边后相遇 | 4 |

第三步比第二步差并不影响答案，历史最好不会被覆盖成当前值。

## 解法复述与检查

- 容量为什么受短边限制？
- 为什么移动短边安全？
- 能不能声称每次都向更优解移动？

:::details 解法概述

从最左和最右两条边开始，计算容量并更新历史最大值。固定较短边而把另一边向内移动，宽度减小且高度上限不会提高，因此这批配对均不优于当前配对。移除较短边后继续计算，直到两个位置相遇。移动依据是安全排除候选，并不保证当前容量每次增加。

:::

## TypeScript 实现

```ts
export function maxArea(height: number[]): number {
  let left = 0
  let right = height.length - 1
  let best = 0
  while (left < right) {
    const area = (right - left) * Math.min(height[left], height[right])
    best = Math.max(best, area)
    // 较短边保留时缩小宽度不可能超过本次面积
    if (height[left] <= height[right]) left++ // [!code highlight]
    else right--
  }
  return best
}
```

## 复杂度与边界

- 每轮至少一端向内移动一步，总轮数最多 n - 1，时间 **O(n)**，额外空间 **O(1)**，无递归，输入不变。
- 两根线只比较一次。
- 存在零高度时面积可能为零，仍按短边规则移动。
- 题目整数范围内面积能由 number 精确表示。
- 输入至少两项，本地空输入会返回零但不作为题目要求。
