# 0015 三数之和

阅读前提：[本章基础](/leetcode/02-two-pointers/)。[官方题目](https://leetcode.cn/problems/3sum/)。

## 题目

:::info 题面

**难度**：中等

找三个不同位置，使对应数值之和为零。返回数值三元组，而且相同数值组合只能出现一次。[0,0,0,0] 虽有多组位置选择，答案仍只有 [[0,0,0]]。这与两数之和返回下标不同，排序不会丢失最终需要的信息，但仍要区分相同数值能否来自不同位置。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [-1,0,1,2,-1,-4]
> 输出：[[-1,-1,2],[-1,0,1]]

> **示例 2**
>
> 输入：nums = [0,1,1]
> 输出：[]

> **示例 3**
>
> 输入：nums = [0,0,0]
> 输出：[[0,0,0]]

### 约束

- 3 <= nums.length <= 3000
- -10^5 <= nums[i] <= 10^5

## 前期思路

### 朴素方法与复杂度

三个循环枚举下标 i < j < k，每次判断和是否为零。这个顺序保证位置不同，但不同位置仍可能产生相同数值结果，因此还要去重。枚举次数 O(n³)，不是仅加一个结果 Set 就能改善枚举规模。

可以先固定第一个数，再找剩下两个数之和等于它的相反数。这样把问题拆成已经熟悉的“两数配对”，但要找出全部不同组合，不能找到第一组就整体返回。

### 优化依据：排序建立排除方向

固定首数后，直接枚举后两数仍有 O(n²) 次比较。如果把剩余数排好序，当前两数和偏小，就能够确定一批候选都太小；偏大则确定另一批候选都太大。这种有方向的判断，来自排序后数值只增不减的事实。

先把整个数组按数值升序排列。固定 first，left 从它后一位开始，right 从末尾开始。总和小于零时，当前 left 与任何更靠左的 right 搭配只会更小，因此可以移走 left。总和大于零时，当前 right 与任何更靠右的 left 搭配只会更大，因此可以移走 right。

找到零时记录结果，随后跳过左右相同数值。首数也只处理同一值的第一次。这三处去重各有职责，不能靠“见到重复就全部不选”来替代，否则 [-1,-1,2] 会被错误排除。

### 正确性与停止条件

三个位置始终满足 first < left < right，因此没有重复使用一个元素。固定首数后，每次移动排除的候选都由和的方向证明不可能为零；命中后跳过同值只会去掉相同三元组，不会丢失新值组合。不同首数对应不同排序后三元组第一项，相同首数跳过则不会重复输出。

当排序后的首数已经大于零，后面两项也大于零，和不可能为零，可以结束外层。这个提前停止依赖目标是零，不能照搬到任意目标。

### 变式分析与错误反例

- TS 默认 sort 按字符串比较，[2,10,-1] 不会按数值升序，因此必须传比较器。错误地在命中后只移动一个指针且不去重，会让 [0,0,0,0] 输出重复答案。
- 若目标改成任意 target，比较改为与 target 比较，但首数大于零的停止条件要移除或重新证明。若要求所有下标三元组，排序时必须保留原位置，且相同数值不同位置不能按本题规则去重，输出数量也可能达到 O(n³)。

## 执行过程示例

[-1,0,1,2,-1,-4] 排序后是 [-4,-1,-1,0,1,2]。

| 固定值 | 左右值变化 | 判断与动作 |
| --- | --- | --- |
| -4 | -1 与 2 然后 -1 与 2 然后 0 与 2 然后 1 与 2 | 和依次为 -3 -3 -2 -1 均偏小 左端右移直至相遇 |
| -1 首次 | -1 与 2 | 和为零 输出 [-1,-1,2] 并越过重复端值 |
| -1 首次 | 0 与 1 | 和为零 输出 [-1,0,1] 两端随后相遇 |
| -1 第二次 | 不启动 | 首数重复 结果已经覆盖 |
| 0 | 1 与 2 | 和为 3 右端左移后相遇 |

注意首数 -1 后仍允许左端取 -1，因为它来自另一个位置。去重的是结果身份，不是禁止数值重复。

## 解法复述与检查

- 为什么先固定一项？
- 排序提供了什么排除依据？
- 三处去重各在避免哪种重复？

:::details 解法概述

先按数值排序，依次固定不同的首数，在其后范围内用左右两个位置寻找剩余配对。总和偏小就右移左端，偏大就左移右端，排除依据来自排序后的单调性。命中时记录三元组并跳过左右重复值，首数也只处理相同值的第一次，从而保证位置不同且结果唯一。

:::

## TypeScript 实现

```ts
export function threeSum(nums: number[]): number[][] {
  // 复制后排序以保留调用者的原数组
  const sorted = [...nums].sort((a, b) => a - b)
  const result: number[][] = []
  for (let first = 0; first < sorted.length - 2; first++) {
    if (first > 0 && sorted[first] === sorted[first - 1]) continue // [!code highlight]
    if (sorted[first] > 0) break
    let left = first + 1
    let right = sorted.length - 1
    while (left < right) {
      const sum = sorted[first] + sorted[left] + sorted[right]
      if (sum < 0) left++
      else if (sum > 0) right--
      else {
        result.push([sorted[first], sorted[left], sorted[right]])
        const leftValue = sorted[left]
        const rightValue = sorted[right]
        // 相同数值只产生重复三元组
        while (left < right && sorted[left] === leftValue) left++ // [!code highlight]
        while (left < right && sorted[right] === rightValue) right--
      }
    }
  }
  return result
}
```

## 复杂度与边界

- 固定首数至多 n 次，每次左右端总共移动 **O(n)**，主过程 **O(n²)**，排序 **O(n log n)** 不改变总阶。
- 复制排序数组使用 **O(n)** 辅助空间，排序内部开销依引擎实现计入；输出若有 k 组，占 **O(k)**，不应混为常数空间。
- 本实现不修改输入，无递归。
- 题目整数范围内三数相加安全，少于三项本地返回空数组。
