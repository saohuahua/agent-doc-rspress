# 0283 移动零

阅读前提：[本章基础](/leetcode/02-two-pointers/)。[官方题目](https://leetcode.cn/problems/move-zeroes/)。

## 题目

:::info 题面

**难度**：简单

把数组中的零移动到末尾，其他数字之间的相对顺序不能改变，并且直接修改原数组。例如 [0,1,0,3,12] 变成 [1,3,12,0,0]。函数不返回新数组，调用者观察原引用的内容。零有多少个，最后就保留多少个，不能删除它们改变长度。

:::

### 官方示例

> **示例 1**
>
> 输入: nums = [0,1,0,3,12]
> 输出: [1,3,12,0,0]

> **示例 2**
>
> 输入: nums = [0]
> 输出: [0]

### 约束

- 1 <= nums.length <= 10^4
- -2^31 <= nums[i] <= 2^31 - 1

### 进阶要求

在保持原地与稳定顺序的前提下 尽量减少移动操作。

## 前期思路

### 朴素方法与复杂度

按原顺序收集所有非零元素，再在末尾补上原有数量的零，即可得到正确结果。对应代码可以先创建一个新数组过滤零，再复制回来，时间 O(n)，但需要 O(n) 额外空间。

也可以遇到零就把后面所有元素往前挪一格，再把零放末尾。一次移动看起来简单，多个零却会让同一批元素反复搬动，最坏 O(n²)。这一题没有必要强行改善已经线性的过滤方案，真正要改善的是它多用了一块数组空间。

### 优化依据：原地写入的安全条件

读到第 read 个位置时，已经见过的非零元素数量不会超过已读元素数量。所以放下一个非零数的位置 write 一定不在 read 右边。写入只会覆盖已经读过的位置，或者当前位置本身，不会毁掉还没读取的数据。

这一关系允许直接把非零值写入原数组前端。read 表示读取进度，write 表示已保留的非零前缀长度。读取零只推进 read；读取非零值则同时追加结果并推进 write。

现在可以把这种两位置配合叫做快慢指针。名字中的快慢不是每次必须走不同步长，而是两个位置推进的条件不同。此处两个位置的移动条件分别由读取和保留规则决定。

### 算法推导与正确性

初始化 write 为零。逐个读取，如果值非零就写到 write，再增加 write；如果为零就跳过。读完后，前 write 个元素恰好是原数组全部非零值，顺序与读取顺序一致。剩下位置统一填零。

读取过程中立即清零可能导致自覆盖。如果 write 恰好等于 read，先写入再清掉会把刚保留的数变成零。本实现采用第二阶段统一补零，职责分开，避免这类自覆盖问题。

每轮结束时，前 write 项等于已读前缀去掉零的结果。这一事实起初对空前缀成立，每次非零追加或零跳过都保持它。因此读完后前半正确，尾部按长度补零就使整个结果正确。没有交换非零数之间的位置，所以稳定顺序自然成立。

### 变式分析与错误反例

- 若要求移除所有等于某个值的元素并返回新长度，第一阶段几乎不变，判断条件改成不等于目标，并返回 write，不必给无效尾部补值。若允许打乱非零顺序，可以把零与末尾元素交换，但原题不能这样做：[0,1,2] 可能得到 [2,1,0]，顺序违反要求。
- 常见错误是用过滤得到的新数组重新给形参 nums 赋值。它只改变局部变量指向，调用者持有的原数组并没有改变。原地修改要求写元素或改变原对象，而不是换一条局部引用。

## 执行过程示例

| read 与值 | 操作 | write 变化 | 当前有效结果 |
| --- | --- | --- | --- |
| 0 为 0 | 跳过 | 0 不变 | 空 |
| 1 为 1 | 写入位置 0 | 0 到 1 | 1 |
| 2 为 0 | 跳过 | 1 不变 | 1 |
| 3 为 3 | 写入位置 1 | 1 到 2 | 1 3 |
| 4 为 12 | 写入位置 2 | 2 到 3 | 1 3 12 |
| 扫描结束 | 位置 3 和 4 填零 | 3 到 5 | 1 3 12 0 0 |

中途数组中可能暂时出现重复值，那只是尚未整理的尾部，不应把它误认为最终答案。

## 解法复述与检查

- 为什么能安全向左写？
- 两个指针分别代表什么？
- 为什么最后补零而不是遇到零就搬动整个尾部？

:::details 解法概述

按原顺序读取数组，用写入位置表示已保留的非零前缀长度。遇到非零值就写入前缀末端并推进写入位置，遇到零只推进读取位置。写入位置不会超过读取位置，因此不会覆盖尚未读取的数据。最后将剩余位置补零，保留原有长度和非零值的相对顺序。

:::

## TypeScript 实现

```ts
export function moveZeroes(nums: number[]): void {
  // 写入位置之前都是按原顺序保留的非零值
  let write = 0
  for (let read = 0; read < nums.length; read++) {
    if (nums[read] !== 0) nums[write++] = nums[read] // [!code highlight]
  }
  // 非零值搬完后尾部统一补零
  while (write < nums.length) nums[write++] = 0 // [!code highlight]
}
```

## 复杂度与边界

- 扫描一次，加上至多 n 次补零，时间 **O(n)**，额外空间 **O(1)**，无递归，无额外输出数组。
- 直接修改输入，所以调用前需要保留原数据时应由调用者复制。
- 全零时第一阶段不写，第二阶段填满；无零时 write 与 read 同步，末尾不补零；单元素都成立。
- 题目数值为整数，不涉及 NaN 或特殊浮点零的身份区分。
