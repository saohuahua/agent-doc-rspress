# 贪心基础 局部选择的正确性依据

贪心算法在每一步固定一个局部选择，而不再回退修改。其正确性要求证明：固定该选择后，剩余问题仍能构造出全局最优解。仅凭局部最大或最小，无法自动得到这一结论。

阅读前提：[算法问题的分析方法](/leetcode/00-intro/01-how-to-think)。本章从候选方案的比较出发，分析哪些决定能够在不损失最优性的前提下固定。

## 局部选择与整体目标

股票题的整体目标是一次买卖的最大利润。固定卖出日后，最好的买入价就是此前最低价，这个局部选择不会伤害其他卖出日，因为每个卖出日都仍被检查。该方法比较已给定价格序列中的合法交易，不涉及未来价格预测。

跳跃题则把每个可到达位置当成一个能扩张范围的机会。关心能否到终点时，只要保存最远可到达边界，不必保留每条具体路径。最少跳数时，还需要区分一跳能覆盖的整层，不能单纯选择数组值最大的落点。

这些题都被归为贪心，但安全选择的依据不同。分类名称不能代替证明。

## 三种常见的解释方式

交换论证是说若某个最优方案没有采用当前选择，可以把其中一步换成当前选择而不使结果更差，因此至少存在一个最优方案包含这个选择。交换时必须检查换了之后后续仍合法。

领先论证是比较每一步的可达边界，证明当前策略的进展不落后于任何同样步数的方案。最少跳数中，在一层内收集全部下一跳边界，就是明确比较同样跳数能到多远。

强制边界是说某个元素既然还会在后面出现，就不能提前切段；一旦所有段内元素的最后位置都覆盖了，立即切开不会妨碍后面。划分字母区间使用的正是这种约束。

这些词可用于归纳思路，但题解要用具体对象解释。例如说明换的是哪天买入、领先的是哪个下标、切分必须跨过哪个字符，而不是只写存在交换证明。

## 局部最优策略的失效反例

硬币面值1、3、4，凑6元，每次优先取最大面值会选4加1加1，实际3加3只用两枚。由此可见不是所有最少次数问题都适合直接局部最大，必须利用具体面值或结构条件才能证明。

跳跃数组里最大跳跃长度也不等于最远落点。位置i可以跳nums[i]，实际覆盖到i加nums[i]，索引贡献不能漏掉。再大的一项若位于不可达区域，也不能用于更新边界。

## 历史信息的压缩依据

压缩历史意味着证明某些细节不再影响后续选择。股票仅需此前最低价，是因为固定卖出价后利润随买入价越低越大。可达性仅需最远边界，是因为从起点到这个边界之间的位置都能通过允许的步长落下，而不是只有一个孤立端点可达。

一旦限制改变，压缩可能失效。若跳跃必须恰好跳给定长度，边界中间不保证能到；若股票加入冷冻期或允许多笔交易，单个最低价不足以描述全部合法历史。

## 方法适用性检查

方法检查应包含朴素枚举方案、可替换或可固定的选择，以及不会损失最优性的理由。还需说明条件变化后该理由是否成立。若无法证明安全选择，应保留必要候选或重新定义状态；有限样例通过不能替代正确性证明。
