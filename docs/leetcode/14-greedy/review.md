# 贪心复习与迁移

## 一 硬币找零

面额为 1、3、4，目标金额为 6，每次选择最大可用面额是否保证最少枚数？

:::details 提示与解析

不能保证。4 + 1 + 1 需要三枚，3 + 3 只需两枚。局部面额更大不保证总枚数更少；需要证明特定面额条件下的最优性，或保存不同金额的最少枚数。

:::

## 二 恰好跳跃

将最多跳 nums[i] 步改为必须恰好跳 nums[i] 步，最远边界还能表示全部可达位置吗？

:::details 提示与解析

不能。中间位置可能不可达，例如从起点必须跳两步时，下标 1 不一定可达。原有连续区间的归纳依据失效，需要按照实际可达状态进行搜索。

:::

## 三 分段目标改变

划分字母区间的问题改为要求段数最少，最优解如何变化？

:::details 提示与解析

非空字符串整体作为一段，就满足同一字符不跨段的条件，因此最少为一段。原题尽早切分的理由依赖于段数最大化这一目标。

:::

## 理解检查

逐题说明保留的历史信息能够决定哪些后续选择，当前选择不会损失最优性的依据是什么，以及哪些条件变化会使该依据失效。
