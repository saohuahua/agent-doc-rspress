# 0045 跳跃游戏 II

最少跳跃次数取决于使用相同跳数能够覆盖的范围。逐条保存路线会产生重复状态，而连续可达区间提供了按跳数合并这些状态的依据。

相关基础：[本章基础](/leetcode/14-greedy/)。[力扣原题](https://leetcode.cn/problems/jump-game-ii/)。

## 题目

:::info 题面

**难度**：中等

数组含非负整数，每项是最多可向右跳的步数。从下标0到末尾，输出最少跳跃次数。题目保证终点可达。只有一个元素时已经在终点，答案0。

:::

### 官方示例

> **示例 1**
>
> 输入: nums = [2,3,1,1,4]
> 输出: 2

> **示例 2**
>
> 输入: nums = [2,3,0,1,4]
> 输出: 2

### 约束

- 1 <= nums.length <= 10^4
- 0 <= nums[i] <= 1000
- 题目保证可以到达 n - 1

## 前期思路

### 朴素方法与复杂度

可以枚举路径并取最短，也可以从起点做分层搜索：第一层是一跳能到的位置，第二层是再跳一次能到的位置。每条跳跃代价相同，首次到达终点的层数就是最少次数。但若逐一展开所有边，会重复枚举大量重叠落点，最坏O(n²)。

### 优化依据

同样跳数内能到的下标是连续区域。无需显式保存每条边和每个落点，只要扫描这一层全部可达位置，把它们下一跳能覆盖的最远位置汇总为nextEnd。当前层结束时再统一增加一次跳数。

### 算法推导

维护currentEnd表示使用当前jumps次跳跃能覆盖的边界，nextEnd表示扫描当前层过程中收集到的下一层最远边界。初始零次跳只能在0，所以两者为0。

每扫描位置i，先更新nextEnd为它与i加nums[i]的较大值。只有i等于currentEnd时，说明当前层能贡献的跳板都已看完，才增加jumps并把currentEnd换成nextEnd。这不是决定落在哪个单一位置，而是对整层机会做压缩。

最少跳数的依据是分层覆盖。少一次跳所能到的位置已经全部包含在旧边界内；若终点还在外面，就至少要再跳一次。新的边界由这层所有合法位置的下一跳共同得到，因此正好是多一次跳的最大覆盖，不会错过更优路径。遍历只到倒数第二项，因为到达终点后不需要再起跳。可达性保证意味着当前层在到终点前会继续前进。

### 变式分析与错误反例

- 若还要输出实际跳跃路线，需要记录每次扩张由哪个跳板贡献最远位置，并恢复一条合法链；单纯保存两个边界只够返回次数。若允许不可达输入，应在层末检测nextEnd等于currentEnd且未覆盖末尾，返回约定失败结果。
- 错误反例：`[1,1]`只需1跳，若连最后下标也作为层末增加次数，就会返回2。`[2,3,1,1,4]`中位置1扩大边界但仍在同一层，不能每扩大一次就增加跳数。

## 执行过程示例

输入`[2,3,1,1,4]`。

| 扫描i | nextEnd | 是否到层尾 | jumps与currentEnd |
| --- | --- | --- | --- |
| 0 | 2 | 是 | 1与2 |
| 1 | 4 | 否 | 仍1与2 |
| 2 | 4 | 是 | 2与4 |
| 3 | 4 | 否 | 仍2与4 |

终点不再触发额外一次，结果为2。

## 解法复述与检查

- 两个边界各自代表什么？
- 为什么不能每次nextEnd变大都加一次？
- 为什么不处理终点为起跳点？

:::details 算法概述

按跳数分层，但用连续区间边界代替显式队列。扫描当前层时不断收集下一跳能到的最远位置，直到当前层末尾才增加一次跳数并切换边界。少于当前层数无法越过旧范围，因此首次覆盖终点的层数就是最少跳数。终点不用再次起跳。

:::

## TypeScript 实现

```ts
export function jump(nums: number[]): number {
  let jumps = 0
  let currentEnd = 0
  let nextEnd = 0
  for (let i = 0; i < nums.length - 1; i++) {
    nextEnd = Math.max(nextEnd, i + nums[i])
    // 看完这一跳能到的所有跳板后才进入下一层
    if (i === currentEnd) {
      jumps++
      currentEnd = nextEnd
    }
  }
  return jumps
}
```

## 复杂度与边界

- 时间**O(n)**，辅助空间**O(1)**，不修改输入。
- 单元素循环不执行返回0。
- 本实现依赖题目保证可达，不为非法扩展情形返回失败标记；若取消保证，需要检测层边界是否无法前进。
