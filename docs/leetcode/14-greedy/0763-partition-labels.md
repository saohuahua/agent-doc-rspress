# 0763 划分字母区间

切分位置受到字符后续出现位置的约束。某个字符一旦进入当前区间，该区间就必须包含它的所有出现位置；这一必要条件决定了最早合法切分点。

相关基础：[本章基础](/leetcode/14-greedy/)。[力扣原题](https://leetcode.cn/problems/partition-labels/)。

## 题目

:::info 题面

**难度**：中等

输入小写英文字符串，将其分成尽可能多的连续段，使每个字母最多只出现在其中一段。返回各段长度，不是返回子串，也不是每段只能含一个字母。所有字符必须覆盖且保持原顺序。

:::

### 官方示例

> **示例 1**
>
> 输入：s = "ababcbacadefegdehijhklij"
> 输出：[9,7,8]

> **示例 2**
>
> 输入：s = "eccbbbbdec"
> 输出：[10]

### 约束

- 1 <= s.length <= 500
- s 仅由小写英文字母组成

## 前期思路

### 朴素方法与复杂度

可以尝试所有切分位置，再检查每个字母是否跨段。切分组合数量随间隙数指数增长。也可以从当前段起点逐个试切点，每次检查左段字符在后面是否重现，但反复扫描后缀会重复大量工作。

### 优化依据

对每个字母，只需提前知道它最后一次出现的位置。当前段一旦包含某个字母，段尾就至少要覆盖该位置。扫描途中再遇到新字母，取它最后位置与已有必须段尾的较大值。无需反复查询整个后缀。

### 算法推导

第一遍建立字符到最后下标的Map。第二遍维护start为当前段起点，end为当前已扫描字符要求的最远结束位置。每看见一个字符，用它最后位置扩展end。

当扫描下标i小于end时不能切，因为当前段里至少有一个字符还会在end出现，提前切会让它跨段。当i等于end时，当前段全部已见字符的最后出现都不晚于这里，它们以后不会再出现，因此这里切分是合法的。记录i减start加一，然后新段从i加一开始。

最早合法切点能够保证段数最大化。在这个位置之前任何切点都违反某个已见字符约束，所以这是当前段最早合法结束。选择它不会限制后面的字符，因为两侧字符集合已经分离；若拖到更后面，只会合并本可分开的部分，不可能增加段数。对剩余后缀重复同样理由即可。

### 变式分析与错误反例

- 若要求最少段而非最多段，整串作为一段即可，原来的尽早切分目标不再成立。若允许同字母跨两段，最后位置不再构成禁止切点的充分约束，需要新的状态。
- 错误反例：`abac`看见不同字符就切成a、b、a、c，会让a跨段。只看当前字符是否最后一次也不够，在位置1的b虽已结束，段内a还没结束，所以仍不能切。

## 执行过程示例

字符串`abac`，最后位置为a到2、b到1、c到3。

| i与字符 | end变化 | 能否切 | 原因 |
| --- | --- | --- | --- |
| 0 a | 0变2 | 否 | a还在2出现 |
| 1 b | 保持2 | 否 | a的要求尚未满足 |
| 2 a | 保持2 | 是 长度3 | 段内字母以后都不出现 |
| 3 c | 变3 | 是 长度1 | 单字母段已经完整 |

返回`[3,1]`。

## 解法复述与检查

- 为什么要保存最后位置而不是出现次数？
- 怎样证明切分合法？
- 怎样证明最早合法切点有利于最多段？

:::details 算法概述

先统计每个字母最后出现的下标。扫描当前段时，维护段内字母共同要求的最远结束位置。到达该位置说明它们以后都不再出现，可以立即切段；更早切不合法，更晚切只会减少切分机会。记录长度后从下一位置继续。

:::

## TypeScript 实现

```ts
export function partitionLabels(s: string): number[] {
  const last = new Map<string, number>()
  for (let i = 0; i < s.length; i++) last.set(s[i], i)
  const answer: number[] = []
  let start = 0
  let end = 0
  for (let i = 0; i < s.length; i++) {
    end = Math.max(end, last.get(s[i])!)
    // 所有段内字符的最后出现都已覆盖 此刻才能切分
    if (i === end) {
      answer.push(end - start + 1)
      start = i + 1
    }
  }
  return answer
}
```

## 复杂度与边界

- 两次扫描时间**O(n)**。
- 小写字母表固定26个，记录空间**O(1)**，输出另占**O(n)**上界。
- 若推广任意字符集，记录空间为不同字符数**O(u)**。
- 不修改输入，本题字符下标按ASCII小写字母理解。
