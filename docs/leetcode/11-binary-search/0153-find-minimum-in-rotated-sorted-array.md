# 0153 寻找旋转排序数组中的最小值

相关基础：[本章基础](/leetcode/11-binary-search/)。题目来源：[力扣 153](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/)。

## 题目

:::info 题面

**难度**：中等

输入是非空、没有重复元素的递增数组旋转后的结果，要求最小值而不是其下标。数组可能完全未旋转。比如 [3,4,5,1,2] 的最小值是 1。要求 O(log n)，意味着不能仅仅扫描一遍取最小值。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [3,4,5,1,2]
> 输出：1

> **示例 2**
>
> 输入：nums = [4,5,6,7,0,1,2]
> 输出：0

> **示例 3**
>
> 输入：nums = [11,13,15,17]
> 输出：11

### 约束

- n == nums.length
- 1 <= n <= 5000
- -5000 <= nums[i] <= 5000
- nums 中的所有整数 互不相同
- nums 原来是一个升序排序的数组，并进行了 1 至 n 次旋转

## 前期思路

### 朴素方法与复杂度

最直接是看过每个元素并保留最小值，O(n) 时间、O(1) 空间。还可以找第一个比前一项小的位置，那就是断点；没有断点则第一项最小。但逐个找断点仍是线性扫描。接下来要问：看到中点和某个端点，能否判断断点在哪一侧？

### 需要保留什么信息

画出 [3,4,5,1,2] 的走势，旋转后前面一段整体较大，后面一段整体较小，两段内部递增。右端处在当前范围的最后一段。如果中点值大于右端，说明中点和右端之间必然经过下降，最小值在中点右边。如果中点值小于右端，中点到右端是递增的一段，最小值不会在中点之后，只可能是中点自己或左边。

使用右端比较有一个好处：未旋转时中点也小于右端，会自然把搜索压向左边，不必先识别数组到底旋转了多少次。用左端比较也能设计解法，但需要仔细处理有序区间；本实现采用与右端比较的闭区间约定。

### 算法推导

维护闭区间 [left,right]，约定最小值一定还在其中。只要有至少两个元素，就取偏左中点。若 nums[mid]>nums[right]，中点处在较大段，连中点一起排除，left=mid+1。否则最小值可能正好在中点，所以 right=mid，不能写 mid-1。

这里与查找目标不同，没有在中点做“命中即返回”的判定，算法只是在缩小包含最小值的范围。mid 值小于右端并不能证明 mid 就是最小值，例如 [1,2,3,4] 的中点是 2，最小值还在左边，因此继续收缩。

没有重复保证两值不相等，直到只剩一个位置。每次至少排除一个元素，范围严格缩小。初始最小值在全数组中，每步排除的部分都不可能含更小元素，最终唯一位置就是答案。这种“收敛到唯一候选”的结束方式使用 left<right，而不是目标查找中的 left<=right。

### 变式分析与错误反例

- 若允许重复，[1,1,1,0,1] 中 mid 与 right 相等，不能确定最小值在哪边，可以排除一个右端重复值继续找，但最坏时间变为 O(n)。如果要求旋转次数并约定原数组严格递增，那么最小值下标可以表示向右旋转的次数对长度取余，直接返回 left 即可；“次数”定义改变时必须先约定旋转方向。

## 执行过程示例

数组 [3,4,5,1,2]。

| 范围 | 中点与右端 | 原因 | 新范围 |
| --- | --- | --- | --- |
| 0 到 4 | 5 大于 2 | 中点到右端必跨下降 最小值在右侧 | 3 到 4 |
| 3 到 4 | 1 小于 2 | 中点可能最小 保留它 | 3 到 3 |

返回下标 3 的值 1。最后一步如果把 right 写成 mid-1，会把真正的最小值排除。这不是一个无关紧要的边界符号，而是有没有证明中点不可能为答案的区别。

## 解法复述与检查

复述检查：

- 为什么选右端作为参照？
- 两种比较中，哪一种允许排除中点，哪一种必须保留？

:::details 算法概述

保留一定含最小值的闭区间。中点大于右端，下降点在右边，所以最小值在中点之后；中点小于右端，右边递增，最小值只能是中点或更左。不断缩小，直到只有一个位置，再返回它的数值。

:::

## 复杂度与边界

- 时间 **O(log n)**，辅助空间 **O(1)**，无递归，不修改数组，返回一个数。
- 单元素不进入循环。
- 完全有序数组不断缩小右端到零。
- 最小值在尾部时，左端可以不断右移，不需要额外扫描验证。
- 输入无重复是判断前提。

## 分层提示

:::details 提示一 观察方向

把旋转数组画成两段上升线 看中点比最右值大意味着什么

:::

:::details 提示二 需要的信息

一直保留含最小值的范围 不要求每次猜中最小值

:::

:::details 提示三 组织步骤

中点大于右端就越过中点向右 否则保留中点收缩右端 直到一个位置

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function findMin(nums: number[]): number {
  // 闭区间始终保留真正的最小值
  let left = 0
  let right = nums.length - 1
  while (left < right) {
    const mid = left + Math.floor((right - left) / 2)
    if (nums[mid] > nums[right]) left = mid + 1
    // 中点仍可能是最小值所以必须保留
    else right = mid
  }
  return nums[left]
}
```
