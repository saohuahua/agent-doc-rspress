# 0033 搜索旋转排序数组

相关基础：[本章基础](/leetcode/11-binary-search/)。题目来源：[力扣 33](https://leetcode.cn/problems/search-in-rotated-sorted-array/)。

## 题目

:::info 题面

**难度**：中等

一个严格递增数组在某个位置旋转，形成两段相接，例如 [0,1,2,4,5,6,7] 变成 [4,5,6,7,0,1,2]。输入没有重复元素，数组非空。要求目标下标，不存在返回 -1，且时间需要为对数级。旋转没有打乱每一段内部顺序，但整体不再有序，不能直接套普通二分的大小判断。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [4,5,6,7,0,1,2], target = 0
> 输出：4

> **示例 2**
>
> 输入：nums = [4,5,6,7,0,1,2], target = 3
> 输出：-1

> **示例 3**
>
> 输入：nums = [1], target = 0
> 输出：-1

### 约束

- 1 <= nums.length <= 5000
- -10^4 <= nums[i] <= 10^4
- nums 中的每个值都 独一无二
- 题目数据保证 nums 在预先未知的某个下标上进行了旋转
- -10^4 <= target <= 10^4

## 前期思路

### 朴素方法与复杂度

逐项比较可确定目标位置，时间为 O(n)。另一种方法是先找到最小值，把旋转恢复后查找，但恢复数组顺序需要 O(n) 成本。优化目标是仅通过比较排除候选，避免移动数组元素。因此先研究一个中点把数组分成两半以后，是否仍然有一半能提供可靠的排序信息。

### 从无序表象里找信息

旋转数组只有一个从大数落到小数的断点，中点切出的左右半区不可能同时跨过这个断点。因此至少一半有序。比较 nums[left] 和 nums[mid]：前者不大于后者时，左半 [left,mid] 有序；否则断点在左边，右半 [mid,right] 有序。

这里的不大于包含 left=mid 的单元素半区，这个半区天然有序。没有重复值是判断可靠的重要前提。如果允许重复，[1,0,1,1,1] 的端点相等可能遮住断点，就不能再用同样信息唯一判断。

### 算法推导

先检查中点是否命中。未命中时，如果左半有序，判断目标是否满足 nums[left]<=target<nums[mid]。满足则只可能在左半，把 right 改为 mid-1；不满足则有序左半内没有目标，排除它，把 left 改为 mid+1。

如果右半有序，对称判断 nums[mid]<target<=nums[right]。在这个值域内就保留右半，否则保留左半。比较目标所在值域之前必须先确认这一半有序，因为只有有序区间的端点才描述全部可能值的范围。

闭区间始终包含所有还可能命中的下标。每次只排除已证明不存在目标的一半，而且中点既然检查过就可以一并排除。区间严格缩小到空时返回 -1。正确性来自有序半区的值域排除，不是来自“目标比中点大就往右”的错误直觉。

### 变式分析与错误反例

- 允许重复会破坏有序半区的识别，如 [1,0,1,1,1] 中左端和中点都是 1，却不能据此排除左侧寻找 0。需要在无法判断时逐步缩小相等端点，最坏退化到 O(n)。若只问是否存在，可以改变返回值，但不能省略值域判断。错误直接按中点大小走方向，会在本题示例第一轮就丢掉正确答案。

## 执行过程示例

数组 [4,5,6,7,0,1,2]，找 0。

| 范围 | 中点 | 有序部分和判断 | 下一范围 |
| --- | --- | --- | --- |
| 0 到 6 | 下标3值7 | 左半4到7有序 目标0不在其中 | 4 到 6 |
| 4 到 6 | 下标5值1 | 左半0到1有序 目标在其中且未命中中点 | 4 到 4 |
| 4 到 4 | 下标4值0 | 命中 | 返回4 |

第一轮中点 7 大于目标，保留的范围却在右侧：左半区虽有序，但其值域不包含目标。整体旋转后不能仅根据中点与目标的大小关系决定搜索方向。

## 解法复述与检查

- 为什么一定至少有一半有序？
- 哪个条件决定保留左半？
- 先比较哪两个值，后比较目标？

:::details 算法概述

旋转只产生一个断点，所以中点两侧至少一半有序。首先检查中点，再用端点判断有序半区。如果目标落在这半区的值域里就保留它，否则排除它去另一半。每次排除都依赖已确认的顺序，最后返回命中下标或不存在。

:::

## 复杂度与边界

- 每次减半，时间 **O(log n)**，辅助空间 **O(1)**，无递归，不修改输入，输出常数空间。
- 未旋转时左半判断一直可用。
- 单元素先做命中判断，未命中会让范围变空。
- 比较使用题目范围内的精确整数。

## 分层提示

:::details 提示一 观察方向

旋转只产生一个断点 中点两侧会不会同时包含它

:::

:::details 提示二 需要的信息

先确认哪半有序 再用它的两个端点判断目标能否在其中

:::

:::details 提示三 组织步骤

检查中点 判有序半区 判目标值域 保留可能的一半 重复到空

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function search(nums: number[], target: number): number {
  let left = 0
  let right = nums.length - 1
  while (left <= right) {
    const mid = left + Math.floor((right - left) / 2)
    if (nums[mid] === target) return mid
    // 先识别有序半区再判断目标是否属于其值域
    if (nums[left] <= nums[mid]) {
      if (nums[left] <= target && target < nums[mid]) right = mid - 1
      else left = mid + 1
    } else {
      if (nums[mid] < target && target <= nums[right]) left = mid + 1
      else right = mid - 1
    }
  }
  return -1
}
```
