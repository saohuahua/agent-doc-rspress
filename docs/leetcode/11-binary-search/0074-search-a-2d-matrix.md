# 0074 搜索二维矩阵

相关基础：[本章基础](/leetcode/11-binary-search/)。题目来源：[力扣 74](https://leetcode.cn/problems/search-a-2d-matrix/)。

## 题目

:::info 题面

**难度**：中等

输入是非空矩形整数矩阵，行内非递减，而且每行第一个元素大于上一行最后一个元素。输出目标是否存在。第二条约束非常关键，它比“每行和每列各自有序”更强，意味着按行读完的整个序列也是有序的。这里只要布尔值，不用返回行列坐标。

:::

### 官方示例

> **示例 1**
>
> 输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3
> 输出：true

> **示例 2**
>
> 输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13
> 输出：false

### 约束

- m == matrix.length
- n == matrix[i].length
- 1 <= m, n <= 100
- -10^4 <= matrix[i][j], target <= 10^4

## 前期思路

### 朴素方法与复杂度

逐格检查肯定正确，m 行 n 列总共 O(mn) 次。稍微利用信息，可以先比较每行首尾，找到可能包含目标的一行，再逐个检查其中元素。但两个阶段都线性扫描，仍有进一步排除的空间。先在纸上把矩阵每一行接到上一行后面，会看到一个普通有序数组。

### 浪费与需要的信息

真正没必要的是在已知大小关系时仍逐格看。比如三行依次为 [1,3]、[5,7]、[9,11]，如果中间的 7 小于目标 9，它前面的所有元素都可以一起排除。将一维下标映射回行列坐标，即可读取有序序列的中点，无需花费额外 O(mn) 时间和空间复制矩阵。

因此只需要一套位置换算：把矩阵假想为长度 m*n 的数组，线性下标 k 对应行 Math.floor(k/n)，列 k%n。每行恰有 n 个位置，所以除法得到跳过的完整行数，余数得到行内偏移。数据不必移动，只有访问方式变化。

### 算法推导

维护闭区间 [left,right]，初始 0 到 m*n-1，表示还没有排除的位置。取线性中点，把它换算成坐标后读值。相等则立即返回 true；比目标小则连中点一起舍弃左半段；比目标大则舍弃右半段。闭区间中 right 是实际候选位置，因此更新时使用 mid-1，与右开区间的 mid 不同。

为什么不会漏掉答案？矩阵按行展开整体有序，所以中点左侧不会大于中点，右侧不会小于中点。每次被排除部分均不可能含目标，未排除部分继续保留目标若存在的可能。区间每次严格缩小。left 超过 right 表示候选耗尽，这才返回 false。

线性下标与行列坐标的对应关系由每行长度确定。长度为 n 的一行占据连续 n 个线性位置，跨过整行才增加行号；行末的下一位置余数回到零。边界处不需要单独写跨行循环。

### 变式分析与错误反例

- 若只有行列分别递增，例如 [[1,4],[2,5]]，按行连接变成 [1,4,2,5]，不再整体有序。直接沿用本题会在找 2 时误删合法位置。此时需要用行列的双方向信息另选方法，不能因为都是矩阵搜索就复制代码。若只需返回坐标，命中时返回换算得到的行与列即可，排除依据不变。

## 执行过程示例

矩阵 [[1,3],[5,7],[9,11]]，目标 9。

| 范围 | 线性中点 | 坐标和值 | 后续原因 |
| --- | --- | --- | --- |
| 0 到 5 | 2 | 第 1 行第 0 列为 5 | 5 太小 搜 3 到 5 |
| 3 到 5 | 4 | 第 2 行第 0 列为 9 | 相等 返回 true |

若目标改为 8，第二轮的 9 太大，范围变为 3 到 3；第三轮读取 7 太小，范围变为 4 到 3，返回 false。没有读到目标不等于算法失败，穷尽合法候选就是不存在的证据。

## 解法复述与检查

- 哪些约束保证展开后有序？
- 为什么可以不真正展开？
- 闭区间为什么使用 left<=right？

:::details 算法概述

按行连接后整体有序，因此对虚拟的一维位置做折半查找。每次用列数把中点换成行列坐标，读原矩阵中的值。比目标小就排除左半，包括中点；比目标大排除右半；相等返回真，区间为空返回假。没有复制数据，因此省掉了展开成本。

:::

## 复杂度与边界

- 时间 **O(log(mn)**)，辅助空间 **O(1)**，无递归栈，不修改输入，输出为布尔值。
- 单行或单列都使用同一映射。
- 实现为本地调用补充空矩阵保护，题目保证非空。
- 所有行等长属于输入契约，不用每次读取前扫描验证矩形。

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function searchMatrix(matrix: number[][], target: number): boolean {
  if (matrix.length === 0 || matrix[0].length === 0) return false
  const columns = matrix[0].length
  // 线性闭区间代表按行展开后仍待检查的元素
  let left = 0
  let right = matrix.length * columns - 1
  while (left <= right) {
    const mid = left + Math.floor((right - left) / 2)
    // 整行数量决定行号而余数决定列号
    const value = matrix[Math.floor(mid / columns)][mid % columns]
    if (value === target) return true
    if (value < target) left = mid + 1
    else right = mid - 1
  }
  return false
}
```
