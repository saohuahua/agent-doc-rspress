# 0034 在排序数组中查找元素的第一个和最后一个位置

相关基础：[本章基础](/leetcode/11-binary-search/)。题目来源：[力扣 34](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)。

## 题目

:::info 题面

**难度**：中等

输入非递减整数数组，允许重复，也允许为空。要求返回目标第一次和最后一次出现的位置；不存在返回 [-1,-1]。与找到任意一个目标不同，中间命中仍不能确定边界。比如 [5,7,7,8,8,10] 找 8，必须得到 [3,4]。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [5,7,7,8,8,10], target = 8
> 输出：[3,4]

> **示例 2**
>
> 输入：nums = [5,7,7,8,8,10], target = 6
> 输出：[-1,-1]

> **示例 3**
>
> 输入：nums = [], target = 0
> 输出：[-1,-1]

### 约束

- 0 <= nums.length <= 10^5
- -10^9 <= nums[i] <= 10^9
- nums 是一个非递减数组
- -10^9 <= target <= 10^9

## 前期思路

### 朴素方法与复杂度

线性扫一遍，第一次遇到目标记录起点，每次遇到都覆盖终点，可以正确解决，时间 O(n)。如果先折半找到一个目标再向左右扩展，也有最坏 O(n)：整个数组全是同一个数时仍要扫过所有位置。要求对数时间时，不能让后半段退回逐个扩展。

### 优化依据与所需信息

有序性把数组分成三段：小于目标、等于目标、大于目标。只需三段之间的两个边界，不需要读取相等段内每个元素。第一个边界是第一个大于等于目标的位置，第二个是第一个严格大于目标的位置。相等段的右端下标就是第二个边界减一。

第一条边界与搜索插入位置所求的边界相同。第二条只改变相等时的判断方向。第二条边界直接比较是否严格大于目标，不依赖 target+1 运算，因此也适用于不存在安全后继整数的一般数值模型。

### 算法推导

写一个内部边界查找函数，布尔参数表示是否寻找严格大于。它维护左闭右开范围 [0,n)。中点值小于目标时，两种查找都要向右；中点值等于目标时，找左边界向左保留它，找右边界向右越过它；中点值大于目标时两种都收缩右端。

每种查找都相当于寻找一串 false 后面的第一个 true。左边界使用“值>=目标”作为 true，右边界使用“值>目标”。因为数组有序，true 后不会再出现 false，这就是整段舍弃的依据。最终返回交界位置，允许为 n。

先得到左边界之后还要确认：它是否等于 n，或它指向的值并不是目标。如果是，说明根本没有相等段，应立即返回 [-1,-1]。只有确定目标存在，才用第二条边界减一。把插入位置误当成命中位置，会让不存在的目标得到虚假的范围。

### 变式分析与错误反例

- 要求统计出现次数时，直接用右边界减左边界；目标不存在时两者相等，次数为零。要求找小于目标的最大下标时，用首个不小于的位置减一，但负一表示不存在。错误做法是命中就返回 [mid,mid]，[2,2,2] 会漏掉两侧，因此找到任意值与寻找边界应当分开理解。

## 执行过程示例

数组 [5,7,7,8,8,10]，目标 8。

| 查找 | 范围与中点变化 | 终止结果 |
| --- | --- | --- |
| 首个不小于 | [0,6) 中点3为8收右到3 再中点1为7移左到2 再中点2为7移左到3 | 3 |
| 首个大于 | [0,6) 中点3为8移左到4 再中点5为10收右到5 再中点4为8移左到5 | 5 |

两次查找相等时的方向不同，所以分别落在相等段两侧。最终范围是 [3,5-1]。若找 6，首个不小于的位置为 1，但 nums[1] 是 7，必须返回不存在。

## 解法复述与检查

解释为什么找到了一个 8 还不够，以及如何完全避免向两边线性扩展。

:::details 算法概述

有序数组中的目标值形成连续一段。分别找第一个不小于目标的位置和第一个大于目标的位置，两个查找只在等于时选择不同方向。先检查左边界是否真的命中目标；命中后右边界减一就是最后出现位置。两次都折半，所以整体仍为对数时间。

:::

## 复杂度与边界

- 两次 **O(log n)** 查找相加仍是 **O(log n)**，辅助空间 **O(1)**。
- 内部函数只是顺序调用，不产生递归栈。
- 输入不修改，两个下标输出空间 **O(1)**。
- 空数组左边界为零，利用短路判断先确认越界，不读取非法元素。
- 全部相等时两个边界分别为 0 和 n。

## 分层提示

:::details 提示一 观察方向

相同值在有序数组里会形成连续段 先找这段两端的分界

:::

:::details 提示二 需要的信息

区分首个不小于与首个大于 两者在等于时必须做不同决定

:::

:::details 提示三 组织步骤

分别求两个边界 先验证左边界命中 右边界减一作为末位置

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function searchRange(nums: number[], target: number): number[] {
  // 严格模式寻找首个更大值否则寻找首个不小于值
  const boundary = (strict: boolean): number => {
    let left = 0
    let right = nums.length
    while (left < right) {
      const mid = left + Math.floor((right - left) / 2)
      if (nums[mid] < target || (strict && nums[mid] === target)) left = mid + 1
      else right = mid
    }
    return left
  }
  const first = boundary(false)
  // 插入位置存在不代表目标真实存在
  if (first === nums.length || nums[first] !== target) return [-1, -1]
  return [first, boundary(true) - 1]
}
```
