# 二分查找复习

## 练习一 相等时向哪走

[1,2,2,4] 中把新的 2 插到已有 2 后面 应返回哪里

:::details 提示与解析

返回3 找首个严格大于2的位置 相等时应越过中点向右 若仍找首个不小于 会返回1

:::

## 练习二 排序条件改变

矩阵 [[1,4],[2,5]] 可否按行展开后查找 2

:::details 提示与解析

不可以 展开序列不单调 普通二分第一步可能错误排除下标2 需要使用行列分别有序的其他排除方法

:::

## 练习三 为什么重复值会降速

旋转数组 [1,0,1,1,1] 的中点与右端相等时 可以固定舍弃一半吗

:::details 提示与解析

不能 相等会遮住断点位置 不同位置放一个零都可能形成相似比较信息 必要时只能排除一个相等端点 最坏线性

:::

## 口述自检

不用代码解释四件事 当前区间包含什么 中点比较证明了什么 哪一段被排除 为什么循环一定结束 中位数题还要分别说明数量条件与跨边界大小条件
