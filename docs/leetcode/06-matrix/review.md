# 矩阵复习与迁移

## 练习一 螺旋读取改为填数

生成三乘四矩阵，按顺时针依次填一到十二，怎样复用思路？

:::details 提示与解析

继续用四个边界与上右下左顺序，把 push 改成写入递增数字。第一行 1 2 3 4，右侧 5 6，底边反向 7 8 9，左侧 10，内部填 11 12。结果为 [[1,2,3,4],[10,11,12,5],[9,8,7,6]]。

:::

## 练习二 旋转方向改成逆时针

转置以后应该改哪一种翻转？

:::details 提示与解析

转置后上下翻转整张矩阵，坐标由 (r,c) 到 (c,r) 再到 (n - 1 - c,r)，恰是逆时针。以 [[1,2],[3,4]] 验证得到 [[2,4],[1,3]]。反转操作需要明确作用于行内列顺序还是外层行顺序。

:::

## 练习三 只有每行有序

[[1,9],[2,3]] 中搜索 3，右上角排除法还能用吗？

:::details 提示与解析

不能。看到 9 大于 3 后删列会把下面的答案 3 一并删掉，列有序前提已经失效。可以逐行二分或者整体扫描，复杂度与具体约束匹配。

:::

## 解法复述检查

能否说明坐标含义、每次写入前后信息含义、边界是否包含端点、以及每次删行删列的依据。画图时先标行列下标，再追踪一个元素，而不是只看整体形状。
