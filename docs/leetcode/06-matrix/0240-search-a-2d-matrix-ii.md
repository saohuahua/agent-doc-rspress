# 0240 搜索二维矩阵 II

阅读前提：[本章基础](/leetcode/06-matrix/)。[官方题目](https://leetcode.cn/problems/search-a-2d-matrix-ii/)。

## 题目

:::info 题面

**难度**：中等

矩阵每行从左到右递增，每列从上到下递增，判断目标是否存在，返回布尔值。注意没有保证下一行第一个数大于上一行最后一个数，因此不能直接把整张矩阵当作一个排序数组做一维二分。

例如 [[1,4],[2,5]] 行列都有序，但按行展开成 [1,4,2,5] 并无序。先区分题目真的给了什么信息，才能判断能否排除候选。

:::

### 官方示例

> **示例 1**
>
> 输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 5
> 输出：true

> **示例 2**
>
> 输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 20
> 输出：false

### 约束

- m == matrix.length
- n == matrix[i].length
- 1 <= n, m <= 300
- -10^9 <= matrix[i][j] <= 10^9
- 每行的所有元素从左到右升序排列
- 每列的所有元素从上到下升序排列
- -10^9 <= target <= 10^9

## 前期思路

### 朴素方法与复杂度

扫描所有 m 乘 n 个位置，找到就返回，时间 O(mn)，空间 O(1)。可以利用每行有序，对每行做二分，时间 O(m log n)，但这还没有利用列也有序的信息。

想同时利用两个方向，需要挑一个比较后能明确排除整行或整列的位置。左上角是区域最小值：若它比目标小，目标既可能在右边也可能在下面，没有单一方向。右下角类似。右上角则一边是更小值，另一边是更大值，比较结果具有方向。

### 优化依据：右上角的排除性质

从当前候选区域的右上角读 value。如果 value 大于目标，那么本列下面的值只会更大，这整列都不可能含目标，可以左移一列。若 value 小于目标，那么本行左边的值只会更小，这整行都不可能含目标，可以下移一行。

一次比较不是仅排除一个格子，而是排除一整条边。每次剩余区域仍是一个矩形，其右上角就是新位置，条件可以持续使用。

这里不用真的删除行列，只用 row 表示剩余区域上边，用 col 表示剩余区域右边。已排除区域不会再访问。

### 正确性与终止

最初全部位置都可能是答案。每次比较排除的行或列都由有序性证明不可能等于目标，因此若目标原来存在，它一直保留在剩余区域中，直到当前格子命中。如果 row 越过最后一行，或者 col 小于零，候选区域已经为空，说明目标不存在。

位置只向下或向左，最多下移 m 次、左移 n 次，所以不是遍历每格的复杂度。即使路径呈阶梯状反复换方向，总移动次数也受两条边长之和限制。

### 变式分析与错误反例

- 只保证每行有序却没有列有序时，从右上角偏大不能删整列。例如 [[1,9],[2,3]] 搜 3，若看到 9 就删整列，会漏掉下面的 3。先决条件失效，移动规则也随之失效。
- 若每行有序但列无序，可以逐行二分；若另有“下一行首项大于上一行末项”保证，则可映射为一维二分，复杂度 O(log(mn))。不同版本名称相似，必须回到具体约束，而不是因为看到矩阵搜索就套同一写法。

## 执行过程示例

矩阵 [[1,4,7],[2,5,8],[3,6,9]]，目标 6。

| 当前坐标与值 | 比较 | 排除依据 | 下一步 |
| --- | --- | --- | --- |
| (0,2) 为 7 | 大于 6 | 第 2 列下方更大 | 左移到 (0,1) |
| (0,1) 为 4 | 小于 6 | 第 0 行左边更小 | 下移到 (1,1) |
| (1,1) 为 5 | 小于 6 | 第 1 行剩余部分都更小 | 下移到 (2,1) |
| (2,1) 为 6 | 相等 | 找到目标 | 返回 true |

如果目标是 10，从右上角一路向下，越过底边后返回 false。两种情况都能用同一排除规则解释。

## 解法复述与检查

- 为什么不从左上角开始？
- 比较偏大时为何能删整列？
- 为什么时间不是 O(mn)？

:::details 解法概述

从剩余候选矩形的右上角开始。当前值大于目标时，下方同列值更大，可排除该列并左移；当前值小于目标时，左侧同行值更小，可排除该行并下移。相等时返回成功，越界时候选区域为空。每步仅排除确定不可能包含答案的区域。

:::

## TypeScript 实现

```ts
export function searchMatrix(matrix: number[][], target: number): boolean {
  let row = 0
  let col = matrix[0].length - 1
  while (row < matrix.length && col >= 0) {
    const value = matrix[row][col]
    if (value === target) return true
    // 右上角过大时整列候选都过大
    if (value > target) col--
    else row++
  }
  return false
}
```

## 复杂度与边界

- 时间 **O(m + n)**，辅助空间 **O(1)**，无递归，输入不变，输出一个布尔值。
- 单行时主要左移，单列时主要下移，也自然成立。
- 题目矩阵非空且行列有序，出现相等值也不会破坏不大于与不小于的排除依据。
- 数字为整数，直接比较即可。
