# 0048 旋转图像

阅读前提：[本章基础](/leetcode/06-matrix/)。[官方题目](https://leetcode.cn/problems/rotate-image/)。

## 题目

:::info 题面

**难度**：中等

输入 n 乘 n 的方阵，把图像顺时针旋转九十度，直接修改矩阵，不申请另一张矩阵。原来左上角到右上角，原来上边从左到右的一排会变成右边从上到下的一列。

二阶矩阵 [[1,2],[3,4]] 顺时针旋转后为 [[3,1],[4,2]]。该例可用于验证坐标映射的方向。

:::

### 官方示例

> **示例 1**
>
> 输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
> 输出：[[7,4,1],[8,5,2],[9,6,3]]

> **示例 2**
>
> 输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
> 输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]

### 约束

- n == matrix.length == matrix[i].length
- 1 <= n <= 20
- -1000 <= matrix[i][j] <= 1000

## 前期思路

### 朴素方法与复杂度

用新矩阵存结果最直接。原位置 row、col 的值应到 col、n - 1 - row。对于每个旧格子按这个公式写到新格子，时间 O(n²)，空间 O(n²)。问题不在访问次数，而在原地写入会覆盖还没搬走的值。

一种原地方案沿四个位置组成的旋转环交换；本篇采用另一种分解，将目标坐标映射拆成两次可原地完成的变换。

### 从坐标公式拆解动作

目标是把 (row,col) 变成 (col,n - 1 - row)。先交换横纵坐标，得到 (col,row)，这叫沿主对角线转置；再把每一行左右翻转，第二个坐标 row 就变成 n - 1 - row，恰好得到目标。

转置意味着 matrix[row][col] 与 matrix[col][row] 对换。主对角线元素映射到原位置，无需交换。每一对非对角格子只交换一次，因此只遍历 col 大于 row 的半边。若整张矩阵都交换，同一对会被换回原状。

转置后的每行反转可以用数组 reverse，原地改变行内容。这里反转的是每一行，不是外层行的顺序；两种操作得到的旋转方向不同。

### 正确性依据

可以追踪任意一个元素，不需要为每格画图。转置后坐标由 (r,c) 到 (c,r)，行内反转后到 (c,n - 1 - r)，正好与顺时针旋转公式一致。两个步骤都是交换操作，不丢失、不复制任何元素，所有格子的位置映射也一一对应。

原地转置使用临时变量，确保读取目标位置旧值之后再覆盖。交换边界由一对对称位置只处理一次的条件决定。

### 变式分析与错误反例

- 整个双层循环交换 row、col，会使 [[1,2],[3,4]] 的 2 与 3 先交换再换回，转置失败。转置后若反转行的上下顺序，得到的是逆时针九十度，不是本题方向。
- 若要求逆时针，可以转置后反转外层行顺序，仍需用坐标追踪证明。若输入是 m 乘 n 且 m 不等于 n，旋转后尺寸变成 n 乘 m，无法沿用方阵的简单就地交换，需要重新定义存储与接口，通常用新矩阵。

## 执行过程示例

| 阶段 | 三行内容 | 解释 |
| --- | --- | --- |
| 初始 | 1 2 3 ／ 4 5 6 ／ 7 8 9 | 原图 |
| 转置 | 1 4 7 ／ 2 5 8 ／ 3 6 9 | 交换 2 与 4 3 与 7 6 与 8 |
| 行内反转 | 7 4 1 ／ 8 5 2 ／ 9 6 3 | 每行左右倒过来 |

跟踪数字 2：原在 (0,1)，转置后到 (1,0)，行内反转后到 (1,2)，正是旋转后的右侧中间。元素位置追踪可直接验证两步变换与目标映射一致。

## 解法复述与检查

- 顺时针旋转后坐标是什么？
- 转置改变哪个部分？
- 为什么只遍历一半？

:::details 解法概述

顺时针旋转将坐标 (r,c) 映射到 (c,n - 1 - r)。先沿主对角线转置得到 (c,r)，再反转每一行，得到目标坐标。转置仅交换对角线一侧的对应元素，避免同一对位置重复交换。两步均通过原地交换完成，不需要另一张矩阵。

:::

## TypeScript 实现

```ts
export function rotate(matrix: number[][]): void {
  const n = matrix.length
  // 只交换主对角线一侧以免同一对交换两次
  for (let row = 0; row < n; row++) {
    for (let col = row + 1; col < n; col++) {
      const temporary = matrix[row][col]
      matrix[row][col] = matrix[col][row]
      matrix[col][row] = temporary
    }
  }
  // 转置后反转每行得到顺时针旋转
  for (const row of matrix) row.reverse()
}
```

## 复杂度与边界

- 转置与行内反转共 **O(n²)** 时间，辅助空间 **O(1)**，无递归，无新输出矩阵。
- 修改输入及各行内容，不替换整个矩阵引用。
- n 为一时两步都不改变结果，奇数方阵中心保持在中心，其他元素正常映射。
- 题目保证方阵，代码不负责矩形输入。
