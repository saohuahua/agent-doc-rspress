# 滑动窗口复习与迁移

本章复习依次检查朴素方法、重复计算、保留状态、新增元素引起的冲突，以及移除起点的依据。复述应独立于代码，并能够通过具体输入说明每一次状态变化。

## 练习一 识别可以复用的信息

给出 `[4, 1, 3, 2, 6]`，求连续三个数字的最大和。请先手算所有候选，再说明相邻候选的关系。

:::details 提示

从 `[4, 1, 3]` 变到 `[1, 3, 2]`，哪些值没有变？只需对哪两个值更新结果？

:::

:::details 解析

三个区间的和依次是 8、6、11。保存当前和，每次减去离开左端的值，再加上新进入右端的值。这里长度固定，不需要判断字符冲突；移动规则来自“必须恰好三个”，不是来自“不重复”。初始化第一段，再依次移动，时间 O(n)，额外空间 O(1)。如果数组长度不足三个，应由需求明确无解行为，不能将长度不足三的区间当作满足条件的答案。

:::

## 练习二 条件改为最多两种字符

`eceba` 中寻找最多包含两种不同字符的最长连续段。为什么不能直接沿用“同一字符出现就越过旧位置”的规则？

:::details 提示

`ece` 虽然重复了 `e`，却满足要求。真正触发冲突的是什么？移出一个 `e` 是否一定减少字符种类？

:::

:::details 解析

重复不再是冲突，第三种字符进入才是冲突。维护窗口内字符次数和不同字符种类数。右侧加入后若种类超过二，从左侧依次减次数，某个次数降到零时才删除该种类。恢复到最多两种后更新最大长度，结果为 `ece` 的 3。每个字符各进入和离开最多一次，在平均常数时间 Map 操作假设下时间 O(n)。

:::

## 练习三 判断移动依据是否失效

寻找元素和至少为 3 的最短连续子数组。有人说只要右扩直到和足够，再左缩直到和不够，就能处理任意整数。用 `[1, -1, 3]` 检查这个判断。

:::details 提示

总和达到 3 后，先删除 1，再删除 -1，区间和分别是什么？第一次变得不足是否能证明后面都不足？

:::

:::details 解析

总和为 3，删 1 后是 2，常见正数窗口会停止收缩，却错过再删 -1 后的 `[3]`。允许负数时，删除左端不保证和减小，原本的停止依据失效。可以先采用枚举起点并累加的 O(n²) 正确基线；需要进一步优化时，再学习前缀和与单调队列。窗口停止条件依赖于单调性；条件失效后需要重新选择搜索方式。

:::

## 解法复述检查

- 不看代码解释 `abba` 最后一个 `a` 为什么不能让左端后退
- 说明次数表与最近位置表各自保存的事实
- 用一个例子解释当前窗口长度和历史最大长度不同
- 说明某段被丢弃后为什么不会在右端继续移动时重新成为候选
- 把一题改成返回文本后说明要新增哪些记录

上述检查项用于记录思路掌握程度。算法名称不能替代状态含义与移动依据；编码能力另行通过独立实现验证。
