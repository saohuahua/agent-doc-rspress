# 0032 最长有效括号

相关基础：[本章基础](/leetcode/15-dp/)。题目来源：[力扣 32](https://leetcode.cn/problems/longest-valid-parentheses/)。

## 题目

:::info 题面

**难度**：困难

给只包含左右括号的字符串，找最长连续且配对正确的括号子串长度。允许空串，结果可以为零。连续是关键，不能删掉中间字符再配对。合法括号要求每个前缀左括号数量不少于右括号，最后两者相等；仅总数相等并不够，例如 )( 无效。

:::

### 官方示例

> **示例 1**
>
> 输入：s = "(()"
> 输出：2

> **示例 2**
>
> 输入：s = ")()())"
> 输出：4

> **示例 3**
>
> 输入：s = ""
> 输出：0

### 约束

- 0 <= s.length <= 3 * 10^4
- s[i] 为 '(' 或 ')'

## 前期思路

### 朴素方法与复杂度

固定起点向右扫描，用计数器遇左加一、遇右减一。计数负数时这一起点不可能得到更长合法串；计数为零时得到一个合法候选。遍历所有起点，时间 O(n²)。重复计算来自不同起点对同一合法内部区间的反复验证。若保存已匹配区间的长度，就有可能将其作为整体跳过，避免再次检查内部字符。

### 定义结尾状态

令 length[i] 表示必须以位置 i 结尾的最长合法括号子串长度。左括号不能作为非空合法串结尾，因此 s[i]='(' 时状态为0。右括号才可能完成一对，要找它对应的左括号在哪里。先看紧邻前方最长合法段，它长度为 length[i-1]，内部都已配好，可以整体跳过。

跳过后候选左括号位置为 open=i-length[i-1]-1。若这个位置不存在或不是左括号，当前右括号不能接成以它结尾的合法串，状态仍为零。这里不是在任意向左搜索左括号，因为跨越不合法字符会破坏连续性。

### 算法推导

如果 open 是左括号，它和当前右括号把中间已合法段包起来，新增长度为 length[i-1]+2。但还要检查 open 前面是否紧接另一个合法段。如果 open>0，可再接上 length[open-1]。因此总长度为内部长度加当前配对的2，再加左侧相邻合法段长度。

这个公式同时处理 () 与嵌套情况。紧前字符是左括号时 length[i-1]=0，open自然是i-1；紧前字符是右括号时，就跨过其已经匹配的合法后缀。每个完整合法括号串都能视为“此前合法串 + 最后这一对包住的合法串”，所以这一分解不会遗漏最长结尾方案。

从左向右计算，所有读取下标都小于i，依赖已经完成。全局答案取每个结尾状态最大值，不能只返回最后位置，因为尾部可能带有无法配对的括号。

### 变式分析与错误反例

- 错误只数左右括号总量在 )( 上会返回2，但答案0；错误只算内层加2在 ()(()) 上漏掉左侧连续部分。若增加多种括号，候选匹配还要验证类型，而不能只看左右方向。若改求最长合法子序列，允许跳过字符，原来强制相邻的连接关系就不是同一个问题，应重新定义状态。

## 执行过程示例

输入 ()(())，下标0到5。

| i字符 | 前段长度 | 候选open | 当前长度与原因 |
| --- | --- | --- | --- |
| 0左括号 | 无 | 无 | 0 不能结束合法串 |
| 1右括号 | 0 | 0 | 2 配成第一对 |
| 2左括号 | 2 | 不计算 | 0 |
| 3左括号 | 0 | 不计算 | 0 |
| 4右括号 | 0 | 3 | 2 配成内部一对 |
| 5右括号 | 2 | 2 | 内部2加外层2再接length[1]的2 等于6 |

最后一步最容易漏的是左侧 length[1]。只算内层加外层会得到4，漏掉紧邻的第一对。反过来，不能接任意更早的最佳值，只能接 open-1 这个相邻位置的状态。

## 解法复述与检查

- 为什么左括号状态为零？
- 候选匹配位置怎样算？
- 为什么还能接左侧一段？

:::details 算法概述

保存以每个位置结尾的最长合法长度。遇到右括号，先越过前一个位置已经配好的整段，再检查它前面的字符是不是左括号。是的话就包上这一对，并连接该左括号之前紧挨的合法段。所有结尾取最大，得到全局连续答案。

:::

## 复杂度与边界

- 每个位置常数次读取，时间 **O(n)**，辅助空间 **O(n)**，无递归栈，不修改输入。
- 空串和全同方向括号均返回0。
- open可能为负，必须先判断再读取；open=0时左侧没有可连接段，以零处理。
- 结果长度不超过输入长度，number精确。

## 分层提示

:::details 提示一 观察方向

合法串只能以右括号结束 已经合法的前段可以当成整体跳过

:::

:::details 提示二 需要的信息

记录每个位置结尾的合法长度 由它定位当前右括号可能配对的位置

:::

:::details 提示三 组织步骤

检查配对位置合法且为左括号 包住内部段 再连接左侧紧邻合法段 更新全局最大

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function longestValidParentheses(s: string): number {
  // 每项只表示强制在该位置结尾的最长合法连续段
  const length = new Array<number>(s.length).fill(0)
  let best = 0
  for (let i = 1; i < s.length; i++) {
    if (s[i] !== ')') continue
    // 跳过紧邻的已匹配段寻找当前右括号的候选搭档
    const open = i - length[i - 1] - 1
    if (open >= 0 && s[open] === '(') {
      length[i] = length[i - 1] + 2
      // 左侧相邻合法段可以与新配好的一段连接
      if (open > 0) length[i] += length[open - 1]
      best = Math.max(best, length[i])
    }
  }
  return best
}
```
