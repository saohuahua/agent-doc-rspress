# 0416 分割等和子集

相关基础：[本章基础](/leetcode/15-dp/)。题目来源：[力扣 416](https://leetcode.cn/problems/partition-equal-subset-sum/)。

## 题目

:::info 题面

**难度**：中等

给非空正整数数组，判断能否把所有元素分成两个子集，使两边元素之和相等。每个位置只能分配一次，两个相等数来自不同位置时可以分别选择。返回布尔值。子集不要求连续，也不要求保持相邻结构。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [1,5,11,5]
> 输出：true

> **示例 2**
>
> 输入：nums = [1,2,3,5]
> 输出：false

### 约束

- 1 <= nums.length <= 200
- 1 <= nums[i] <= 100

## 前期思路

### 朴素方法与复杂度

每个元素决定放左边或右边，最后比较两边总和，最多2的n次方种分配。但两边之和始终等于总和 total，因此如果 total 为奇数，根本不可能平分；若为偶数，只需找到一组元素恰好凑出 target=total/2，剩下的自然也是 target。

这个等价变换把两组的划分问题转化为单组的目标和问题，因为总和守恒已经决定另一组的和。接下来仍要解决大量不同选择会凑出相同小和的重复。

### 保存什么才不会复用元素

定义 reachable[sum] 表示在已经处理的元素中，是否能选择若干位置凑出 sum。初始只有零可以由空集凑出，其他都不行。每次加入一个新元素 value，可以不选它保留旧状态，或选它并依赖旧 reachable[sum-value]。

这里的“旧状态”是资源只能使用一次的关键约束。与无限硬币不同，当前元素只允许用一次，不能读到同一轮刚写出来且已包含当前元素的状态。完整二维表可以明确区分处理前后两层；压缩成一维时从大和向小和更新，让依赖下标更小且还没在本轮更新，仍代表上一层。

### 算法推导

算出总和，奇数直接返回false。创建长度 target+1 的布尔数组，reachable[0]=true。遍历每个数，对 sum 从 target 降到 value，更新 reachable[sum] 为旧值或 reachable[sum-value]。

不选和选两类覆盖每个子集，且每次选择都连接来自之前元素的状态，因此不会漏掉合法子集，也不会重复使用当前位置。由于元素为正，和超过 target 后不可能再通过加入元素降回来，所以只保留不超过 target 的状态就足够。

处理完所有位置，reachable[target] 为真就表示找到一边，另一边由未选位置组成。重复数不需要去重，因为它们是各自独立的可用位置，去重反而可能把必要资源删除。

### 变式分析与错误反例

- 错误正序更新会在 [1,2,5] 中把唯一的1反复使用，错误认为能凑4并返回true，但真实无法平分。若每个数可无限使用，正序恰好可以表达重复选取，说明方向取决于资源约束。若求具体两个子集，需要记录来源选择，单个布尔数组不能直接解释每个位置归属。

## 执行过程示例

输入 [1,5,11,5]，目标11，只列出每轮新增的可达和，未列出的旧可达和仍保留。

| 新元素 | 此前可达 | 新增可达和及原因 |
| --- | --- | --- |
| 1 | 0 | 1来自0加1 |
| 5 | 0 1 | 5和6分别来自0和1 |
| 11 | 0 1 5 6 | 11来自0加11 |
| 5 | 0 1 5 6 11 | 10来自旧5加5 其余不超过11结果已出现 |

两枚5能组成10，是因为分属不同轮次。与此相反，同一轮不能从新5再生成10，否则一枚5会被使用两次。

## 解法复述与检查

- 为什么只找总和一半就够？
- 为什么金额循环必须倒序？

:::details 算法概述

先检查总和是否为偶数，再把问题变成每个元素最多选一次凑出一半。布尔数组记录已处理元素能凑出的和，零由空集得到。处理新元素时倒序更新，保证读取的较小和仍是没用当前元素的旧状态。最后检查目标和是否可达。

:::

## 复杂度与边界

- 令 S 为总和的一半，时间 **O(nS)**，辅助空间 **O(S)**，无递归栈，不修改输入。
- 输出布尔值。
- 单元素为正所以不可能平分；元素大于目标时本轮没有更新。
- 题目正整数约束确保和的有限下标模型合理，若允许负数，状态范围和遍历方向都要重新设计。

## 分层提示

:::

:::details 提示二 需要的信息

记录已处理元素能凑出的和 每个新元素只有选与不选

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function canPartition(nums: number[]): boolean {
  const total = nums.reduce((sum, value) => sum + value, 0)
  if (total % 2 !== 0) return false
  const target = total / 2
  const reachable = new Array<boolean>(target + 1).fill(false)
  reachable[0] = true
  for (const value of nums) {
    // 倒序保证较小和仍属于尚未使用当前元素的上一轮
    for (let sum = target; sum >= value; sum--) {
      reachable[sum] = reachable[sum] || reachable[sum - value]
    }
  }
  return reachable[target]
}
```
