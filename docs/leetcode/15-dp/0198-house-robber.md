# 0198 打家劫舍

相关基础：[本章基础](/leetcode/15-dp/)。题目来源：[力扣 198](https://leetcode.cn/problems/house-robber/)。

## 题目

:::info 题面

**难度**：中等

一排房屋各有非负金额 nums[i]，不能同时选相邻两间，求能获得的最大总额。只求金额，不求选了哪些下标。数组非空。不是要求隔一间必选一间，也不是在奇数位置总和与偶数位置总和之间选择；可以按需要跳过多间。

:::

### 官方示例

> **示例 1**
>
> 输入：[1,2,3,1]
> 输出：4

> **示例 2**
>
> 输入：[2,7,9,3,1]
> 输出：12

### 约束

- 1 <= nums.length <= 100
- 0 <= nums[i] <= 400

## 前期思路

### 朴素方法与复杂度

每间房都有选与不选两种决策，枚举全部方案并筛掉相邻同时被选的方案，可以找到最大值，朴素上界 O(2^n)。例如 [2,7,9,3,1] 可以选2、9、1得到12。只选当前金额最大的9，并不能凭这个动作决定其余位置都如何处理。

### 优化依据

不同的后半段选择经常需要知道同一个前缀最多能拿多少。既然题目只要最优总额，可以保存“前 i 间房的最大合法收益”，记为 best[i]。这里 i 表示数量，所以 best[0] 是还没有房间可选时的0。这一约定让“跳过当前房”与“选当前房”都能连接到已经计算的前缀。

关键不是记住上一次实际选了哪间，而是把所有合法方案按最后一间是否被选分成两类。这样同一类需要的过去信息可以压缩成一个最优值，不必保留每个方案的完整路径。

### 算法推导

考虑当前第 i 间房。不选它时，收益等于前 i-1 间的最佳值。选它时，前一间必须不选，剩余选择只来自前 i-2 间，加上当前金额。因此 best[i]=max(best[i-1],best[i-2]+nums[i-1])。

前 i-2 间的最优解可以与当前房连接，因为当前房与那些房之间隔着未选的前一间，任何前缀合法方案都可以安全连接当前房。在这个类别中若不用最优前缀，只会让收益更低。两类覆盖所有方案，取最大就是完整问题的最优值。

初始化空前缀为0，第一间的最佳值为其金额。实现用两个变量都从0开始，第一轮直接计算 max(0,0+第一间金额)，等效完成第一间初始化。每轮旧的 oneBack 表示前一前缀最优值，twoBack 表示前两前缀最优值，新值只依赖它们，因此可以滚动保存。

### 变式分析与错误反例

- 错误比较奇数位置总和与偶数位置总和，在 [2,1,1,2] 得到3，但首尾两间不相邻可以得到4。若房屋连成环，首尾也相邻，原前缀推导不能直接处理同时选首尾。可以分别考虑不选首间或不选末间的两个线性问题，再取最大；单房单独处理。若要返回具体房屋，需要记录每个状态选择来源，两个数不足以恢复方案。

## 执行过程示例

输入 [2,7,9,3,1]。

| 当前金额 | 不选当前 | 选当前 | 当前最优 |
| --- | --- | --- | --- |
| 2 | 0 | 0+2 | 2 |
| 7 | 2 | 0+7 | 7 |
| 9 | 7 | 2+9 | 11 |
| 3 | 11 | 7+3 | 11 |
| 1 | 11 | 11+1 | 12 |

第四轮不选3，并不是判定3永远没有价值，而是在前四间这个问题中，不选3能保留更高收益。两个状态保存的是不同前缀的最优总额，不应误读为相邻两间房的金额。

## 解法复述与检查

- 为什么选当前只能接前两间之前的结果？
- 为什么取最大而不是相加？

:::details 算法概述

按最后一间是否选择分类。不选它就继承前一前缀的最好结果；选它必须跳过相邻前一间，因此使用前两前缀最优值加当前金额。两类取最大，从空前缀零开始向右计算，只保存最近两个最优值即可。

:::

## 复杂度与边界

- 时间 **O(n)**，辅助空间 **O(1)**，无递归栈，不修改 nums，输出常数空间。
- 单房直接由第一轮处理；全零结果零。
- 题目非负金额及规模保证 number 精确。
- 若金额允许负数且允许一间不选，零初始化仍合理；若强制至少选一间，则负数情形需要重新定义初始状态。

## 分层提示

:::details 提示一 观察方向

先按最后一间选还是不选分类 奇偶位置分组不能覆盖全部合法方案

:::

:::details 提示二 需要的信息

两类分别需要前一前缀与前两前缀的最佳金额

:::

:::details 提示三 组织步骤

空前缀为零 每间取不选收益和隔间加当前收益的较大者 保存最近两个结果

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function rob(nums: number[]): number {
  // 两个值表示前两前缀和前一前缀的最优合法收益
  let twoBack = 0
  let oneBack = 0
  for (const money of nums) {
    // 选择当前必须跳过相邻前房
    const current = Math.max(oneBack, twoBack + money)
    twoBack = oneBack
    oneBack = current
  }
  return oneBack
}
```
