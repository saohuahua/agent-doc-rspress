# 0118 杨辉三角

相关基础：[本章基础](/leetcode/15-dp/)。题目来源：[力扣 118](https://leetcode.cn/problems/pascals-triangle/)。

## 题目

:::info 题面

**难度**：简单

给定行数 numRows，返回杨辉三角前这些行。第一行为 [1]，每行两端为 1，内部元素等于上一行相邻两项之和。输入至少一行，最多三十行。输出是二维数组，每一行长度比前一行多一。题目已经给定局部生成规则，实现的关键是将该规则转换为准确的行列坐标。

:::

### 官方示例

> **示例 1**
>
> 输入: numRows = 5
> 输出: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]

> **示例 2**
>
> 输入: numRows = 1
> 输出: [[1]]

### 约束

- 1 <= numRows <= 30

## 前期思路

### 朴素方法与复杂度

先写 [1]，下一行两端都是 1，于是得到 [1,1]。第三行中间来自上一行的 1 和 1，得到 [1,2,1]。继续写第四行，内部第一个数来自 1+2，第二个来自 2+1，得到 [1,3,3,1]。逐行生成与输出需求直接一致，已经能够保证每个输出位置只计算一次。

### 状态定义与依赖

每一个内部位置只需要上一行两项。设行下标从零开始，当前第 row 行有 row+1 项，位置 col 的两个来源为上一行 col-1 和 col。坐标差来自三角形每行增加一个位置，而不是两个来源都来自当前行。上一行是已完成的事实，当前行是正在写的新结果。

这里的重复计算风险来自每次求一个位置时递归向上重新展开。例如第四行两个中间数都依赖第三行的中间值，如果递归不缓存，就会反复算同一格。逐行保存既与输出需求一致，也让每个位置只计算一次。该过程属于按行推进的动态规划，依赖关系直接来自题目给定的局部生成规则。

### 算法推导

每次先创建长度 row+1、填满 1 的新数组，边界自然就有正确值。再遍历 col=1 到 row-1 的内部位置，读取 result[row-1][col-1] 与 result[row-1][col] 相加。完成整行后加入结果。

第一行不会读取不存在的上一行，因为 row=0 时内部循环为空，只保留单个 1。第二行也没有内部项，同样不会误读。到了第三行，上一行已经加入结果，可以安全依赖。该循环范围来自“内部项排除两端”的定义。

所有边界按定义正确，若上一行正确，本行每个内部值按题目规则计算也正确。因此逐行推进能够得到全部结果。总输出本来就有 numRows*(numRows+1)/2 个数，显式输出这些数本身就需要对应数量的写入，因此逐格生成已经达到输出规模的时间下界。

### 变式分析与错误反例

- 若只返回第 r 行，可以只保存最近一行，空间 O(r)。若在同一数组内更新，要从右向左，否则新值会污染还未使用的旧左邻居。错误从左向右更新 [1,2,1]，算出新第二项3后再用它算下一项，会得到4而非3。若仍要求全部行，不能只保留一个可变数组引用，输出需要独立行。

## 执行过程示例 前四行

| 行下标 | 创建边界后 | 内部计算 | 完整行 |
| --- | --- | --- | --- |
| 0 | [1] | 无内部位置 | [1] |
| 1 | [1,1] | 无内部位置 | [1,1] |
| 2 | [1,1,1] | col1来自1+1 | [1,2,1] |
| 3 | [1,1,1,1] | col1来自1+2 col2来自2+1 | [1,3,3,1] |

每行必须是独立数组。前端里多个组件共享同一个可变对象会互相影响，在这里多行共享同一个数组也会让后续写入污染历史结果。

## 解法复述与检查

说明上一行两个来源的坐标，以及为什么第一行不会越界。

:::details 算法概述

按行生成，每行先把两端设成一，再让内部位置等于上一行左上和右上之和。每行完成后保存到结果，下一行只读取已完成的上一行。前两行没有内部位置，因此不用特殊访问不存在的上一行。每个输出格子只生成一次。

:::

## 复杂度与边界

- 时间 **O(r²)**，其中 r 为行数。
- 输出空间 **O(r²)**，若排除输出存储，除正在构建且最终属于输出的一行外只用常数个变量，没有额外递归栈。
- 更保守计正在构建行的峰值临时空间为 **O(r)**。
- 输入数字不修改，三十行以内系数可由 number 精确表示。

## 分层提示

:::details 提示一 观察方向

先手写四行 区分两端固定值和内部生成值

:::

:::details 提示二 需要的信息

内部第 col 项依赖上一行的 col 与 col减一 两个值

:::

:::details 提示三 组织步骤

逐行创建独立数组 两端填一 内部读取上一行 完成后加入结果

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function generate(numRows: number): number[][] {
  const result: number[][] = []
  for (let row = 0; row < numRows; row++) {
    // 每行独立创建以避免后续写入污染历史行
    const current = new Array<number>(row + 1).fill(1)
    for (let col = 1; col < row; col++) {
      // 内部位置只读取已经完成的上一行
      current[col] = result[row - 1][col - 1] + result[row - 1][col]
    }
    result.push(current)
  }
  return result
}
```
