# 0152 乘积最大子数组

相关基础：[本章基础](/leetcode/15-dp/)。题目来源：[力扣 152](https://leetcode.cn/problems/maximum-product-subarray/)。

## 题目

:::info 题面

**难度**：中等

给非空整数数组，寻找乘积最大的非空连续子数组，返回乘积值。连续意味着不能跳过中间项，非空意味着不能凭空选择乘积一。数组包含负数、零和正数。乘法遇到负数会改变大小顺序，这决定了不能只套用最大子数组和的单个状态。

:::

### 官方示例

> **示例 1**
>
> 输入: nums = [2,3,-2,4]
> 输出: 6

> **示例 2**
>
> 输入: nums = [-2,0,-1]
> 输出: 0

### 约束

- 1 <= nums.length <= 2 * 10^4
- -10 <= nums[i] <= 10
- nums 的任何子数组的乘积都 保证 是一个 32-位 整数

## 前期思路

### 朴素方法与复杂度

固定起点，向右逐个乘入元素，比较每个终点的乘积。这样每条连续区间都被检查，时间 O(n²)，只需常数个变量。若每个区间重新从头相乘会达到 O(n³)，先复用同起点的乘积已能消除一层重复。还想更快，需要看固定终点的多个区间之间能否只保存少量代表。

### 负数乘法与双极值状态

以 [-2,3,-4] 为例，到3结尾时有乘积3和-6。只保留最大3，接上-4只能得到-12，却丢掉-6乘-4=24。负数会让最小值变成最大值的有力候选。因此需要同时保存“以当前位置结尾的最大乘积”和“以当前位置结尾的最小乘积”。

同时保存两个极值的依据是乘法单调性：乘正数保持顺序，乘负数反转顺序，乘零全部变零。所有历史结尾乘积中，经过同一个数乘法后成为最大或最小的，必定来自原来的两个极值之一。中间值没有必要保留。

### 算法推导

处理当前 x，以它结尾的区间只有两类：只选 x 自己，或者把 x 接在前一个位置结尾的某个区间后面。根据极值分析，只需比较 x、旧最大*x、旧最小*x 三个候选。新最大取max，新最小取min。

两个新状态都依赖旧状态，必须先保存旧最大，不能更新最大后又拿新最大计算最小。初始最大、最小和全局答案都设为首元素，让非空约束自然成立。之后从第二项开始推进，每轮用新最大更新全局最大。

全局答案需要单独维护，因为当前末尾状态强制包含当前位置，遇到零或不利负数时可能变小，但早先的最佳子数组仍然存在。最后一轮的状态不一定是全数组最佳。

### 变式分析与错误反例

- 若所有数非负，也仍要考虑小于一的小数会使延长变差，不能把本题整数前提默默扩展。若题目保证都是正整数，整个数组乘积可作为最大，但零会把数组分段，负数又引入奇偶与极值。错误只保留最大值在 [-2,3,-4] 直接漏掉24；错误每轮先覆盖最大再算最小会把不存在的重复当前元素乘积引入后续状态。

## 执行过程示例

输入 [-2,3,-4]。

| 位置 | 三个候选 | 当前最大 | 当前最小 | 全局最大 |
| --- | --- | --- | --- | --- |
| 首项-2 | 初始化 | -2 | -2 | -2 |
| 3 | 3 -6 -6 | 3 | -6 | 3 |
| -4 | -4 -12 24 | 24 | -12 | 24 |

到第二行，最小值-6虽然不是眼前答案，却包含未来可能转正的价值。若换成 [-2,0,-1]，遇零后三个候选都归零；下一项可以从-1重新开始，全局答案保持0，因此不用额外写清空区间的特殊分支。

## 解法复述与检查

- 为什么保留最小乘积？
- 为什么三个候选里必须有当前元素本身？

:::details 算法概述

保存以前一个位置结尾的最大和最小乘积，因为负数会交换大小关系。当前区间要么重新从当前数开始，要么连接旧区间，只需检查当前数与两个旧极值乘当前数的三个候选。同步算出新极值，再更新全局答案。

:::

## 复杂度与边界

- 每个元素常数次乘法比较，时间 **O(n)**，辅助空间 **O(1)**，无递归栈，不修改输入。
- 单负数返回它本身，不允许选择空区间返回零。
- 题目对乘积范围有限制，按该约束 number 可精确计算；若改成任意大整数数组，必须重新考虑溢出和精度，不能仅保证最终答案小就假定所有中间乘积安全。

## 分层提示

:::details 提示一 观察方向

用负二 三 负四检查只保留最大乘积是否足够

:::

:::details 提示二 需要的信息

乘负数会反转大小顺序 最小结尾乘积也必须保留

:::

:::details 提示三 组织步骤

当前数单独开始或连接旧最大旧最小 同步更新两个极值 再更新全局最大

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function maxProduct(nums: number[]): number {
  let largest = nums[0]
  let smallest = nums[0]
  let best = nums[0]
  for (let i = 1; i < nums.length; i++) {
    const value = nums[i]
    // 两个新状态必须共同读取上一轮的极值
    const oldLargest = largest
    largest = Math.max(value, oldLargest * value, smallest * value)
    smallest = Math.min(value, oldLargest * value, smallest * value)
    best = Math.max(best, largest)
  }
  return best
}
```
