# 0279 完全平方数

相关基础：[本章基础](/leetcode/15-dp/)。题目来源：[力扣 279](https://leetcode.cn/problems/perfect-squares/)。

## 题目

:::info 题面

**难度**：中等

给一个正整数 n，要把它写成若干完全平方数之和，返回最少项数。完全平方数是整数的平方，如1、4、9、16，同一个数可多次使用。12可以写成4+4+4，所以答案是3；不能因为9更大就先选9然后认定后面只能三个1。

:::

### 官方示例

> **示例 1**
>
> 输入：n = 12
> 输出：3

> **示例 2**
>
> 输入：n = 13
> 输出：2

### 约束

- 1 <= n <= 10^4

## 前期思路

### 朴素方法与复杂度

从剩余总和 n 出发，尝试减去每个不超过它的平方数，再继续尝试，减到零就得到一种表示。比较所有表示的项数得到最小值。这能解决问题，但同一个剩余和会通过不同选择顺序被反复触发，比如先减1再减4与先减4再减1。

### 从重复中保存答案

后续需要几项只由剩余和决定，与此前选了哪些平方数无关。因此定义 best[sum] 为恰好凑出 sum 的最少项数。状态保存最小数量，不保存一种未经最优性证明的局部选择。因为平方数都为正，新状态只会依赖更小总和，可以从零开始向上填表。

这与爬楼梯都能问最后一个动作，但合并规则不同：爬楼梯统计所有路线，因此把互斥类别数量相加；本题只求最少项数，所以在各个最后平方数候选中取最小，不能把各方案项数相加。

### 算法推导

设最后用了平方数 k*k，那么此前需要恰好凑出 sum-k*k，再加一项。候选就是 best[sum-k*k]+1。遍历所有 k*k<=sum，取最小。best[0]=0，因为凑出零不用任何项。其余先设为 Infinity，表示当前尚无已确认方案，该标记不表示数学上的最少项数为无穷大。

该转移覆盖全部方案：每个非空表示都有最后一项，其平方根一定会被循环枚举。固定最后一项后，若前面的表示不是剩余和的最少方案，替换成更少项方案会改善整体，所以最优方案一定可以由某个最优子问题扩展。枚举全部最后项并取最小，不会遗漏最佳情况。

sum 从1递增，读取的下标都更小，已经计算完成。由于平方数1永远可用，任何正整数最终都能表示成若干1，所有状态都会从 Infinity 更新为有限值，不需要返回无解的特殊值。

### 变式分析与错误反例

- 贪心每次选最大平方数在12上给出9+1+1+1，比4+4+4多一项。若每个平方数只能用一次，当前状态定义下随意读取以前总和可能复用同一个数，需要增加“允许使用哪些平方数”的阶段信息或改用物品外层且倒序容量。若求表示方案数量，则最小值合并要改成计数，并先明确不同顺序是否算不同方案。

## 执行过程示例 总和不超过十二

| 总和 | 参与比较的候选 | 最少项数 |
| --- | --- | --- |
| 1 | best[0]+1 | 1 |
| 2 | best[1]+1 | 2 |
| 3 | best[2]+1 | 3 |
| 4 | best[3]+1 与 best[0]+1 | 1 |
| 5 | best[4]+1 与 best[1]+1 | 2 |

继续同样步骤得到 best[6]=3、best[7]=4、best[8]=2、best[9]=1、best[10]=2、best[11]=3。到12，最后用1得到4项，最后用4得到best[8]+1=3项，最后用9得到best[3]+1=4项，所以选3。这些中间状态给出了计算12时所需的全部依赖。

## 解法复述与检查

- 为什么最大平方数不一定属于最少方案？
- 每个状态具体存什么，初始零是什么意思？

:::details 算法概述

按最后一个平方数枚举方案，固定它后只需知道剩余总和的最少项数。保存每个总和的最少项数，从零项凑出零开始，按总和递增计算。每个合法平方数提供剩余答案加一的候选，取最小。最后读取 n 对应状态。

:::

## 复杂度与边界

- 共有 n 个状态，每个最多尝试根号 n 个平方数，时间 **O(n√n)**，辅助空间 **O(n)**，无递归栈，不修改输入。
- 输出一个整数。
- n本身是平方数时会比较到best[0]+1，得到1。
- 题目范围内平方及数量均可由 number 精确保存。

## 分层提示

:::details 提示一 观察方向

最后一项可能是哪些平方数 先全部考虑而不是只取最大的

:::

:::details 提示二 需要的信息

同一个剩余总和的最少项数会重复出现 可以记下来

:::

:::details 提示三 组织步骤

零的项数为零 从小总和开始 枚举最后平方数 在剩余最少项数加一中取最小

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function numSquares(n: number): number {
  // 每个总和保存最少项数而零不需要任何项
  const best = new Array<number>(n + 1).fill(Infinity)
  best[0] = 0
  for (let sum = 1; sum <= n; sum++) {
    for (let root = 1; root * root <= sum; root++) {
      // 当前平方数作为最后一项连接更小总和
      best[sum] = Math.min(best[sum], best[sum - root * root] + 1)
    }
  }
  return best[n]
}
```
