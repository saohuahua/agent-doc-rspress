# 动态规划复习 状态含义与依赖关系

本节检查以下推导：为什么按最后一步分类，为什么两类能相加，两个初始值从哪里来，为什么从小到大算，以及为什么只保留两个值仍然足够。

## 练习一 识别需要复用的信息

一条直线有编号 0 到 6 的位置，每次向前走一格或两格，问从 0 到 6 有多少条路线。比较它与楼梯计数在允许动作和计数对象上的对应关系。说明它与样题是否等价，并算出结果。

:::details 提示

最后一步到达位置 6 时，出发点只能是哪两个位置？

:::

:::details 解析

等价，因为位置递增且允许步长相同。位置 1 和 2 分别有 1 和 2 条路线，此后得到 3、5、8、13，所以答案为 13。表面故事改变，没有改变状态依赖。

:::

## 练习二 步长改变

现在每次只能走一阶或三阶。到第四阶有几种走法？原来的公式为什么不能直接使用？

:::details 提示

重新按最后一步分类，检查前驱位置是否随步长改变。

:::

:::details 解析

到第四阶有 `1111`、`13`、`31` 三种。前驱变成 `i - 1` 和 `i - 3`。可以定义零阶有一种空路线，负数阶有零种，从而得到一阶 1、二阶 1、三阶 2、四阶 3。若做空间压缩，需要保留后续会读到的三个历史位置，不能继续机械使用两个变量。

:::

## 练习三 原状态何时失效

仍然允许一阶或两阶，但禁止连续两次走两阶。只记“到达第 i 阶的总路线数”是否够用？用第四阶举例。

:::details 提示

到达第二阶的 `11` 和 `2` 能否都继续走两阶？

:::

:::details 解析

不够。`11` 可以继续走两阶，`2` 不可以。因此必须区分最后一步类型，例如分别保存以一阶结尾和以两阶结尾的路线数。新的两阶结尾路线只能由前两阶的一阶结尾路线扩展。第四阶原来的五种路线去掉 `22`，剩下四种。错误在于丢掉了会影响下一步资格的历史信息。

:::

## 理解检查

对任一变式，说明状态的完整含义、分类依据、依赖关系和合并方式。状态定义不明确时，可对照样题的“状态定义与转移依据”重新分析。
