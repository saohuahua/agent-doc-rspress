# 0300 最长递增子序列

相关基础：[本章基础](/leetcode/15-dp/)。题目来源：[力扣 300](https://leetcode.cn/problems/longest-increasing-subsequence/)。

## 题目

:::info 题面

**难度**：中等

给非空整数数组，求最长严格递增子序列的长度。子序列保持原来的相对顺序，但可以跳过元素；严格递增意味着相等不能接在后面。例如 [10,9,2,5,3,7,101,18] 可以取 [2,3,7,18]，长度4。不要求连续，也不要求输出具体序列。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [10,9,2,5,3,7,101,18]
> 输出：4

> **示例 2**
>
> 输入：nums = [0,1,0,3,2,3]
> 输出：4

> **示例 3**
>
> 输入：nums = [7,7,7,7,7,7,7]
> 输出：1

### 约束

- 1 <= nums.length <= 2500
- -10^4 <= nums[i] <= 10^4

### 进阶要求

尝试把时间复杂度降到 O(n log n)。

## 前期思路

### 朴素方法与复杂度

每个元素选或不选，列出全部子序列，过滤非递增并比较长度，最多有2的n次方种选择。也可能想从每个位置尽可能接下一个更大元素，但接哪个会影响未来：较大的早期选择可能挡住更多后续元素。局部选择下一项尚无最优性保证，可以改为按末尾位置对候选分组，再比较同组内哪些信息足以保留。

### 状态定义与依赖

若只保存“前 i 个元素的最长长度”，不知道这条序列以什么数结尾，就无法判断当前数能否接上。例如同长度的 [1,100] 和 [1,2] 对接3的能力完全不同。因此定义 length[i] 为必须以 nums[i] 结尾的最长严格递增子序列长度。这句话中的“必须”让末尾值已知，使下一次连接可以判定。

固定末尾位置后，不必保留同末尾的所有序列，只保留最长的一条长度，因为接上同一个更大数时，较短的不会更有优势。状态的关键是既保留未来需要的末尾信息，又压缩不再需要的内部历史。

### 算法推导

每个元素单独都能成为长度1的序列，所以所有 length 初始化为1。处理 i 时枚举此前 j<i，只在 nums[j]<nums[i] 时考虑接上当前值，候选为 length[j]+1。取所有候选与1的最大值。

任何以 i 结尾且长度超过1的合法序列，都有一个倒数第二位置 j，它必须在左边且值更小；枚举覆盖这些 j。如果对应前缀不是以 j 结尾的最长序列，把它替换成长序列不会改变末尾值，因此仍能接 i，并让结果更好。这个替换说明只保存最优长度足够。

按 i 从左向右计算保证所有 j 的状态已完成。最终答案是所有 length[i] 的最大值，不一定在最后位置。把 length[n-1] 当答案，会在数组末尾很小的时候漏掉前面的长序列。

### 变式分析与错误反例

- 若改为非递减，连接条件从小于改成小于等于，[2,2] 的答案从1变2。若改成连续子数组，就只能接相邻前驱，不应枚举任意 j。错误直接排序会改变顺序：[3,1,2] 排序后长度3，但原题最多2，因此排序得到的是另一个问题。

## 执行过程示例

输入 [3,1,2,2,4]。

| 下标和值 | 可以连接的前驱 | 当前末尾最长长度 |
| --- | --- | --- |
| 0 值3 | 无 | 1 |
| 1 值1 | 无 | 1 |
| 2 值2 | 下标1值1 | 2 |
| 3 值2 | 下标1值1 不能接相等的2 | 2 |
| 4 值4 | 前面所有位置 最佳前驱长度2 | 3 |

两次出现2分别是不同末尾位置，但严格条件使它们不能串联。表中答案3对应 [1,2,4]，不是把两个2都拿来变成4。

## 解法复述与检查

- 为什么状态要强调以当前元素结尾？
- 为什么最后取全表最大值？

:::details 算法概述

按结尾位置分组。每个元素单独是长度一，遍历它前面的更小元素，把那些位置的最长长度加一作为候选。固定末尾后较短方案没有优势，所以只保留最长。所有位置算完取最大，因为最优序列可能在中间结束。

:::

## 复杂度与边界

- 双层遍历时间 **O(n²)**，辅助空间 **O(n)**，无递归栈，不修改数组，输出一个长度。
- 这是清晰的基础主解；题目的 **O(n log n)** 进阶可以在掌握状态后学习“每种长度的最小末尾”与二分，但不能把进阶要求冒充本实现已满足。
- 单元素为1，全相等也为1，负数只影响比较不影响状态。

## 分层提示

:::details 提示一 观察方向

当前数能否接上已有序列 取决于它的末尾值而不只是长度

:::

:::details 提示二 需要的信息

分别保存每个位置作为末尾时的最佳长度 末尾值因此已知

:::

:::details 提示三 组织步骤

先设单元素长度一 从左到右枚举更小前驱做加一候选 全表取最大

:::

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function lengthOfLIS(nums: number[]): number {
  // 每项必须以当前位置结尾因此单元素初始长度为一
  const length = new Array<number>(nums.length).fill(1)
  let best = 0
  for (let i = 0; i < nums.length; i++) {
    for (let j = 0; j < i; j++) {
      if (nums[j] < nums[i]) length[i] = Math.max(length[i], length[j] + 1)
    }
    // 全局答案可能在任意位置结束
    best = Math.max(best, length[i])
  }
  return best
}
```
