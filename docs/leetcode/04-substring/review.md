# 子串复习与迁移

## 练习一 和为目标改成最长

[1,-1,5,-2,3] 中求和为 3 的最长区间长度，前缀表该保存次数吗？

:::details 提示与解析

应保存每个前缀首次出现的位置。相同右端下，越早的匹配前缀使区间越长。本例前四项和为 3，长度 4。初始空前缀位于元素之前。已有键不覆盖，避免丢掉最早位置。

:::

## 练习二 固定窗口改求最小值

[3,1,2,0]，k 为 2，怎样改候选淘汰规则？

:::details 提示与解析

新来的更小或相等值可以替代旧大值，队列值改为递增；过期规则不变。输出依次为 1、1、0。改变比较方向有依据，不需要改变下标判断。

:::

## 练习三 覆盖改成有序子序列

s 为 BA，t 为 AB，字符计数是否足够判断覆盖？

:::details 提示与解析

若仍只要求无序覆盖，BA 合法；若要求出现顺序与 AB 一致，BA 不合法。计数已丢失顺序信息，需要保存匹配进度等新状态。不能用同一缺额表回答改变后的问题。

:::

## 解法复述检查

能否解释空前缀、重复前缀次数、候选被替代的证据和缺额变负的意义。拿到题目先写出朴素枚举真正反复计算的内容，再选对应记录方式。
