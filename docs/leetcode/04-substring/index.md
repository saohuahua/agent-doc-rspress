# 子串基础

## 子串 子数组与子序列

本章题目名称归在子串，但实际既有字符串也有数组。子串和子数组都要求原位置连续；子序列可以跳过中间元素。连续区间由起点终点决定，长度 n 的输入有 n(n + 1) / 2 个非空区间，所以简单枚举所有区间通常是平方级。

先读[滑动窗口基础](/leetcode/03-sliding-window/)与[哈希基础](/leetcode/01-hash/)。本章不会把所有连续区间都当成一个模板，而是根据查询目标分别保存累计值、候选下标或字符缺额。

## 前缀和 把区间计算改写成两端关系

数组 [2,-1,3] 的前缀和依次是 0、2、1、4。开头的零代表尚未读取元素。若 P[i] 表示前 i 项之和，那么下标 left 到 right 的和是 P[right + 1] - P[left]。前面的共同部分被相减抵消，留下恰好需要的区间。

这里前缀的下标表示已取元素数量，不直接等于原数组元素下标。把定义写清，可以避免最常见的一位偏移。求某区间的和时，两端前缀查询即可；求和为 k 的区间数量时，则把式子改写成寻找历史前缀 P[right + 1] - k。

相同前缀值可能对应不同位置，比如零元素或正负抵消。输出是数量就记出现次数，输出最长长度就可能记最早位置。状态内容由答案要求决定，不应所有题都存同一种 Map 值。

## 窗口最大值与候选队列

固定窗口和可以减去离开值、加上进入值，最大值却没有类似的减法。最大值离开后，需要确定剩余元素中的最大值，因此只存一个最大数不够。一个更晚且更大的元素能完全替代旧小元素，因为它不会更早过期，也不会更差。

双端队列是一种允许两端删除的序列。单调候选队列让候选值递减，从尾部清掉被新值替代的项，从头部清掉过期项。下标同时提供值的查询入口与过期时间。每项只进出有限次数，才能得到线性总时间。

JS 的数组 shift 会移动后续元素，不应直接当作常数时间出队。本教材使用 head 索引前进，时间明确，但被略过的槽位仍可能占内存，所以相应实现记为 O(n) 物理空间。有效候选数量与实际分配容量是两个不同指标。

## 覆盖窗口与字符缺额

目标 AAB 要两份 A 和一份 B，窗口 AB 只有两种字母但并未覆盖。可用计数表示每个目标字符还缺多少份，零是刚好，负数是多余。另存总缺份数，避免每次重新比对所有字符。

右端扩张直到覆盖，再从左端删除无关或多余字符，尽量缩短；删到缺少必需份数时再扩张。这个动作依据来自覆盖条件对添加字符的稳定性。与和相关的题允许负数时，不具备同样的变化方向，不能见到“连续”就套扩缩模板。

## 不同查询目标的状态选择

方法选择首先取决于输出目标。精确等于目标和且允许负数，优先尝试前缀差关系；固定长度每窗求最大，寻找可淘汰的候选；覆盖需求且求最短，考虑什么时候满足及何时失效。算法名称是推导后的摘要，判断依据必须落到可复用信息和安全删除条件上。
