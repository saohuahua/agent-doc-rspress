# 0239 滑动窗口最大值

阅读前提：[本章基础](/leetcode/04-substring/)。[官方题目](https://leetcode.cn/problems/sliding-window-maximum/)。

## 题目

:::info 题面

**难度**：困难

一个固定长度 k 的窗口从数组左端逐格移动，每次报告窗口内最大值。输出长度为 n - k + 1。k 在 1 到 n 之间，数字可以为负。

相关概念见[滑动窗口基础](/leetcode/03-sliding-window/)。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
> 输出：[3,3,5,5,6,7]

> **示例 2**
>
> 输入：nums = [1], k = 1
> 输出：[1]

### 约束

- 1 <= nums.length <= 10^5
- -10^4 <= nums[i] <= 10^4
- 1 <= k <= nums.length

## 前期思路

### 朴素方法与复杂度

每移动一次就把 k 个数全部看一遍，找最大值。总共有 O(n) 个窗口，所以时间 O(nk)。上一窗口的最大值如果还在，似乎可以直接复用；但它一旦移出，还需要保留后续可能成为最大值的候选，不能只保存一个最大数字。

为每个窗口重新排序更浪费，因为排序获取了许多题目不要求的顺序。优化需要区分仍可能成为最大值的旧元素与已被新元素完全替代的旧元素。

### 从被替代的候选推导结构

假设旧元素为 3，新来的元素为 5。5 更大，而且更晚进入，也更晚过期。从现在开始，只要某个后续窗口还包含旧的 3，就一定也包含新的 5，因此 3 不可能再负责最大值，可以删掉。相等也一样，新值至少同样好且更晚离开窗口。

如果旧元素是 7，新来 5，就不能删 7，因为当前它更大；也不能删 5，因为 7 先过期，5 之后可能成为最大值。所以候选应按进入顺序排列，但对应数值从大到小。新值从队尾淘汰被它压制的候选，过期值从队头删除，队头就是当前最大值。

这就是双端队列的需求：两头都能删除，尾部能添加。候选值保持递减，所以也称单调队列。存下标而不是只存数值，是为了判断何时离开窗口。

### 算法推导与正确性

处理 right 时，合法窗口左端是 right - k + 1，队头下标若小于它就过期。然后从尾部删除所有值不大于新值的候选，再加入当前下标。窗口凑够 k 项后，输出队头对应的值。

队列下标递增，因为按读取顺序加入；值递减，因为加入前删掉了不更大的尾部。队头未过期，其他候选更晚也不会过期。每个删除的尾部元素都被一个更晚且不小的元素替代，因此删除不会损失未来最大值。两个性质共同保证队头既合法又最大。

### 变式分析与错误反例

- 递减数组中每个新数都更小，不能从队尾删除旧值，但最旧最大值过期时必须删除；忘记过期判断会让 [3,2,1]、k 为 2 输出 [3,3]，正确为 [3,2]。k 为一时每次输出当前值，相同值序列也应保留最新位置即可。
- 若改求最小值，把淘汰方向反过来，保留递增候选。若要求严格 O(k) 物理空间，可以实现容量 k 的循环双端队列或定期压缩无效前缀，需另外保证每次操作总成本，而不能把 shift 当成常数。

## 解法复述与检查

- 为什么新大值可以删除旧小值？
- 为什么小的新值还要保留？
- 为什么不能只存数值？

:::details 解法概述

保存仍可能成为最大值的候选下标。每轮先移除已离开窗口的队头，再从队尾删除数值不大于新元素的候选，因为新元素更晚过期且数值不小。加入当前下标后，候选下标递增而对应值递减。窗口长度达到要求时，队头对应值就是当前最大值。

:::

## TypeScript 实现

```ts
export function maxSlidingWindow(nums: number[], k: number): number[] {
  // 队列存下标以同时判断大小和是否过期
  const deque: number[] = []
  let head = 0
  const result: number[] = []
  for (let right = 0; right < nums.length; right++) {
    if (head < deque.length && deque[head] <= right - k) head++ // [!code highlight]
    // 更晚且不小的元素能完全替代尾部候选
    while (head < deque.length && nums[deque[deque.length - 1]] <= nums[right]) deque.pop() // [!code highlight]
    deque.push(right)
    if (right >= k - 1) result.push(nums[deque[head]])
  }
  return result
}
```

## 复杂度与边界

- 每个下标入队一次，最多从头或尾离开一次，虽然有内层 while，总时间 **O(n)**。
- 这里用 head 前移代替 Array.shift，避免搬动数组造成线性出队。
- 实现没有回收 head 前方的旧槽位，因此物理数组辅助空间为 **O(n)**，不能因为有效候选最多 k 项就声称此实现 **O(k)**。
- 输出占 **O(n - k + 1)**，无递归，不修改输入。
