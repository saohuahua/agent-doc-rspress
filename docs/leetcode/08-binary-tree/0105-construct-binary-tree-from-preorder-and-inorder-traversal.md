# 0105 从前序与中序遍历序列构造二叉树

相关基础：[本章基础](/leetcode/08-binary-tree/)。[官方题目](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)。

## 题目

:::info 题面

**难度**：中等

已知同一棵树的前序与中序值序列，恢复树。题目保证节点值互不相同，两序列长度相同且是合法配对。前序是根左右，中序是左根右。单独一个序列通常无法确定形状，本题组合利用一个序列识别根，另一个序列识别左右边界。

题面配图用节点和左右连线表示树；示例中作为树的数组按层序列出节点，`null` 表示对应的孩子不存在。数组表示的是连接结构，不要求按数值排序。

:::

### 官方示例

> **示例 1**
>
> 输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
> 输出: [3,9,20,null,null,15,7]

> **示例 2**
>
> 输入: preorder = [-1], inorder = [-1]
> 输出: [-1]

### 约束

- 1 <= preorder.length <= 3000
- inorder.length == preorder.length
- -3000 <= preorder[i], inorder[i] <= 3000
- preorder 和 inorder 均 无重复 元素
- inorder 均出现在 preorder
- preorder 保证 为二叉树的前序遍历序列
- inorder 保证 为二叉树的中序遍历序列

## 前期思路

### 朴素方法与复杂度

先手工看前序第一项，它一定是整树根。在中序找到这个值，左侧全部属于左子树，右侧全部属于右子树。接着对两边做相同分析。最直接实现每轮在中序区间线性找根，并用 slice 拆数组，但退化树上反复查找和切片可能 O(n²)。核心推导可以保留，只改信息获取方式。

### 优化依据

中序每个值的位置不会变化，而且值唯一，所以先建立“值 → 中序下标”的表，之后找分界平均 O(1)。左右子问题只需传中序边界，不需拷贝数组。前序按根左右顺序消费，使用一个全局游标 nextRoot 就能给每个子问题取下一个根，但这要求严格先建左边再建右边。

### 算法推导

build(left,right) 表示构造中序闭区间覆盖的子树。空区间返回 null，不消费前序。非空时取 preorder[nextRoot] 作为根并推进游标，用位置表取得 middle。再递归构造左区间与右区间。

为什么一个游标不会把左右混淆？当前根之后，前序连续给出整棵左子树的节点，再给出右子树节点；左边递归通过它的中序区间大小恰好消费那一批值，返回后游标自然停在右子树根。因此必须先调用左边。

正确性由两种遍历定义保证：根身份由前序确定，左右成员由中序根位置唯一划分，递归对子区间使用同样规则。每次去掉根后区间缩小，最终每个值创建一次。合法且值唯一的前提支撑唯一重建，不负责修复损坏输入。

### 变式分析与错误反例

- 错误反例：前序 [1,2,3]，中序 [2,1,3]，若在取根 1 后先构造右边，游标却拿到 2，违反右边应为 3 的成员边界。若有重复值，Map 单一下标无法唯一标记每个出现位置，当前推导不成立。
- 若改成中序与后序，后序末项是根，反向游标应先构造右边再左边；改变的是消费方向与子树顺序。只有前序与后序一般不能唯一还原含单孩子节点的二叉树，需要额外条件，不能机械套这里的分界方法。

## 执行过程示例

前序 [3,9,20,15,7]，中序 [9,3,15,20,7]。

| 当前中序区间 | 消费的根 | 中序分界 | 接下来 |
| --- | --- | --- | --- |
| 0 到 4 | 3 | 下标 1 | 左 0到0 右2到4 |
| 0 到 0 | 9 | 下标 0 | 两边空 |
| 2 到 4 | 20 | 下标 3 | 左2到2 右4到4 |
| 2 到 2 | 15 | 下标 2 | 两边空 |
| 4 到 4 | 7 | 下标 4 | 两边空 |

顺序清楚地展示游标为什么先给 9，再给 20，而不是看到右区间更大就先处理它。

## 解法复述与检查

复述检查：

- 前序与中序分别提供哪类信息？
- 游标为什么必须先消费左子树？
- 空区间是否应该推进前序游标？

:::details 算法概述

前序下一项确定当前子树的根，中序中根的位置确定左右分别有哪些节点。预先记录中序位置，递归只传边界，每次消费一个前序根，先构造左边再构造右边。空区间不取值，两个序列的顺序和边界共同约束树形。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { TreeNode } from '../shared.js'

export function buildTree(preorder: number[], inorder: number[]): TreeNode | null {
  const positions = new Map<number, number>()
  inorder.forEach((value, index) => positions.set(value, index))
  let nextRoot = 0
  function build(left: number, right: number): TreeNode | null {
    if (left > right) return null
    const value = preorder[nextRoot++]
    const middle = positions.get(value)!
    const node = new TreeNode(value)
    // 前序先给完左子树的根所以必须先构造左边
    node.left = build(left, middle - 1)
    node.right = build(middle + 1, right)
    return node
  }
  return build(0, inorder.length - 1)
}
```

## 复杂度与边界

- 按 Map 平均常数查询假设时间 **O(n)**，位置表 **O(n)**，递归栈 **O(h)**，总辅助空间 **O(n)**。
- 新建树为 **O(n)** 输出空间，不修改两个输入数组。
- 退化树 h=n，TS 极深递归可能溢栈，工程上可改显式构造栈。
