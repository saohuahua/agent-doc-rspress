# 0098 验证二叉搜索树

相关基础：[本章基础](/leetcode/08-binary-tree/)。[官方题目](https://leetcode.cn/problems/validate-binary-search-tree/)。

## 题目

:::info 题面

**难度**：中等

判断二叉树是否满足严格搜索树定义：每个节点左子树的所有值都小于它，右子树的所有值都大于它，并且子树也满足同样要求。关键词是“所有后代”，不是只比较两个直接孩子。重复值不符合严格关系。输出布尔值，输入结构不变。

题面配图用节点和左右连线表示树；示例中作为树的数组按层序列出节点，`null` 表示对应的孩子不存在。数组表示的是连接结构，不要求按数值排序。

:::

### 官方示例

> **示例 1**
>
> 输入：root = [2,1,3]
> 输出：true

> **示例 2**
>
> 输入：root = [5,1,4,null,null,3,6]
> 输出：false

### 约束

- 树中节点数目范围在[1, 10^4] 内
- -2^31 <= Node.val <= 2^31 - 1

## 前期思路

### 朴素方法与复杂度

可以对每个节点扫描左子树最大值与右子树最小值，再递归检查所有节点，但这样同一后代会被很多祖先反复扫描，退化情况下 O(n²)。仅比较直接父子关系不足以验证整棵树。例如根 5 的右孩子 7，7 的左孩子 4，每一条直接父子关系看似合理，但 4 在根的右子树里，违反必须大于 5 的要求。

### 优化依据

祖先对当前节点的限制可以汇总成一个允许范围，不需要到达后代后再回头遍历祖先。进入某根的左边意味着上界变小，进入右边意味着下界变大。沿路径所有约束的交集就是当前值应该落入的开区间。保存节点与上下界，便能一次访问检查全局规则。

### 算法推导

初始根范围为 (-Infinity,Infinity)，题面有限整数总能处于其中。取出 node 后，若值不严格大于 lower 或不严格小于 upper，就失败。左孩子继承原 lower，上界改为 node.val；右孩子下界改为 node.val，上界继承原 upper。

保留另一侧祖先边界是关键。例如根 5 的右子树允许 (5,∞)，到节点 7 的左孩子时范围是 (5,7)，不是 (-∞,7)。因此 4 会被准确拒绝。

正确性在于每次只增加当前根施加的那条约束，其余祖先约束继续保留；所有节点通过范围检查，等价于每个节点对所有祖先都处于正确侧。栈为空表示所有节点检查完毕，任一失败可立即返回。

### 变式分析与错误反例

- 错误反例：根 5 右接 7、7 左接 4，局部父子检查会错。根 2 左接 2 若用非严格比较，也会错误通过。
- 另一条等价路线是中序遍历必须严格递增，它把全局约束转成相邻输出比较。若题目规定重复值只允许在右侧，则简单中序非递减不够辨别重复值在左侧还是右侧，仍需按新定义调整上下界的开闭性。

## 执行过程示例

检查根 5、右孩子 7、7 的左孩子 4。

| 节点 | 允许开区间 | 检查结果 |
| --- | --- | --- |
| 5 | 负无穷到正无穷 | 通过 |
| 7 | 5 到正无穷 | 通过 |
| 4 | 5 到 7 | 不大于下界 5 失败 |

对根 2、孩子 1 和 3，同样传递范围，1 落在 (负无穷,2)，3 落在 (2,正无穷)，均通过。

## 解法复述与检查

复述检查：

- 只检查直接父子为什么不够？
- 向左与向右分别收紧哪一端范围？
- 哪个祖先限制必须继续传下去？

:::details 算法概述

仅检查父子关系不足以判断合法性，因为祖先也有限制。把每个节点允许的最小和最大范围一起向下传，去左边收紧上界，去右边收紧下界，另一端继续保留。只要值不在严格开区间内就不是搜索树。全部节点都满足这些继承约束才返回真。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { TreeNode } from '../shared.js'

export function isValidBST(root: TreeNode | null): boolean {
  if (root === null) return true
  const stack: Array<[TreeNode, number, number]> = [[root, -Infinity, Infinity]]
  while (stack.length > 0) {
    const [node, lower, upper] = stack.pop()!
    // 祖先传下来的限制也必须满足
    if (node.val <= lower || node.val >= upper) return false
    if (node.left !== null) stack.push([node.left, lower, node.val])
    if (node.right !== null) stack.push([node.right, node.val, upper])
  }
  return true
}
```

## 复杂度与边界

- 时间 **O(n)**，每个节点检查一次；显式深度优先栈 **O(h)**，最坏 **O(n)**，无递归调用栈。
- 输入不修改，输出常数大小。
- 允许范围使用 Infinity 作为边界，不把题目合法最大整数误当非法值；题面有限整数前提下没有 NaN 问题。
