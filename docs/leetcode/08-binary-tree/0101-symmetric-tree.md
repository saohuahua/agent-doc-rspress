# 0101 对称二叉树

相关基础：[本章基础](/leetcode/08-binary-tree/)。[官方题目](https://leetcode.cn/problems/symmetric-tree/)。

## 题目

:::info 题面

**难度**：简单

判断一棵树沿根的竖直轴是否完全对称，需要同时比较结构与节点值。根的左右孩子都为 2 并不充分，它们下面的分支也必须镜像对应。空树按本地接口返回 true，单节点天然对称。输出布尔值，不修改树，也不要求构造翻转后的树。

题面配图用节点和左右连线表示树；示例中作为树的数组按层序列出节点，`null` 表示对应的孩子不存在。数组表示的是连接结构，不要求按数值排序。

:::

### 官方示例

> **示例 1**
>
> 输入：root = [1,2,2,3,4,4,3]
> 输出：true

> **示例 2**
>
> 输入：root = [1,2,2,null,3,null,3]
> 输出：false

### 约束

- 树中节点数目在范围 [1, 1000] 内
- -100 <= Node.val <= 100

### 进阶要求

分别考虑递归和迭代的对称性检查。

## 前期思路

### 朴素方法与复杂度

手工方法是把左边和右边重叠观察：左边最外侧节点应对上右边最外侧，内侧也彼此对应。可以先翻转一边再比较，但会引入修改或复制。更直接的是一边观察一边成对检查。每次面对的不是一个节点，而是“应该互为镜像的两个位置”，位置可以为空。

### 优化依据

只收集每层的非空值并判断回文不够，因为会丢失空位信息。根下两边都为 2，且两个 2 都只有右孩子 3，每层非空值看似对称，结构却不对称。因此需要保留成对位置及 null，而不是仅保存数值序列。这个信息需求自然引出节点对的待办栈。

### 算法推导

初始待比较的一对是 root.left 与 root.right。弹出一对后，若同时为空，这两个位置匹配；若只有一边为空，结构不匹配；若都存在但值不同，内容不匹配。只有两边都有且值相等，才继续比较下一层。

镜像映射会把左转变成右转，所以要压入 left.left 对 right.right，以及 left.right 对 right.left。不能同方向比较，那是在判断两棵子树完全相同而不是镜像。

每个真实节点都只出现在一个对应位置对中。局部值与空位都匹配，并递归或迭代检查两组镜像孩子，就覆盖了全部镜像条件。出现任意反例可以立即返回 false；待办为空表示所有对应位置均通过。

### 变式分析与错误反例

- 错误反例：根两边都是 2，两个 2 都只有右孩子 3。忽略空位置得到每层 [2,2] 与 [3,3]，会误判；同方向比较也会把相同但不镜像的两棵子树误判。
- 如果题目改成两棵树是否相同，应比较左对左、右对右，其他空位和数值规则不变。若只要求结构对称而忽略数值，删去值比较即可，仍不能删去空位检查。迁移关键是先明确位置映射关系。

## 执行过程示例

对称树根 1，孩子 2 与 2，左 2 的孩子为 3、4，右 2 的孩子为 4、3。

| 比较位置对 | 值 | 下一步 |
| --- | --- | --- |
| 根的左右孩子 | 2 与 2 | 拆成外侧与内侧 |
| 左右内侧 | 4 与 4 | 比较各自对应空孩子 |
| 左右外侧 | 3 与 3 | 比较各自对应空孩子 |
| 叶子对应空位 | null 与 null | 匹配并继续 |

如果删掉右侧最外的 3，对应那一对会出现一个非空一个空，当场判 false。

## 解法复述与检查

复述检查：

- 两个位置都空、一空一非空、都非空时各如何判断？
- 为什么比较外侧与内侧，而不是同方向孩子？

:::details 算法概述

对称要求镜像位置的值和结构都相同。保存待比较的节点对，两个空算匹配，一空或值不同就失败。相等时再比较外侧一对和内侧一对，也就是左的左对右的右、左的右对右的左。所有对都通过才返回真。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { TreeNode } from '../shared.js'

export function isSymmetric(root: TreeNode | null): boolean {
  if (root === null) return true
  const pairs: Array<[TreeNode | null, TreeNode | null]> = [[root.left, root.right]]
  while (pairs.length > 0) {
    const [left, right] = pairs.pop()!
    if (left === null && right === null) continue
    if (left === null || right === null || left.val !== right.val) return false
    // 镜像位置是外侧一对和内侧一对
    pairs.push([left.left, right.right], [left.right, right.left])
  }
  return true
}
```

## 复杂度与边界

- 时间 **O(n)**，每个节点只处理常数次。
- 显式深度优先节点对栈空间 **O(h)**，最坏 **O(n)**，没有语言递归栈。
- 不修改输入，不分配新树。
- null 需要保留到比较，不能为了简化代码过滤掉。
