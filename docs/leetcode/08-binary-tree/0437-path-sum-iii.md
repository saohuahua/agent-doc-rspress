# 0437 路径总和 III

相关基础：[本章基础](/leetcode/08-binary-tree/)。[官方题目](https://leetcode.cn/problems/path-sum-iii/)。

## 题目

:::info 题面

**难度**：中等

统计向下路径的节点值之和等于 targetSum 的条数。路径可以从任意节点开始，到任意后代结束，不必从根开始或在叶子结束，但不能拐回父节点再走另一边。节点可为负数，所以和超过目标后也不能直接停止。返回数量而非具体路径。

题面配图用节点和左右连线表示树；示例中作为树的数组按层序列出节点，`null` 表示对应的孩子不存在。数组表示的是连接结构，不要求按数值排序。

:::

### 官方示例

> **示例 1**
>
> 输入：root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8
> 输出：3

> **示例 2**
>
> 输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
> 输出：3

### 约束

- 二叉树的节点个数的范围是 [0,1000]
- -10^9 <= Node.val <= 10^9
- -1000 <= targetSum <= 1000

## 前期思路

### 朴素方法与复杂度

最直接做法是枚举每个起点，再从该起点向所有后代累加并判断，时间在退化链上达到 O(n²)。这个办法清楚覆盖所有路径，但同一段根到节点的累计信息在不同起点搜索中反复计算。想减少这部分重复，可以先把树上当前根到节点路线当成一个暂时的数组。

### 优化依据

对一条固定根路径，当前前缀和为 S，若某个祖先之前的前缀和是 P，那么二者之间那段路径和就是 S-P。要让它等于目标 T，只需查有多少个 P=S-T。这不是只查有没有：路径里出现零或正负抵消时，相同前缀可能对应多个起点，必须保存次数。

### 算法推导

counts 只记录当前递归祖先路线上的前缀和，初始放 0 的一次记录，表示根之前的空前缀。到 node 后得到 current，先查询 current-targetSum 的次数，这些每一个前缀都对应一条以当前节点结束的合法向下路径。

然后把 current 的次数加一，使孩子可以从当前节点之后开始计算。分别处理左右孩子，最后将 current 次数减回去，若为零就删除。离开时撤销是正确性的关键：左子树已经结束的前缀不能作为右子树的祖先，因为两者之间不是向下路径。

先查询再加入也有原因：若目标为零，先加入当前前缀会把长度为零的空路径算进去。每条真实路径有唯一结束节点，在那个节点查到对应前驱前缀时被计数一次；同值前缀使用次数恰好保留不同起点，既不漏计也不重计同一起终点。

### 变式分析与错误反例

- 错误反例：根 1，左右孩子都为 1，目标 0，没有合法零和路径；若左子树前缀 2 离开后不删除，走到右孩子前缀也是 2，会误计一条跨分支路径。全零三节点链目标 0 有 6 条，若只用 Set 而不用次数会少算。
- 若限定从根开始，只需比较当前累计和与目标，不再需要所有祖先前缀次数。若允许路径向上再向下，本算法的祖先路线范围不足以涵盖所有路径，需要在转折节点合并两侧信息，不能仅去掉撤销步骤。

## 执行过程示例

单链 1→-1→1，目标 1，按递归进入顺序。

| 当前值 | 当前前缀 | 查询前需要的前缀 | 命中条数 |
| --- | --- | --- | --- |
| 1 | 1 | 0 | 1 对应第一节点 |
| -1 | 0 | -1 | 0 |
| 1 | 1 | 0 | 2 对应整链和末节点 |

第三步前 0 有两次，分别为空前缀与经过第二节点的前缀。总共 3 条。退出第三、第二、第一节点时逐个撤销，最后表恢复为只有 0 的一次记录。

## 解法复述与检查

复述检查：

- 前缀表为什么记录次数而不是存在性？
- 为什么先查再加？
- 离开当前节点时不撤销会怎样拼出不存在的路径？

:::details 算法概述

枚举起点会重复累加。沿根路径保存前缀和次数，在当前节点查当前和减目标出现过几次，每次出现对应一个合法起点。查完再加入当前前缀，递归孩子，返回时撤销当前记录。这样表里永远只有祖先路线，兄弟分支不会互相拼成不存在的路径。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { TreeNode } from '../shared.js'

export function pathSum(root: TreeNode | null, targetSum: number): number {
  // 空前缀使从根开始的路径也能被统一统计
  const counts = new Map<number, number>([[0, 1]])
  function visit(node: TreeNode | null, prefix: number): number {
    if (node === null) return 0
    const current = prefix + node.val
    let total = counts.get(current - targetSum) ?? 0
    counts.set(current, (counts.get(current) ?? 0) + 1)
    total += visit(node.left, current)
    total += visit(node.right, current)
    // 离开当前路径时撤销记录避免污染兄弟分支
    const remaining = counts.get(current)! - 1
    if (remaining === 0) counts.delete(current)
    else counts.set(current, remaining)
    return total
  }
  return visit(root, 0)
}
```

## 复杂度与边界

- 按 Map 平均常数操作假设时间 **O(n)**。
- 递归栈 **O(h)**，当前路线前缀表最多 **O(h)**，总辅助空间 **O(h)**，最坏 **O(n)**。
- 不修改输入，输出一个计数。
- 题面规模下路径累计值在 JS 安全整数范围内；负数不剪枝。
- 深链可能触及调用栈限制，工程版可用带进入退出标记的显式栈。
