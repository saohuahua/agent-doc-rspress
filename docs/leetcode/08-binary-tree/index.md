# 08 二叉树基础 子树分解与信息汇总

二叉树可以分解为当前节点及其左、右子树。许多算法利用这一结构，将整树问题转化为对子树的计算，再在当前节点组合结果。推导时需要明确子问题的输入、返回值与组合规则；例如求高度时，子树返回高度，当前节点取较大值后加一。

## 节点与结构

二叉树每个节点最多有两个孩子，分别叫 left 和 right。没有孩子的位置为 null。根没有父节点，叶子左右都为空；只有左孩子或只有右孩子的节点不是叶子。树不存在环，每个非根节点只有一个父节点，因此从根到某节点只有一条路径。若结构允许共享孩子或回到祖先，就成为一般图，需要额外处理访问历史。

本项目 `TreeNode` 的 val 为数字，left、right 为节点引用或 null。相同值不代表相同节点。最近公共祖先查的是两个具体对象的关系，路径和计算的是对象上存放的数值；类型相同不代表语义相同。

深度通常按根到某节点的节点数计算，根深度为 1；高度可按当前节点到最深叶子的节点数计算，空树高度 0。部分题用边数，例如直径，必须先看题意。h 表示高度时，只有平衡树才保证 h 为 O(log n)，一条链形的二叉树可以 h=n。

## 三种深度优先顺序

前序为根左右，中序为左根右，后序为左右根。这些名字指“什么时候处理根”，不是左子树只有一个节点。说先左子树，表示完整处理那棵子树里的全部节点，再回来执行当前根的下一步。

根为 2、左 1、右 3 时，前序是 2 1 3，中序是 1 2 3，后序是 1 3 2。若左孩子 1 下还有孩子，必须先把那整棵子树的顺序展开，不能把遍历当作只看三层的固定操作。

前序适合进入节点时就能决定的工作，后序适合依赖孩子结果的工作。求高度需要先知道左右高度，所以自下而上汇总；路径前缀和则进入时添加、离开时撤销，同一次访问包含两个不同阶段。

## 递归调用的局部状态与恢复

调用 `height(node.left)` 时，当前函数暂停，运行时记住当前 node 以及之后还需要处理右边、合并结果。这份暂停现场占用调用栈。孩子返回后，父函数从暂停处继续，不会自动重头再执行一遍。

以根 2 左有 1 为例，求根高度先求 1；1 的空孩子返回 0，1 汇总出 1，再返回根；根再求空右边得到 0，最后返回 2。根与孩子函数里虽然变量都叫 left，它们属于不同调用，不互相覆盖。不同调用具有独立的局部变量，调用栈按返回顺序恢复对应现场。

每次递归都应明确三件事：参数表示哪棵子树或哪段范围；返回值的语义；遇到空节点的答案。空高度为 0，空树对称比较要成对判断，最大非空路径的全局答案不能因空树贡献 0 就初始化为 0。不同问题的空值不是一套万能默认值。

## 子树返回值与全局候选

直径在当前节点可以把左右两边连接成一条完整路径，但父节点只能接当前节点向下的一条分支。于是孩子返回单侧高度，另用全局变量记录双侧候选。最大路径和同理，只是高度换成可选负贡献的和。

若将已经连接左右分支的结果继续接到父节点，该节点会出现三条路径边，不再符合简单路径定义。因此返回值必须满足父节点继续连接的条件，全局候选与返回值应分别计算。

## 层序与显式栈

层序把当前层所有节点作为一组，收集它们的孩子形成下一层。保留层边界就可以求层数、右视图或逐层结果。不能因为只取本层最右答案，就丢弃其他父节点的后代。

显式栈可用 TS 数组的 push、pop 实现后进先出，保存未处理分支或待返回祖先；层序可用两组数组轮换，避免不断 shift 删除数组首项。递归代码的辅助空间是调用栈 O(h)，显式栈也有存储成本，不会因为换一种写法就变成 O(1)。JS 对极深递归有上限，工程处理长链树时应使用显式状态栈。

## 二叉搜索树的额外约束

二叉搜索树要求每个节点左侧所有后代都小于它，右侧所有后代都大于它。只检查直接孩子不够。这个额外约束使中序严格递增，从而支持排名查询。普通二叉树的中序只是访问顺序，不能拿它当排序结果，也不能按目标值大小选择分支。
