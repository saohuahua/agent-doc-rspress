# 0114 二叉树展开为链表

相关基础：[本章基础](/leetcode/08-binary-tree/)。[官方题目](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/)。

## 题目

:::info 题面

**难度**：中等

将原二叉树原地展开成一条沿 right 前进的链，所有 left 都应为 null，节点顺序必须等于原树前序，也就是根、左子树、右子树。不能新建一条值相同的链代替原树。函数返回 void，通过修改节点让调用者从原 root 沿 right 读取结果。

题面配图用节点和左右连线表示树；示例中作为树的数组按层序列出节点，`null` 表示对应的孩子不存在。数组表示的是连接结构，不要求按数值排序。

:::

### 官方示例

> **示例 1**
>
> 输入：root = [1,2,5,3,4,null,6]
> 输出：[1,null,2,null,3,null,4,null,5,null,6]

> **示例 2**
>
> 输入：root = []
> 输出：[]

> **示例 3**
>
> 输入：root = [0]
> 输出：[0]

### 约束

- 树中结点数在范围 [0, 2000] 内
- -100 <= Node.val <= 100

### 进阶要求

尝试只用 O(1) 额外空间原地展开树。

## 前期思路

### 朴素方法与复杂度

朴素方法先执行前序遍历，将全部节点引用存入数组，再依次清空 left、把 right 指向下一项。该方法需要 O(n) 辅助数组。观察连接下一项时，只需要当前前序节点和前一个节点，没必要等完整序列生成后才开始接边。于是可以边产生前序顺序，边把相邻项连起来。

### 优化依据

困难是访问树与改树同时发生，覆盖原 right 之前必须保存还未访问的孩子。显式栈正好保存这部分待办。当当前节点出栈时，先把原右、原左压栈，之后即使修改前驱边，也不会失去后面的子树入口。栈后进先出，所以先压右再压左才能让左子树先处理。

### 算法推导

previous 表示已经展开链的最后一个节点。首次取出 root 时没有前驱，只保存它；之后每次取出 node，先保留其原孩子，再将 previous.left 清空、previous.right 指向 node，最后 previous=node。

循环开始时，已经弹出的节点按原前序构成完整前缀，栈里保留所有尚未访问子树的入口。右先左后入栈保证下一次弹出的是原前序的下一项，连接这对相邻节点就保持链顺序。当前节点孩子保存后才会在将来的步骤中被覆盖，避免丢树。

循环结束还需把最后节点的左右边清空，显式保证链尾终止。有效非空有限二叉树的前序最后一个节点必为叶子；清空指针仍显式保证最终链尾的输出条件。输入保证是树，无共享或环，每个节点仅入栈一次。

### 变式分析与错误反例

- 错误反例：根 1 左为 2、右为 3，先执行 root.right=root.left 且没有保存原 right，就丢失 3。先压左再压右会产生根右左顺序，虽然仍是一条链，但不满足前序要求。只检查 val 序列也不足以证明原地，必须检查节点引用全部来自原树。
- 如果要求保留原树，可以生成新节点链，不再需要清空原 left，但输出空间 O(n)。如果要求中序展开，当前节点的访问时机变了，必须先保存右入口并按中序调度，不能直接替换一个 push 顺序来保证正确。

## 执行过程示例

原树根 1，左子树 2 带孩子 3、4，右子树 5 右接 6。

| 弹出节点 | 压入待办后栈底到顶 | 新接边 |
| --- | --- | --- |
| 1 | 5 2 | 没有前驱 |
| 2 | 5 4 3 | 1.right=2 |
| 3 | 5 4 | 2.right=3 |
| 4 | 5 | 3.right=4 |
| 5 | 6 | 4.right=5 |
| 6 | 空 | 5.right=6 最后清空 6 |

最终顺序 1→2→3→4→5→6，每个节点 left 都为空。

## 解法复述与检查

复述检查：

- 为什么先保存原孩子再改连接？
- 栈中先右后左如何产生前序？
- previous表示哪条已完成链的哪个位置？

:::details 算法概述

首先把题目理解成前序序列的相邻节点重连。用栈按前序取节点，先保存原右和原左，确保左先出栈，再把上一个节点的右边连到当前节点并清空左边。这样不用保存完整前序数组，边遍历边连接，同时保留所有未访问入口。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { TreeNode } from '../shared.js'

export function flatten(root: TreeNode | null): void {
  if (root === null) return
  const stack: TreeNode[] = [root]
  let previous: TreeNode | null = null
  while (stack.length > 0) {
    const node = stack.pop()!
    // 先保存孩子再改边并让左孩子先出栈
    if (node.right !== null) stack.push(node.right)
    if (node.left !== null) stack.push(node.left)
    if (previous !== null) {
      previous.left = null
      previous.right = node
    }
    previous = node
  }
  // 最后节点成为链尾所有后继均为空
  previous!.left = null
  previous!.right = null
}
```

## 复杂度与边界

- 时间 **O(n)**，显式深度优先待办栈 **O(h)**，最坏 **O(n)**，不使用递归栈。
- 修改原节点左右连接，不创建输出节点。
- 此主解没有宣称常数辅助空间；进阶可通过将左子树右边界接原右子树来原地展开，但需要额外论证扫描总成本。
