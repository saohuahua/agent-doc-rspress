# 0199 二叉树的右视图

相关基础：[本章基础](/leetcode/08-binary-tree/)。[官方题目](https://leetcode.cn/problems/binary-tree-right-side-view/)。

## 题目

:::info 题面

**难度**：中等

从树的右侧观察，每个深度能看到最右边的那个节点，按从上到下返回值。不是只沿 root.right 一直走：如果右子树较浅，更深处的左子树节点仍能被看到。空树输出 []。右视图是按层筛选，不是按数值取每层最大值。

题面配图用节点和左右连线表示树；示例中作为树的数组按层序列出节点，`null` 表示对应的孩子不存在。数组表示的是连接结构，不要求按数值排序。

:::

### 官方示例

> **示例 1**
>
> 输入：root = [1,2,3,null,5,null,4]
> 输出：[1,3,4]

> **示例 2**
>
> 输入：root = [1,2,3,4,null,null,null,5]
> 输出：[1,3,4,5]

> **示例 3**
>
> 输入：root = [1,null,3]
> 输出：[1,3]

> **示例 4**
>
> 输入：root = []
> 输出：[]

### 约束

- 二叉树的节点个数的范围是 [0,100]
- -100 <= Node.val <= 100

## 前期思路

### 朴素方法与复杂度

手工先画出每层节点，再在每层圈最右的一个，这已经给了正确方案。可以先完整做层序遍历得到二维数组，再取每层最后值，但为了一个值保存整层结果并非必要。只需在处理这一层时直接记录最后节点，同时收集下一层即可。

### 优化依据

本题要保留的信息有两个：当前层全部节点，用于发现下一层；当前层最右节点的值，用于答案。不能只保留最右节点本身来继续，因为它可能没有孩子，而较左节点有更深后代。输出候选少，不代表下一轮搜索范围也能同样缩小。

### 算法推导

沿用 0102 的分层数组。初始 level 为 root。每轮数组从左到右排列，因此最后一个元素就是这一层可见节点，加入 result。然后依次把每个节点存在的左孩子、右孩子放入 next，再切换到下一层。

正确性需要同时说明顺序和完整性：父节点按从左到右处理，每个父节点先左后右，所以 next 仍按空间顺序排列；所有父节点都处理，因此不会漏掉左侧分支的深层节点。每层恰好选最后一项，正符合右侧观察的定义。

也可以深度优先先走右边，并在每个深度首次到达时记值。但这需要解释首次到达为何最右。这里选择直接按层观察，让题意与维护状态更容易对应。

### 变式分析与错误反例

- 错误反例：根 1 只有左孩子 2，2 有左孩子 3，答案应为 [1,2,3]，沿 right 只会返回 [1]。按层取最大值也不对，例如同层从左到右 [9,2]，可见的是 2。
- 若求左视图，保持层序不变取第一项即可；若求每层最大值，需要比较数值，而不是选择位置。若求从顶部看树的投影，横坐标与遮挡定义发生变化，按层最后一项不够，需要新的空间状态。

## 执行过程示例

根 1，左右孩子 2 和 3，2 的右孩子 5，3 的右孩子 4，5 下方还有 6。

| 当前层 | 记录 | 下一层 |
| --- | --- | --- |
| 1 | 1 | 2 3 |
| 2 3 | 3 | 5 4 |
| 5 4 | 4 | 6 |
| 6 | 6 | 空 |

答案 1 3 4 6，其中 6 来自左子树。仅沿最右链会漏掉它。

## 解法复述与检查

复述检查：

- 为什么不能只走右孩子链？
- 每层只输出一个值为何仍要遍历整层？
- 左子树节点在什么情况下也会被看见？

:::details 算法概述

右视图等于每层最右节点。使用从左到右的分层数组，每层记最后一个值，但仍遍历本层全部节点来生成下一层。不能只跟着右孩子走，因为右边结束后左边更深的节点也可能可见。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { TreeNode } from '../shared.js'

export function rightSideView(root: TreeNode | null): number[] {
  if (root === null) return []
  const result: number[] = []
  let level: TreeNode[] = [root]
  while (level.length > 0) {
    // 当前层已按从左到右排列最后一个就是可见节点
    result.push(level[level.length - 1].val)
    const next: TreeNode[] = []
    for (const node of level) {
      if (node.left !== null) next.push(node.left)
      if (node.right !== null) next.push(node.right)
    }
    level = next
  }
  return result
}
```

## 复杂度与边界

- 时间 **O(n)**，每个节点处理一次。
- 辅助空间 **O(w)**，w 为最大层宽，最坏 **O(n)**；输出每层一个值，占 **O(h)**。
- 无递归栈，不修改输入。
- 单边左链每个节点都可见，单边右链也一样。
