# 0094 二叉树的中序遍历

相关基础：[本章基础](/leetcode/08-binary-tree/)。[官方题目](https://leetcode.cn/problems/binary-tree-inorder-traversal/)。

## 题目

:::info 题面

**难度**：简单

返回二叉树的中序访问值序列，规则是先完整访问左子树，再访问当前节点，最后完整访问右子树。“中”表示根在两棵子树之间被访问，不表示按数值取中间，也不要求树有序。输出数组里的值可以重复，因为每个节点都应访问一次。空树输出空数组。

题面配图用节点和左右连线表示树；示例中作为树的数组按层序列出节点，`null` 表示对应的孩子不存在。数组表示的是连接结构，不要求按数值排序。

:::

### 官方示例

> **示例 1**
>
> 输入：root = [1,null,2,3]
> 输出：[1,3,2]

> **示例 2**
>
> 输入：root = []
> 输出：[]

> **示例 3**
>
> 输入：root = [1]
> 输出：[1]

### 约束

- 树中节点数目在范围 [0, 100] 内
- -100 <= Node.val <= 100

### 进阶要求

在递归之外 尝试迭代完成中序遍历。

## 前期思路

### 朴素方法与复杂度

面对一棵画出来的树，可以先沿左边走到底，访问最左节点，然后返回它的父节点，接着访问父节点右侧。递归写法也很自然：让相同过程处理左树，记录根，再处理右树。遍历全部节点需要 O(n) 次访问，该方法已达到这一数量级。显式栈实现需要进一步保存左子树处理完成后的返回位置。

### 优化依据

节点没有 parent 字段，沿 left 走下去后，仅靠 current 无法返回祖先。需要保存尚未轮到访问的祖先，返回时最近暂存的祖先应该先处理，所以使用后进先出的栈。递归调用栈也在保存这种待办任务；显式数组栈让返回过程可见，并避免依赖 JavaScript 深递归的调用栈上限。

### 算法推导

current 指向一棵还未展开的子树。只要它存在，就把当前节点压栈，并继续去左子树，这表示当前根尚未访问，需要在左子树处理完后返回。走到 null 说明最深的左侧为空，这时弹出栈顶并记录值，它的左侧已经处理完，正轮到根。

接着 current 改为弹出节点的 right，重新展开这棵右子树。右树不存在时，下一轮会继续弹出更高祖先。主循环必须同时检查 current 与 stack：current 为空不代表全部完成，栈里可能还有等待访问的根。

每个节点恰好压栈一次、弹出一次。弹出之前左子树已完整处理，弹出之后才展开右子树，因此访问顺序满足定义；有限节点全部弹完且没有待展开子树时才终止。

### 变式分析与错误反例

- 错误反例：根 1 无左子树但右孩子 2，如果弹出根后没有转向 right，会漏掉 2；若主循环只检查 current，在完成左侧后会过早退出而漏祖先。
- 若要求前序，根应在展开左子树之前记录；若要求后序，根要等两边都结束，不能简单把本题 push 调换一行就保证正确。二叉搜索树的中序有额外升序性质，但普通树只保证访问顺序，不能把这两种事实混为一谈。

## 执行过程示例

树的根为 2，左孩子 1，右孩子 3。

| 动作 | 栈底到栈顶 | 输出 | 原因 |
| --- | --- | --- | --- |
| 压入 2 再压 1 | 2 1 | 空 | 先寻找最左侧 |
| 弹出 1 | 2 | 1 | 1 左侧为空 |
| 弹出 2 | 空 | 1 2 | 2 左子树已完成 |
| 压入再弹出 3 | 空 | 1 2 3 | 转入 2 的右子树 |

若把值改成根 9、左 5、右 1，输出是 5 9 1，仍然是中序，只是不再升序。

## 解法复述与检查

复述检查：

- 沿左边走时栈记录什么待办？
- 何时才正式输出节点值？
- current为空为什么不一定意味着遍历结束？

:::details 算法概述

中序要求左根右。沿左边走时把祖先压栈，表示暂存尚待访问的祖先；走到空后弹最近祖先记录值，再进入它右边。当前子树和栈都空才结束。每个节点入栈出栈各一次，栈保存的是返回位置，不是在排序数值。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { TreeNode } from '../shared.js'

export function inorderTraversal(root: TreeNode | null): number[] {
  const values: number[] = []
  const stack: TreeNode[] = []
  let current = root
  while (current !== null || stack.length > 0) {
    // 暂存祖先以便左侧处理完后回来访问
    while (current !== null) {
      stack.push(current)
      current = current.left
    }
    const node = stack.pop()!
    values.push(node.val)
    current = node.right
  }
  return values
}
```

## 复杂度与边界

- n 个节点时间 **O(n)**，辅助栈最多树高 h，空间 **O(h)**，退化链可达 **O(n)**。
- 输出数组另占 **O(n)**，不是常数输出。
- 没有递归栈，不修改左右指针。
- 空树、单节点、只左或只右的链都能处理。
