# 0226 翻转二叉树

相关基础：[本章基础](/leetcode/08-binary-tree/)。[官方题目](https://leetcode.cn/problems/invert-binary-tree/)。

## 题目

:::info 题面

**难度**：简单

把整棵树左右镜像翻转，返回根引用。根值不变，根的左子树要变成右子树，同时每棵子树内部也要镜像。只交换最外层两个孩子还不够。空树仍为空，本实现直接修改原树的左右指针，不创建另一棵树。

题面配图用节点和左右连线表示树；示例中作为树的数组按层序列出节点，`null` 表示对应的孩子不存在。数组表示的是连接结构，不要求按数值排序。

:::

### 官方示例

> **示例 1**
>
> 输入：root = [4,2,7,1,3,6,9]
> 输出：[4,7,2,9,6,3,1]

> **示例 2**
>
> 输入：root = [2,1,3]
> 输出：[2,3,1]

> **示例 3**
>
> 输入：root = []
> 输出：[]

### 约束

- 树中节点数目范围在 [0, 100] 内
- -100 <= Node.val <= 100

## 前期思路

### 朴素方法与复杂度

逐个交换每个节点的左右子树入口，即可得到整树的镜像。该方法只需访问每个节点一次，时间为 O(n)。实现时需要保证所有节点均被处理，并在交换入口前保存尚未访问的子树引用。

### 优化依据

只有一个 current 只能沿一条分支走，另一条分支需要暂存。可以递归让两棵子树自己翻转，也可以用显式栈保存待处理节点。本实现选择后者：每取出一个节点，就交换它的两个子树入口，再把两个存在的孩子压栈。栈表达的是还有哪些局部工作没做。

### 算法推导

先把非空根放入栈。每轮弹出 node，先保存旧 left，再用旧 right 替换 left，最后把保存的旧 left 赋给 right。这三步确保两个子树引用都保留，不能先覆盖 left 后再从 left 读取旧值。

交换之后，两个孩子都仍是原有子树入口，只是位置互换。把它们加入栈，就能继续处理内部连接。遍历顺序无需与中序或前序完全一致，因为本题的局部交换只依赖当前两条边，不依赖孩子先算出一个结果。

正确性可按结构理解：所有节点都交换自己的左右子树，因此任意原路径中每次向左都变成向右，向右都变成向左，整条路径正是镜像。树无环且每个节点只有一个父节点，访问每个节点一次即可完成，无需额外访问集合。

### 变式分析与错误反例

- 错误反例：根 1 左子树为 2 且 2 左孩子 3，只交换根会得到右子树 2 仍左接 3，正确镜像应让 2 右接 3。另一个错误是把 left=right 后再 right=left，导致两个方向指向同一个子树并丢掉旧 left。
- 若要求保留原树，应对每个节点新建副本，让副本左边复制原右边、右边复制原左边，输出空间 O(n)。若要求验证两棵树互为镜像，应成对比较对应位置，而不是先破坏其中一棵再比较。

## 执行过程示例

根 4，左孩子 2 带孩子 1、3，右孩子 7 带孩子 6、9。栈先压左再压右，所以右侧先处理。

| 处理节点 | 交换前孩子 | 交换后孩子 | 尚待内部处理 |
| --- | --- | --- | --- |
| 4 | 2 和 7 | 7 和 2 | 7 与 2 的内部 |
| 2 | 1 和 3 | 3 和 1 | 叶子也会经过栈 |
| 7 | 6 和 9 | 9 和 6 | 叶子没有实际边变化 |

表按关键非叶节点列出，叶子交换两个 null，无结构变化。最终层序为 4 / 7 2 / 9 6 3 1。

## 解法复述与检查

复述检查：

- 交换的是子树入口还是节点数值？
- 为什么只交换根不够？
- 临时变量保护了哪一个即将被覆盖的引用？

:::details 算法概述

整树镜像等于每个节点都交换左右入口。使用栈保存未处理节点，取出一个后先保存一边再交换两边，随后把孩子放进栈继续。只交换根不够，因为子树内部也要镜像。操作的是指针而不是值，根对象保持不变。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { TreeNode } from '../shared.js'

export function invertTree(root: TreeNode | null): TreeNode | null {
  if (root === null) return null
  const stack: TreeNode[] = [root]
  while (stack.length > 0) {
    const node = stack.pop()!
    // 交换的是子树入口而不是两个根节点的数值
    const left = node.left
    node.left = node.right
    node.right = left
    if (node.left !== null) stack.push(node.left)
    if (node.right !== null) stack.push(node.right)
  }
  return root
}
```

## 复杂度与边界

- 时间 **O(n)**，每个节点一次。
- 深度优先显式栈最多 **O(h)** 个待处理分支，最坏 **O(n)**；无语言递归栈。
- 原地修改左右连接，输出复用原根。
- 单节点不变，只有一边的链会变为相反方向的链。
