# 0102 二叉树的层序遍历

相关基础：[本章基础](/leetcode/08-binary-tree/)。[官方题目](https://leetcode.cn/problems/binary-tree-level-order-traversal/)。

## 题目

:::info 题面

**难度**：中等

按从上到下、每层从左到右返回二叉树的值。输出是二维数组，每个内层数组代表一层，不能只返回一个扁平序列。比如根 3，下一层 9 和 20，再下一层 15 和 7，答案是 [[3],[9,20],[15,7]]。空树返回 []，不是 [[]]。

题面配图用节点和左右连线表示树；示例中作为树的数组按层序列出节点，`null` 表示对应的孩子不存在。数组表示的是连接结构，不要求按数值排序。

:::

### 官方示例

> **示例 1**
>
> 输入：root = [3,9,20,null,null,15,7]
> 输出：[[3],[9,20],[15,7]]

> **示例 2**
>
> 输入：root = [1]
> 输出：[[1]]

> **示例 3**
>
> 输入：root = []
> 输出：[]

### 约束

- 树中节点数目在范围 [0, 2000] 内
- -1000 <= Node.val <= 1000

## 前期思路

### 朴素方法与复杂度

在图上按横排逐层读很自然，但程序从根只能直接看到两个孩子。深度优先一路走到底会先经过深层节点，再回来访问浅层右侧，不符合直接输出的层序顺序。也能在深度优先时按深度把值收集进不同数组，按整层节点组织访问则可直接保持层边界，下一层由当前层全部节点的孩子构成。

### 优化依据

需要保存当前这一层所有节点，不能只保存一个分支。它们按从左到右排列时，依次收集每个节点的左孩子再右孩子，得到的恰好是下一层从左到右顺序。这种按距离逐层扩展的过程叫广度优先遍历。数组可以承担每层的待办清单，不必对 JS 数组反复 shift。

### 算法推导

非空根构成初始 level。每轮建立 values 和 next，遍历 level 时把节点值放入 values，把存在的左孩子和右孩子依次放入 next。遍历完整层后，将 values 作为一个整体放入 result，再把 level 换成 next。

两个数组区分很重要：values 是本层结果数字，next 是下轮要处理的节点引用，不是同一类数据。next 不可以在本轮直接继续处理，否则会把不同深度混入同一个 values。每层结束才交换待办，层边界由此确定。

正确性来自层间归纳：第一层只有根且顺序正确；假设当前层顺序正确，则父节点先后次序和每个父节点的左后右次序共同确定下一层顺序。每个非根节点仅被唯一父节点加入一次，因此不会重复。所有层为空后结果完整。

### 变式分析与错误反例

- 错误反例：若把当前节点的孩子 push 到正在 for 遍历的同一数组，并在这一轮继续遍历，根和所有后代都可能进入同一个输出数组。若先右后左收集，第二层 [9,20] 会颠倒。
- 若改成锯齿层序，可以保持节点发现顺序不变，只在输出奇偶层时反转 values，这仍为总 O(n) 额外处理；若改成自底向上，完成后反转最外层数组即可。先保住正确层边界，再变换输出，比同时改变遍历方向更容易验证。

## 执行过程示例

用根 3、孩子 9 和 20、20 的孩子 15 和 7。

| 本轮 level | 本轮 values | 下一轮 next | result 变化 |
| --- | --- | --- | --- |
| 3 | [3] | 9 20 | [[3]] |
| 9 20 | [9,20] | 15 7 | [[3],[9,20]] |
| 15 7 | [15,7] | 空 | [[3],[9,20],[15,7]] |

节点 9 没有孩子，只是不向 next 增加内容，不会导致 20 的孩子被放到错误层。

## 解法复述与检查

复述检查：

- values和next分别保存什么？
- 为何不能把孩子直接混入本轮level？
- 先左后右如何保证下一层顺序？

:::details 算法概述

保存当前整层节点，按从左到右读取值，同时按先左后右把它们的孩子收集成下一层。本层处理完才把结果加入二维数组并切换层。这样层边界清楚，不会把刚发现的孩子混入当前结果。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { TreeNode } from '../shared.js'

export function levelOrder(root: TreeNode | null): number[][] {
  if (root === null) return []
  const result: number[][] = []
  let level: TreeNode[] = [root]
  while (level.length > 0) {
    const next: TreeNode[] = []
    const values: number[] = []
    for (const node of level) {
      values.push(node.val)
      // 先左后右保证下一层的相对顺序
      if (node.left !== null) next.push(node.left)
      if (node.right !== null) next.push(node.right)
    }
    result.push(values)
    level = next
  }
  return result
}
```

## 复杂度与边界

- 每个节点处理一次，时间 **O(n)**。
- 当前和下一层节点数组最多 **O(w)** 辅助空间，w 为最大宽度，最坏 **O(n)**；结果数组总共保存 n 个数，输出空间 **O(n)**。
- 无递归栈，不修改输入。
- 使用分层数组避免反复删除数组首元素可能产生的移动成本。
