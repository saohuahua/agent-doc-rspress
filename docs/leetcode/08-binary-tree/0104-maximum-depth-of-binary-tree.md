# 0104 二叉树的最大深度

相关基础：[本章基础](/leetcode/08-binary-tree/)。[官方题目](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)。

## 题目

:::info 题面

**难度**：简单

最大深度是从根到最远叶子的路径包含多少个节点。只有根时深度为 1，空树为 0，不是边数。树可能一边很深另一边很浅，要求最长那条。先把节点画成按距离根的层次排列，最深层的编号就是目标值。

题面配图用节点和左右连线表示树；示例中作为树的数组按层序列出节点，`null` 表示对应的孩子不存在。数组表示的是连接结构，不要求按数值排序。

:::

### 官方示例

> **示例 1**
>
> 输入：root = [3,9,20,null,null,15,7]
> 输出：3

> **示例 2**
>
> 输入：root = [1,null,2]
> 输出：2

### 约束

- 树中节点的数量在 [0, 10^4] 区间内。
- -100 <= Node.val <= 100

## 前期思路

### 朴素方法与复杂度

可以枚举每条根到叶路径并比较长度，使用深度优先遍历时也能在线性时间完成，因为路径深度可以随行记录，不需要复制整条路径。另一种更直观的手工方式是数横向层数：第一轮只有根，第二轮是根的孩子，直到再也没有孩子。按层维护显式状态同样为线性时间，并避免使用深递归调用栈。

### 优化依据

要数下一层，不需要记住整条访问历史，只需要当前这一层的节点。当前层的孩子集合恰好是下一层，因为每个非根节点有唯一父节点，且父子距离相差一。因此可以用两组数组轮换保存层，而不是为每个节点记录完整路径。

### 算法推导

空树直接返回 0。非空时 level 先保存 root，depth 从 0 开始。每轮遍历 level，将存在的 left 和 right 加到新的 next 数组，然后 depth 加一，level 换为 next。

为什么处理完当前层才加一？此时确认完整走完一层，无论这层有一个还是上千节点，深度只增长一。next 必须新建，不能把孩子推入当前正在遍历的 level，否则循环会把多层混在一轮。

初始 level 正好是第一层。若某轮是完整第 d 层，它的孩子集合就是完整第 d+1 层，没有遗漏或重复；因此按层推进的约定保持。有限树最终产生空 next，此时 depth 恰为已经访问过的层数，也就是最远根叶路径的节点数。

### 变式分析与错误反例

- 错误反例：根有左叶和右侧三层链，如果见到第一片叶子就返回 2，算到的是最小深度而非最大深度。按边数计深度则会把单节点答案算成 0。
- 若改求最小深度，按层遍历遇到第一片真正叶子即可返回当前层数，但叶子要求左右都空，单边空不算叶。若希望输出最深路径本身，需要保存父关系或沿深度遍历保存路径，单个层数不足以还原路线。

## 执行过程示例

根 3，孩子 9 和 20，20 的孩子是 15 和 7。

| 当前 level | 收集 next | depth 更新后 |
| --- | --- | --- |
| 3 | 9 20 | 1 |
| 9 20 | 15 7 | 2 |
| 15 7 | 空 | 3 |

处理 9 时没有孩子不代表整树结束，因为同层的 20 仍有后继。必须处理完整层后才能判断。

## 解法复述与检查

复述检查：

- 最大深度为什么按层数而不是节点总数计？
- 某个节点没有孩子为何不能立即停止？
- 空树和单节点分别有几层？

:::details 算法概述

将深度看成层数。当前数组只保存同一层的节点，遍历它们收集全部孩子形成下一层，每走完一层加一。孩子数组为空说明所有更深路径都不存在，已经走过的层数就是最大深度。空树没有任何层，返回零。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { TreeNode } from '../shared.js'

export function maxDepth(root: TreeNode | null): number {
  if (root === null) return 0
  let level: TreeNode[] = [root]
  let depth = 0
  while (level.length > 0) {
    const next: TreeNode[] = []
    // 本轮只收集下一层避免混入当前层计数
    for (const node of level) {
      if (node.left !== null) next.push(node.left)
      if (node.right !== null) next.push(node.right)
    }
    depth++
    level = next
  }
  return depth
}
```

## 复杂度与边界

- 每个节点处理一次，时间 **O(n)**。
- 设最大层宽为 w，当前和下一层同时存在时最多 **O(w)** 量级，辅助空间 **O(w)**，最坏 **O(n)**。
- 无递归调用栈，不修改输入。
- 若采用递归左右高度取最大，则栈 **O(h)**，二者适合不同树形，不能都无条件标 **O(log n)**。
