# 0108 将有序数组转换为二叉搜索树

相关基础：[本章基础](/leetcode/08-binary-tree/)。[官方题目](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)。

## 题目

:::info 题面

**难度**：简单

输入严格递增数组，把全部值放入一棵高度平衡的二叉搜索树。搜索树要求左侧所有后代比根小、右侧所有后代比根大；平衡要求每个节点左右子树高度差不超过 1。答案不唯一，偶数长度时选偏左或偏右中点都可能正确。目标是构造满足性质的树，不是复刻某个示例的唯一形状。

题面配图用节点和左右连线表示树；示例中作为树的数组按层序列出节点，`null` 表示对应的孩子不存在。数组表示的是连接结构，不要求按数值排序。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [-10,-3,0,5,9]
> 输出：[0,-3,9,-10,null,5]

> **示例 2**
>
> 输入：nums = [1,3]
> 输出：[3,1]

### 约束

- 1 <= nums.length <= 10^4
- -10^4 <= nums[i] <= 10^4
- nums 按 严格递增 顺序排列

## 前期思路

### 朴素方法与复杂度

可以把数组从小到大逐个插入普通搜索树，但第一个最小值作根，后来的值全插到右边，形成链，完全不平衡。手工摆放时，若希望根两边数量差不多，应该选择接近中间的值。因为数组已排序，中点左边全小、右边全大，同时满足搜索顺序与规模平衡两个需求。

### 优化依据

无需反复排序或寻找最接近中位数的值，数组中点就是所需位置。把整个问题拆成左半区间和右半区间，它们仍是有序数组子区间，拥有与原题相同的结构。每个递归调用只需知道左右边界，不需要复制 slice 出两个新数组，避免额外拷贝。

### 算法推导

build(left,right) 处理包含两端的区间。left>right 表示没有值，返回 null。否则取向下取整的中点 middle，新建根节点，然后左孩子来自 [left,middle-1]，右孩子来自 [middle+1,right]。

为什么要把中点从子区间排除？它已被当前根使用，若再次包含，会重复创建同一值，甚至让区间不缩小。每次左右规模都小于当前区间，最终到空区间，所以递归结束。

搜索树性质由排序保证：左区间所有值小于根，右区间所有值大于根；子树递归保持相同性质。平衡来自中点拆分，每层左右规模至多差一，递归产生的高度由各自规模的对数量级决定，相邻规模对应高度最多差一。不是任意“有序建树”都会平衡，关键是每层都均分。

### 变式分析与错误反例

- 错误反例：每次选区间最左元素作根，虽然满足搜索树顺序，但 [1,2,3] 会生成三节点右链，根处高度差 2，违反平衡要求。测试不应只比较某个固定层序答案，因为合法结果不唯一。
- 若输入改成有序链表，按下标取中点不再 O(1)，可用中序模拟构造或快慢找中点，并重新分析成本。若允许重复值，必须先定义等值应该放在哪侧，当前严格搜索树假设不能直接沿用。

## 执行过程示例

数组 [-10,-3,0,5,9]。

| 处理区间 | 选中值 | 左区间 | 右区间 |
| --- | --- | --- | --- |
| 0 到 4 | 0 | -10 -3 | 5 9 |
| 0 到 1 | -10 | 空 | -3 |
| 1 到 1 | -3 | 空 | 空 |
| 3 到 4 | 5 | 空 | 9 |
| 4 到 4 | 9 | 空 | 空 |

根左右各有两个节点，高度都为 2。与示例选择偏右中点不同也没有问题，只要中序还原数组且每处平衡。

## 解法复述与检查

复述检查：

- 中点选择怎样同时保证搜索顺序与平衡？
- 为什么子区间必须排除中点？
- 偶数长度有多个正确树形吗？

:::details 算法概述

有序数组两边大小关系已经确定。为了同时保证平衡，每次选区间中点作根，左半递归构造左子树，右半构造右子树。中点只用一次，空区间返回空。传边界而不切片，每个值只建一个节点。

:::

## TypeScript 实现

本地保留导出及共用类型导入以便测试。提交时移除模块导入和导出，节点定义使用力扣模板；随机节点的类名按模板调整。

```ts
import { TreeNode } from '../shared.js'

export function sortedArrayToBST(nums: number[]): TreeNode | null {
  function build(left: number, right: number): TreeNode | null {
    if (left > right) return null
    // 中点两侧规模最多相差一个
    const middle = Math.floor((left + right) / 2)
    const node = new TreeNode(nums[middle])
    node.left = build(left, middle - 1)
    node.right = build(middle + 1, right)
    return node
  }
  return build(0, nums.length - 1)
}
```

## 复杂度与边界

- 时间 **O(n)**，每个数组元素创建一次；辅助递归栈 **O(log n)**，因为人为构造的树始终均衡。
- 新树输出空间 **O(n)**，输入数组不修改。
- 官方数组非空，本地实现也支持空数组返回 null。
- 数字直接存入 number，不做可能溢出的值计算。
