# 二叉树复习与迁移

复述应覆盖树的额外约束、答案的计量单位、子树返回值、全局候选，以及退出节点时是否恢复状态。不同题目的汇总规则与访问顺序需分别说明。

## 练习一 空侧是不是叶子

根 1 只有右孩子 2，2 只有右孩子 3。求最小深度时，直接套 `1 + min(左深度,右深度)` 会得到什么？怎样修正？

:::details 提示与解析

空侧深度为 0，直接取最小会得到 1，却不存在根到叶只有一个节点的路径。单边为空时只能沿非空侧继续；两边都有时才取较小。也可按层搜索，第一次遇到左右都空的节点才结束，得到 3。最大深度中空侧取零没有这个问题，不能直接把 max 换成 min。

:::

## 练习二 父节点可连接的信息

根 1 的左孩子 2 有两个孩子 3 与 4，根右孩子为 5。求最大路径和时，为什么不能让 2 返回 3+2+4，再由根加 1 和 5？

:::details 提示与解析

这样得到的结构包含 2 的左、右和父三条边，不是一条简单路径。2 可以用 3+2+4=9 更新完整候选，但向父返回只能带 2+max(3,4)=6。根的完整候选为 6+1+5=12，对应 4→2→1→5。问题的重点是返回结果能否合法继续组合，而不是哪个局部数字更大。

:::

## 练习三 前缀和记录何时失效

根和两个孩子都为 1，目标和为 0。解释为什么左分支前缀记录必须在进入右分支前撤销。

:::details 提示与解析

正确答案为 0。左孩子前缀是 2，若它离开后仍在表里，右孩子前缀也是 2，差值 0 会命中旧记录，虚构一条跨兄弟分支路径。Map 表示的是当前根到节点的祖先前缀，不是全树已见前缀。撤销不是为了节省空间，而是维护含义正确。

:::

## 练习四 已排序中序是否足够

普通二叉树中序输出为 [1,2,3]，能否断定是严格二叉搜索树？如果改成允许相等值只出现在右边，中序 [1,1,2] 是否足够？

:::details 提示与解析

对有效二叉树，严格递增中序与严格搜索树性质等价：任意根的左侧值都先出现且更小，右侧值都后出现且更大。但非递减序列无法分辨相等值位于祖先哪侧，例如根 1 左孩子 1 仍输出 [1,1]，却违反只许右侧相等的规则。新定义需要传递带开闭性的边界来检查，不能只放宽一次比较。

:::
