# 技巧复习与迁移

## 一 出现次数变化

其他数字均出现三次，只有一个数字出现一次，直接异或全部元素是否仍然有效？

:::details 提示与解析

无效。三个相同数异或后仍保留该值，无法成对消除。可考虑逐位统计并对三取模，但需要处理位宽和符号位，不能直接复用出现两次时的抵消公式。

:::

## 二 多数不保证存在

若题目不保证严格多数存在，投票算法返回候选后是否可以直接输出？

:::details 提示与解析

不可以。例如 [1,2,3] 会留下一个候选，但没有元素出现次数超过一半。需要再次遍历统计候选的实际次数，验证满足条件后才返回。

:::

## 三 下一个更小排列

若要求得到字典序紧邻的更小排列，选择转折位置和处理后缀的规则应如何改变？

:::details 提示与解析

从右向左寻找仍可减小的位置，即前项大于后项的位置。再从其右侧严格更小的元素中选择最大者交换，最后将后缀调整为尽可能大。目标方向改变后，比较规则和后缀排列方向相应反转。

:::
