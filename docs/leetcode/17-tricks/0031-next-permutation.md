# 0031 下一个排列

字典序由第一个不同位置决定。寻找紧邻的更大排列，需要依次确定必须改变的最靠右位置、该位置的最小增量，以及剩余后缀的最小排列。

相关基础：[本章基础](/leetcode/17-tricks/)。[力扣原题](https://leetcode.cn/problems/next-permutation/)。

## 题目

:::info 题面

**难度**：中等

原地把整数数组改成字典序紧邻的下一个排列。若已是最大排列，改成最小排列。允许重复元素，要求常数额外空间，不返回新数组。字典序由最左侧第一个不同位置决定大小。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [1,2,3]
> 输出：[1,3,2]

> **示例 2**
>
> 输入：nums = [3,2,1]
> 输出：[1,2,3]

> **示例 3**
>
> 输入：nums = [1,1,5]
> 输出：[1,5,1]

### 约束

- 1 <= nums.length <= 100
- 0 <= nums[i] <= 100

## 前期思路

### 朴素方法与复杂度

枚举全部不同排列并排序，再找到当前的后继可以得到正确结果，但排列数量可达阶乘，远远超出需求。更有价值的手工尝试是先只重排最右两项，不行就扩大右侧后缀，找到最靠右可以增大的位置。

### 优化依据

如果一个后缀已经非递增排列，它已经使用这些元素组成了最大字典序，怎样重排都无法更大。因此该后缀的全部重排都可排除，需要向左找到第一个满足nums[i]小于nums[i+1]的位置，称作转折位置。右侧恰好是最大排列后缀。

### 算法推导

从倒数第二项向左寻找转折i。它是最靠右可被增大的位置；更靠右无法只靠重排变大，而更靠左提前改变会造成更大的字典序跳跃。若不存在i，整个数组非递增，已经最大，反转为最小即可。

存在i时，必须从右侧选一个严格大于nums[i]的值交换。为增加幅度最小，应选符合条件的最小值。由于右侧非递增，从最右往左找到的第一个更大值就是它。交换后左前缀固定，新i值以最小幅度变大。

接下来让后缀尽可能小，即升序。交换后的后缀仍非递增：选中的是从右数第一个更大者，右边都不大于旧转折值，左边不小于被选值；替换为旧值后次序仍成立。因此直接反转就得到升序，不需再排序。三步共同保证得到的是紧邻后继，而非任意更大排列。

### 变式分析与错误反例

- 若想得到上一个排列，反向寻找可减小的最靠右位置，选择右侧严格更小中最大的值，再让后缀尽可能大。思考顺序不变，字典序目标改变使比较与后缀方向反转。
- 错误反例：`[1,2,3]`若交换最左1与3得到`[3,2,1]`，虽然更大却不是下一个，正确是`[1,3,2]`。重复值输入`[1,5,5]`中必须选严格大于1的值，后缀最小化仍不能省。

## 执行过程示例

输入`[1,3,2]`。

| 步骤 | 观察或操作 | 数组 |
| --- | --- | --- |
| 找转折 | 3不小于2 继续左移 1小于3 | [1,3,2] |
| 找最小更大值 | 从右遇2 它严格大于1 | 未变 |
| 交换 | 1与2交换 | [2,3,1] |
| 最小化后缀 | 反转3与1 | [2,1,3] |

不能直接停在[2,3,1]，它虽更大却跳过了更近的排列。

## 解法复述与检查

- 为什么从右找转折？
- 为什么从右找第一个更大值就是最小更大值？
- 后缀为什么能直接反转？

:::details 算法概述

首先找最靠右可以增大的位置，后面非递增说明单靠改后缀已经无法变大。从右边找到严格大于转折值的最小值交换，使这一位增幅最小，再反转仍非递增的后缀使后面最小。若整串都非递增，就整体反转回最小排列。

:::

## TypeScript 实现

```ts
export function nextPermutation(nums: number[]): void {
  let pivot = nums.length - 2
  while (pivot >= 0 && nums[pivot] >= nums[pivot + 1]) pivot--
  if (pivot >= 0) {
    let successor = nums.length - 1
    while (nums[successor] <= nums[pivot]) successor--
    ;[nums[pivot], nums[successor]] = [nums[successor], nums[pivot]]
  }
  // 后缀仍然非递增 反转即可得到当前前缀下的最小排列
  let left = pivot + 1
  let right = nums.length - 1
  while (left < right) {
    ;[nums[left], nums[right]] = [nums[right], nums[left]]
    left++
    right--
  }
}
```

## 复杂度与边界

- 寻找转折、替换值和反转各至多线性，总时间**O(n)**，辅助空间**O(1)**。
- 原地修改数组，返回void。
- 单项、全相等、非递增都无需特殊排序，统一反转处理。
- 比较必须使用严格更大，重复值不能拿相等者充当增大。

## 分层提示

:::details 提示一 先观察什么

字典序先看左侧差异 所以尽量从右边寻找增大空间

:::

:::details 提示二 需要维护什么信息

非递增后缀已是最大 找它左边还能增大的位置

:::

:::details 提示三 如何组织步骤

选最小的严格更大后继交换 再把后缀反转为升序

:::
