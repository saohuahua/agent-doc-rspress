# 0075 颜色分类

输入仅包含三种类别，因此目标可以表述为建立连续的零区、一类区和二区。推导的重点是维护已分类区域与未知区域之间的边界，并保证每次交换后仍满足区域定义。

相关基础：[本章基础](/leetcode/17-tricks/)。[力扣原题](https://leetcode.cn/problems/sort-colors/)。

## 题目

:::info 题面

**难度**：中等

数组只包含0、1、2，要求原地排列成所有0在前、1居中、2在后，不返回新数组。题目进阶希望一次遍历和常数额外空间，不能调用通用排序完成核心任务。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [2,0,2,1,1,0]
> 输出：[0,0,1,1,2,2]

> **示例 2**
>
> 输入：nums = [2,0,1]
> 输出：[0,1,2]

### 约束

- n == nums.length
- 1 <= n <= 300
- nums[i] 为 0、1 或 2

### 进阶要求

尝试只用常数空间扫描一趟。

## 前期思路

### 朴素方法与复杂度

先数出三种值各有几个，再按计数覆盖数组，可以O(n)时间和O(1)空间完成，是正确易懂的两遍方案。若进一步希望单遍，就不能等完整统计后再重写，而需要一边看一边确认各值所属区域。

### 优化依据

新建三个数组分类最后拼接保存了不必要的副本。数组本身已有足够空间，只需维护三个边界，把尚未分类的元素逐步送到两端或中间。一遍方案需要维护更细的区域状态；与计数法相比，它以更复杂的边界处理换取单次遍历。

### 算法推导

用left指向零区右侧，current指向未知区左侧，right指向未知区右侧。始终保持左侧到left之前全为0，left到current之前全为1，current到right未知，right之后全为2。初始两种已确认左区为空，整个数组未知。

若当前是0，与left交换，再让left和current都前进。若left小于current，交换回来的必是已确认的1，所以无需重查；若二者相等则只是自交换。若当前是1，只前进current，扩大中间区。若当前是2，与right交换并缩小right，但current不动，因为从未知区右端换来的值尚未分类。

每个分支都减少未知区长度，且保持已确认区域条件。循环在current大于right时结束，未知区为空，三段都正确且没有丢失元素。交换只改变位置，不改变每种值的数量。

### 变式分析与错误反例

- 若有k种颜色且k可变，三个边界不够直接推广，可以先计数再回填，空间O(k)。若元素是带其他字段的对象且要求稳定分组，两遍覆盖数值也不再适用，需要保留对象及相对顺序。
- 错误反例：`[1,2,0]`处理中间2与右边0交换后变为`[1,0,2]`，若直接推进current，就漏掉0，结果仍无序。必须重新检查换回来的未知值。

## 执行过程示例

用`[2,0,1]`手推所有步骤。

| 当前状态 | 动作 | 新数组与边界 |
| --- | --- | --- |
| left0 current0 right2 | 2交换右端 不推进current | [1,0,2] 边界0 0 1 |
| current值1 | current前进 | [1,0,2] 边界0 1 1 |
| current值0 | 与left交换 两个左边界前进 | [0,1,2] 边界1 2 1 |

current越过right，所有未知项完成分类。

## 解法复述与检查

- 四个区域分别是什么？
- 为什么换到右边后不能立即推进current？
- 换到左边后却可以推进？

:::details 算法概述

维护零区、一类区、未知区和二区。当前未知值是0就交换到零区后方并推进两个左边界，是1就扩大一类区，是2就送到右端并缩小未知右界。右端换回的仍未知，所以要停在当前位置再检查。未知区清空时原地排序完成。

:::

## TypeScript 实现

```ts
export function sortColors(nums: number[]): void {
  let left = 0
  let current = 0
  let right = nums.length - 1
  while (current <= right) {
    if (nums[current] === 0) {
      ;[nums[left], nums[current]] = [nums[current], nums[left]]
      left++
      current++
    } else if (nums[current] === 2) {
      ;[nums[current], nums[right]] = [nums[right], nums[current]]
      right--
      // 右端换回的仍属未知区域 必须留在当前位置检查
    } else {
      current++
    }
  }
}
```

## 复杂度与边界

- 每轮未知区至少缩短一项，所以时间**O(n)**，辅助空间**O(1)**。
- 直接修改输入，返回void。
- 不使用新数组存分类结果。
- 相同数值的对象身份若有业务含义，此交换过程不保证稳定性。
