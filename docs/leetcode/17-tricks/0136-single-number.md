# 0136 只出现一次的数字

除一个元素出现一次外，其余元素均恰好出现两次。该次数约束允许用具有成对抵消性质的运算替代完整计数表，但正确性同时依赖运算性质和输入位宽。

相关基础：[本章基础](/leetcode/17-tricks/)。[力扣原题](https://leetcode.cn/problems/single-number/)。

## 题目

:::info 题面

**难度**：简单

输入非空整数数组，一个元素出现一次，其余每个元素出现两次。返回单个元素，要求线性时间和常数额外空间。不是找所有不重复元素，也不允许其他元素出现三次。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [2,2,1]
> 输出：1

> **示例 2**
>
> 输入：nums = [4,1,2,1,2]
> 输出：4

> **示例 3**
>
> 输入：nums = [1]
> 输出：1

### 约束

- 1 <= nums.length <= 3 * 10^4
- -3 * 10^4 <= nums[i] <= 3 * 10^4
- 除了某个元素只出现一次以外，其余每个元素均出现两次。

## 前期思路

### 朴素方法与复杂度

可以用Map统计次数，再找次数为一的键，时间O(n)、空间O(n)。也可以排序后成对比较，但需要排序成本。计数法能够直接保证正确性，但不能满足常数额外空间要求；进一步优化需要利用其余值恰好成对的条件。

### 优化依据

完整计数表保留了每个值的身份与次数，但最终只需让所有成对值消失。寻找一种满足相同值抵消、与零结合不改变值、顺序可任意调整的运算，就能把整张表压缩成一个累积结果。逐位异或恰好具备这些性质。

### 算法推导

先看单个位：0异或0与1异或1都是0，0异或1与1异或0都是1。因此任何数x与自己异或得到0，x与0异或仍是x。异或满足交换律和结合律，所有相同值即使在输入中相隔很远，也可以在数学上重新分组。

以0初始化answer，依次把每项异或进去。全部处理后，可把重复元素两两配对，它们各贡献0，唯一单值与这些0异或后不变。中间累积结果未必是某个输入元素，因此每一步的累积值并不代表一个答案候选；只有完整遍历和次数保证共同支撑最终含义。

辅助空间为常数，因为算法只维护一个32位累积值，不保留每个元素的记录。本题数值在适用位宽内，负数以补码参与运算，同值仍会抵消。若超出位宽，即使TS类型仍是number，也不代表这个运算保留原整数。

### 变式分析与错误反例

- 若其他元素出现三次，三次异或还剩该值，方法失效，可改用逐位计数对三取模。若有两个单值，总异或只得到二者混合值，需要依据某个不同二进制位分组，分别抵消后才能恢复两个答案。
- 错误反例：`[2,2,2,3]`不符合本题次数保证，异或得到1而不是单值3。这个例子说明正确性来自题目条件，不是异或天然能找到唯一出现一次的数字。

## 执行过程示例

对`[4,1,2,1,2]`完整累积。

| 读入 | 异或后结果 | 解释 |
| --- | --- | --- |
| 初始 | 0 | 单位元素 |
| 4 | 4 | 与零结合不变 |
| 1 | 5 | 暂态无需对应输入值 |
| 2 | 7 | 继续累积 |
| 1 | 6 | 两个1在整体中抵消 |
| 2 | 4 | 两个2抵消 只剩4 |

## 解法复述与检查

- 为什么不需要把重复值排在一起？
- 中间answer是否一定是答案候选？
- 哪些次数和数值范围条件不可删？

:::details 算法概述

先考虑计数表可以找单值，再利用其余值恰好成对，用异或让相同数抵消。异或可以交换结合，因此不需要排序，从零累积全部元素即可。成对项都归零，单值留下。这个实现依赖输入位宽和出现次数保证。

:::

## TypeScript 实现

```ts
export function singleNumber(nums: number[]): number {
  let answer = 0
  // 相同值成对抵消 完整遍历后才得到唯一单值
  for (const num of nums) answer ^= num
  return answer
}
```

## 复杂度与边界

- 时间**O(n)**，辅助空间**O(1)**，不修改输入。
- JS普通位运算采用32位整数，本题范围内适用。
- 单项输入直接返回该值，负数也能抵消。
- 不能推广为任意number整数都安全。
