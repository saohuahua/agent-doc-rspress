# 0287 寻找重复数

有限值域使数组元素能够作为下一次访问的下标。由此形成的跳转关系可以用于定位重复值，但必须证明环入口与重复数字的对应关系，而非仅证明存在环。

相关基础：[本章基础](/leetcode/17-tricks/)。[力扣原题](https://leetcode.cn/problems/find-the-duplicate-number/)。

## 题目

:::info 题面

**难度**：中等

长度为n加一的数组，每个值都在1到n之间，仅有一个重复的整数，它可以出现两次以上。返回这个重复整数，要求不修改数组且额外空间O(1)。不是找重复值第一次出现的下标。

:::

### 官方示例

> **示例 1**
>
> 输入：nums = [1,3,4,2,2]
> 输出：2

> **示例 2**
>
> 输入：nums = [3,1,3,4,2]
> 输出：3

> **示例 3**
>
> 输入：nums = [3,3,3,3,3]
> 输出：3

### 约束

- 1 <= n <= 10^5
- nums.length == n + 1
- 1 <= nums[i] <= n
- nums 中 只有一个整数 出现 两次或多次 ，其余整数均只出现 一次

### 进阶要求

证明重复数必然存在 并尝试 O(n) 时间解法。

## 前期思路

### 朴素方法与复杂度

用Set记录见过的值，遇到再次出现就能返回，时间线性但空间线性。排序后比较相邻值会改变原数组；复制再排序又违背常数空间。这些方法虽能找到重复值，但不满足全部约束；进一步优化需要利用长度与值域的关系。

### 优化依据

数组值都能成为合法下标，因此无需额外创建节点或next数组，原数组已经描述一个每点只有一条出边的图。令下一位置为nums[当前位置]，从下标0开始。有限个节点持续跳转必然重复，从而进入环。

### 算法推导

环入口与重复数字的对应关系来自两个不同前驱。0不在值域内，所以没有任何边指向0，起点位于环外。从0走到环入口时，入口有一个来自环外路径的前驱，也有一个来自环内的前驱，这两个不同下标的值都等于入口下标。因此入口编号就是重复值。唯一重复保证让目标没有歧义。

先让slow与fast都从0出发，每轮分别走一步与两步，至少移动一次后再检查相等。它们最终在环内相遇，但相遇点不一定是入口。设起点到入口距离为μ，环长为λ，相遇时慢指针走了t步；快指针多走t步且在同一点，说明t是λ的倍数。

将一个指针放回0，另一个留在相遇处，两者每次一步。走μ步后，起点指针到入口；相遇指针总位置对应t加μ，而t是整圈数，所以也回到入口。之前起点指针尚在环外，不可能与环内指针相遇，故第一次相遇就是入口。返回该下标数值即重复整数。

### 变式分析与错误反例

- 若允许修改数组，可以把值放回对应位置检查冲突，但那使用了不同约束。若值域不是合法下标范围，当前图映射无法直接成立，改用Set或其他适合新约束的方法，不能继续按数值索引。
- 错误反例：示例第一次相遇在4，而重复数字是2，直接返回相遇位置会错。把两个指针初始同为0却用普通while先比较，会一开始就停止，因此第一阶段必须先移动再判断。

## 执行过程示例

数组`[1,3,4,2,2]`对应路径0到1到3到2到4到2。

| 第一阶段轮次 | slow | fast |
| --- | --- | --- |
| 初始 | 0 | 0 |
| 1 | 1 | 3 |
| 2 | 3 | 4 |
| 3 | 2 | 4 |
| 4 | 4 | 4 |

重置一指针为0，随后两者分别为1与2、3与4、2与2，在入口2相遇，所以重复值是2。这里第一次相遇4不是答案。

## 解法复述与检查

- 数组为何能作为跳转图？
- 为什么0必须不在值域？
- 第一次相遇为什么不能直接返回？
- 重置后同步走依据是什么？

:::details 算法概述

将nums[i]当成下一下标，从0出发形成环。因为0没有入边，进入环的入口同时有环外和环内两个前驱，所以入口编号就是重复值。先用快慢步速找到环内相遇点，再把一指针放回0，两者同步前进，利用相遇时走过整圈的关系找到入口。全程不改数组也不保存访问集合。

:::

## TypeScript 实现

```ts
export function findDuplicate(nums: number[]): number {
  let slow = 0
  let fast = 0
  do {
    slow = nums[slow]
    fast = nums[nums[fast]]
  } while (slow !== fast)
  // 首次相遇只证明进入同一环 重置后再定位入口
  let finder = 0
  while (finder !== slow) {
    finder = nums[finder]
    slow = nums[slow]
  }
  return finder
}
```

## 复杂度与边界

- 路径尾部与环总长度不超过n加一，两阶段时间**O(n)**，辅助空间**O(1)**，不修改输入。
- 题目值域保证所有间接访问合法。
- 重复次数可以超过两次。
- 实现不是对任意数字数组都安全的通用重复检测器。
