# 技巧基础 从题目特殊条件中减少信息

本章方法依赖出现次数、值域、类别数量或排列顺序等特定约束。推导重点是将这些约束转换为抵消、分区或连接关系，并明确条件变化后哪些结论不再成立。

阅读前提：[TypeScript数值与引用](/leetcode/00-intro/03-ts-runtime-and-recursion)。下一个排列还需要知道数值序列的字典序，寻找重复数需要理解 [链表基础](/leetcode/07-linked-list/) 中的环与快慢追赶。

## 异或消除的是成对出现

异或逐二进制位运算，相同位得到0，不同位得到1。一个整数与自身异或为0，与0异或仍是自身；运算满足交换和结合，所以排列顺序不影响所有数异或的结果。

这正适合所有其他元素恰好出现两次的情况。它并不一般性回答哪个数字重复、哪个数字出现奇数次最多。如果有两个只出现一次的值，把所有数异或只会得到它们混合的结果，还需要额外分组才能分离。

JavaScript对number做普通位运算时使用32位整数语义。本题数值范围在该模型内，该实现不能直接推广到任意安全整数，TS 的 number 类型也不保证整数处于该位宽范围内。

## 多数条件与抵消不变量

一个值出现次数严格超过一半时，删掉一对不同值后，它仍然是剩余部分的严格多数。若一对包含多数值，其他值总数也减少一；若都不是，多数优势更大。这使得不断成对抵消以后留下的候选一定是多数。

投票变量记录未被抵消的余额，不是候选的真实出现次数。当余额归零，前面的处理块已经被成对抵消，换候选不影响最终保证。若题目没有保证多数存在，还必须第二遍计数验证候选。

## 分区是给未知区域逐步分类

颜色分类把数组切成已确认的零区、一类区、未知区和二区。每一步只处理未知区最左项，根据数值交换到正确区域，并确保未知区长度减少。

这与普通排序不同：这里只有三种有限类别，分区不需要比较任意两项的完整大小关系。若元素是有身份的对象并要求相同类别维持相对顺序，交换式方案不保证稳定，需要重新设计。

## 字典序的优先级在靠左位置

比较两个序列时，从左到右第一个不同位置决定谁更大。因此下一个排列应尽量不改左侧，找到最靠右仍可增大的位置，再把它增加最小可能幅度，最后把后缀排到最小。

例如1、3、2的后缀3、2已经从大到小，单靠重排这段无法变得更大。必须增大前面的1，然后让剩余部分尽量小。上述步骤分别对应字典序比较中的位置优先级、增量最小化和后缀最小化。

## 数值也能充当指针

长度n加一、值域1到n的数组，可以把下标当节点，把nums[i]当下一节点。每个节点只有一个出口，从0不断跳必然重复访问某个节点，形成环。数值范围保证跳转合法，0不在值域保证起点没有入边，进入环处对应重复引用的值。

这些映射必须逐个检查：若数组值可能越界，就不是同一个合法图；若0也允许出现，起点与环入口的关系需要重做证明。方法的适用性由这些约束与映射关系共同决定，代码中的运算或指针移动本身不能保证其适用于其他输入。
