# 力扣 Hot100 教材

> 以 **LeetCode Hot100** 为范围，系统讲解常用数据结构、算法设计方法与 TypeScript 实现。解题分析按 **问题定义 → 朴素方法 → 计算瓶颈 → 状态设计 → 正确性依据 → 实现** 展开，重点解释方法的来源及其成立条件。
>
> 适用读者：具备 TypeScript 语法经验、需要系统补充算法基础的开发者。学习目标分两层——先能脱离代码说明状态含义、操作步骤与正确性依据，再完成实现与验证。

:::tip 阅读方式

每道题页末用可折叠的「分层提示」给出三级递进线索（观察方向 → 所需信息 → 组织步骤），与「解法概述」分开收存。建议先自行推导，卡住时只展开当前一级提示，再对照解法概述与实现。每章末尾的「复习与迁移」用于自测方法识别与迁移能力。

:::
