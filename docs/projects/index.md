# 项目

## pi-web-vue

给终端里的 Pi Coding Agent 做一个 Web 工作台。Node 服务端接入 Pi Agent SDK，用 SSE 把执行事件送到浏览器。Vue 界面负责组装流式消息，并处理会话切换时晚到的事件。
