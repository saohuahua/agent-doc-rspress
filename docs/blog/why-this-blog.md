# 这个博客想写些什么

做 Agent 应用时，很多问题是把模型、服务端和界面连起来以后才出现的。比如在 `pi-web-vue` 里，用户切换会话以后，先前发出的查询还可能返回。写回界面前，需要确认结果仍属于当前会话、发出请求后会话没有关闭过，以及这仍是最新一次查询。

这类问题适合写成短篇复盘：当时看到什么现象，试过哪些做法，最后用什么证据判断改动有效。想往下看实现，可以看 [pi-web-vue 的设计取舍](/interview/pi-web-vue/02-design-tradeoffs)。

这个博客会记开发过程中遇到的问题和还在形成的想法。适合系统阅读的源码拆解、学习路线和参考资料，可以从 [技术笔记](/notes/) 找到。
