# HTML5 基础

## 特点

+ **提升可读性**， 语义化标签让代码更易于阅读和理解  
+ **改善可访问性**： 屏幕阅读器等辅助技术可以根据语义化标签更好地解析网页结构，帮助视障用户更好地理解和导航页面 ， 例如，一个屏幕阅读器会知道 `<nav>` 里面是导航链接  
+ **有利于SEO搜索引擎优化**： 更好地理解页面的结构和内容，从而更准确地对网页进行排名。例如，搜索引擎会优先考虑 `<article>` 和 `<main>` 中的内容 
+ **易于维护**：当项目规模变大时，语义化的代码结构使得团队协作和后期维护变得更加高效，能快速定位到需要修改的部分  

## 常见的语义化标签

+ `<header>`：通常包含介绍性内容或一组导航链接，比如网站的 logo、主标题和搜索框
+ `<nav>`：定义导航链接的部分，通常包含菜单、链接列表等
+ `<main>`：定义文档的主体内容，一个页面只能有一个 `<main>` 标签
+ `<article>`：定义独立的、完整的、可以独立分发或重用的内容，比如一篇博客文章、一个论坛帖子或一条新闻
+ `<section>`：定义文档中的一个通用区块，通常包含一个标题。一个 `<section>` 应该有一个清晰的主题，并且通常和 `<h1-h6>` 搭配使用
+ `<aside>`：定义与页面内容主体相关但又相对独立的内容，比如侧边栏、广告或引用的内容
+ `<footer>`：定义文档的页脚，通常包含版权信息、作者信息或联系方式
+ `<figure>` 和 `<figcaption>`：`<figure>` 用来包含图片、图表、代码块等独立内容，而 `<figcaption>` 则为该内容提供一个标题或说明
